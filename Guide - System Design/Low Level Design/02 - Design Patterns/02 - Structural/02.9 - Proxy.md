# Proxy Pattern

## At a Glance

|||
|---|---|
|**Type**|Structural|
|**Intent**|Provide a surrogate/placeholder for another object to control access to it|
|**Also Known As**|Surrogate|
|**Frequency in Backend**|★★★★☆ — caching, auth guards, lazy loading, rate limiting|

---

## Proxy Types

|Type|Controls|Example|
|---|---|---|
|**Virtual Proxy**|Lazy initialization|Delay expensive DB connection until first use|
|**Protection Proxy**|Access control|Check permissions before forwarding|
|**Caching Proxy**|Result caching|Return cached response, skip real call|
|**Remote Proxy**|Location transparency|gRPC stub, REST client as local object|
|**Logging Proxy**|Auditability|Record every call to sensitive service|

---

## Full Backend Example: Multi-type Proxy

```python
# user_repository.py — Real subject
class UserRepository(ABC):
    @abstractmethod
    def find_by_id(self, user_id: UUID) -> Optional[User]: pass
    
    @abstractmethod
    def find_by_email(self, email: str) -> Optional[User]: pass
    
    @abstractmethod
    def save(self, user: User) -> User: pass
    
    @abstractmethod
    def delete(self, user_id: UUID) -> bool: pass


class SqlUserRepository(UserRepository):
    """Real implementation — does actual DB work."""
    def __init__(self, session): self._session = session
    
    def find_by_id(self, user_id):
        return self._session.query(UserModel).get(user_id)
    
    def find_by_email(self, email):
        return self._session.query(UserModel).filter_by(email=email).first()
    
    def save(self, user):
        self._session.merge(user)
        return user
    
    def delete(self, user_id):
        user = self.find_by_id(user_id)
        if user:
            self._session.delete(user)
            return True
        return False


# caching_proxy.py — Caching Proxy
class CachingUserRepository(UserRepository):
    """
    Caching Proxy: checks cache before hitting DB.
    Transparent to callers — same interface as SqlUserRepository.
    """
    
    def __init__(self, real_repo: UserRepository, cache: CacheClient,
                 ttl_seconds: int = 300):
        self._repo = real_repo
        self._cache = cache
        self._ttl = ttl_seconds
    
    def find_by_id(self, user_id: UUID) -> Optional[User]:
        key = f"user:id:{user_id}"
        cached = self._cache.get(key)
        if cached is not None:
            return cached
        
        user = self._repo.find_by_id(user_id)
        if user:
            self._cache.set(key, user, self._ttl)
        return user
    
    def find_by_email(self, email: str) -> Optional[User]:
        key = f"user:email:{email}"
        cached = self._cache.get(key)
        if cached is not None:
            return cached
        
        user = self._repo.find_by_email(email)
        if user:
            self._cache.set(key, user, self._ttl)
        return user
    
    def save(self, user: User) -> User:
        saved = self._repo.save(user)
        # Invalidate on write
        self._cache.delete(f"user:id:{user.id}")
        self._cache.delete(f"user:email:{user.email}")
        return saved
    
    def delete(self, user_id: UUID) -> bool:
        user = self.find_by_id(user_id)
        result = self._repo.delete(user_id)
        if result and user:
            self._cache.delete(f"user:id:{user_id}")
            self._cache.delete(f"user:email:{user.email}")
        return result


# auth_proxy.py — Protection Proxy
class AuthorizedUserRepository(UserRepository):
    """
    Protection Proxy: enforces permissions before delegating.
    Admin can delete; regular users can only read their own data.
    """
    
    def __init__(self, real_repo: UserRepository, current_user: "AuthenticatedUser"):
        self._repo = real_repo
        self._current_user = current_user
    
    def find_by_id(self, user_id: UUID) -> Optional[User]:
        # Users can only see their own record, admins can see any
        if not self._current_user.is_admin and self._current_user.id != user_id:
            raise PermissionDenied(f"Cannot access user {user_id}")
        return self._repo.find_by_id(user_id)
    
    def find_by_email(self, email: str) -> Optional[User]:
        self._require_admin("find by email")
        return self._repo.find_by_email(email)
    
    def save(self, user: User) -> User:
        if not self._current_user.is_admin and self._current_user.id != user.id:
            raise PermissionDenied("Cannot modify another user's data")
        return self._repo.save(user)
    
    def delete(self, user_id: UUID) -> bool:
        self._require_admin("delete users")
        return self._repo.delete(user_id)
    
    def _require_admin(self, action: str):
        if not self._current_user.is_admin:
            raise PermissionDenied(f"Admin required to {action}")


# audit_proxy.py — Logging/Audit Proxy
class AuditingUserRepository(UserRepository):
    """Audit Proxy: logs every mutation for compliance."""
    
    def __init__(self, real_repo: UserRepository, audit_log: AuditLog):
        self._repo = real_repo
        self._audit = audit_log
    
    def find_by_id(self, user_id): return self._repo.find_by_id(user_id)
    def find_by_email(self, email): return self._repo.find_by_email(email)
    
    def save(self, user: User) -> User:
        result = self._repo.save(user)
        self._audit.record(action="user.saved", entity_id=str(user.id),
                          actor=get_current_user_id())
        return result
    
    def delete(self, user_id: UUID) -> bool:
        result = self._repo.delete(user_id)
        if result:
            self._audit.record(action="user.deleted", entity_id=str(user_id),
                              actor=get_current_user_id())
        return result


# Compose proxy chain
repo = (
    AuditingUserRepository(
        CachingUserRepository(
            SqlUserRepository(db_session),
            cache=redis_cache
        ),
        audit_log=AuditLog()
    )
)
# Reads: AuditProxy → CachingProxy → SqlRepo (cache hit skips SQL)
# Writes: AuditProxy → CachingProxy (invalidate) → SqlRepo
```

## Proxy vs Decorator

||Proxy|Decorator|
|---|---|---|
|Purpose|Control _access_|Add _behavior_|
|Creates subject?|Often yes (lazy init)|No — receives externally|
|Knows real type?|Often yes|Usually no|
|Chain?|Rarely|Common|
|Example|Auth guard, cache|Retry, logging|

---

## When NOT to Use Proxy

- **Behavior modification** — that's Decorator
- **Simple delegation** — just call the method directly
- **When transparency is not needed** — if callers should know they're going through a special layer, don't use Proxy

---

## Tradeoffs

|Pro|Con|
|---|---|
|Transparent to callers|Response time latency (caching proxy adds overhead)|
|Separation of cross-cutting concerns|Cache invalidation complexity|
|Access control without touching subject|Proxy must stay in sync with interface changes|
