# Case Study: Job Scheduler

**Difficulty:** Hard | **Patterns:** Command, Observer, State, Strategy, Template Method

---

## Step 1: Requirements

### Functional

- Schedule one-time and recurring (cron) jobs
- Multiple job types: function execution, HTTP webhook, message queue publish
- Priority queues (Critical, High, Normal, Low)
- Retry with configurable policy (count, backoff strategy)
- Distributed: multiple worker nodes claim and execute jobs
- Job history, execution logs
- Pause, resume, cancel jobs
- Dependency chains: Job B starts only after Job A completes

### Non-Functional

- A due job runs within 5 seconds of its scheduled time
- Exactly-once execution (no double runs)
- Survives worker crashes (job re-queued)
- Support 100K+ scheduled jobs

---

## Step 2: State Machine

```
JobStatus lifecycle:

SCHEDULED ──[due + claimed]──▶ RUNNING
           ──[cancelled]──────▶ CANCELLED

RUNNING ──[success]──────────▶ COMPLETED
        ──[failure, retries left]──▶ SCHEDULED  (retry with delay)
        ──[failure, max retries]──▶ FAILED
        ──[worker crash + timeout]──▶ SCHEDULED  (reclaimed)

COMPLETED ── (terminal)
FAILED    ── (terminal)
CANCELLED ── (terminal)
```

# models.py
from enum import Enum
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from datetime import datetime
from typing import Optional, List, Any
from decimal import Decimal

class JobStatus(Enum):
    SCHEDULED = "SCHEDULED"
    RUNNING = "RUNNING"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"
    CANCELLED = "CANCELLED"
    PAUSED = "PAUSED"

class JobPriority(Enum):
    CRITICAL = 1
    HIGH = 2
    NORMAL = 3
    LOW = 4

@dataclass
class RetryPolicy:
    max_retries: int = 3
    backoff_strategy: str = "exponential"   # "fixed", "exponential", "linear"
    base_delay_seconds: int = 60
    max_delay_seconds: int = 3600
    
    def next_delay(self, attempt: int) -> int:
        if self.backoff_strategy == "fixed":
            return self.base_delay_seconds
        elif self.backoff_strategy == "linear":
            return min(self.base_delay_seconds * attempt, self.max_delay_seconds)
        else:  # exponential
            return min(self.base_delay_seconds * (2 ** (attempt - 1)), self.max_delay_seconds)

@dataclass
class JobExecution:
    execution_id: UUID = field(default_factory=uuid4)
    job_id: UUID = None
    worker_id: str = ""
    started_at: datetime = field(default_factory=datetime.now)
    completed_at: Optional[datetime] = None
    status: str = "RUNNING"
    output: Any = None
    error: Optional[str] = None
    attempt_number: int = 1


# job.py — Command pattern: encapsulates work to be done
class JobPayload:
    """Base for all job payloads (Command objects)."""
    pass

@dataclass
class HttpWebhookPayload(JobPayload):
    url: str
    method: str = "POST"
    headers: dict = field(default_factory=dict)
    body: Optional[dict] = None
    timeout_seconds: int = 30

@dataclass
class FunctionPayload(JobPayload):
    module: str          # "myapp.tasks"
    function: str        # "send_report"
    args: list = field(default_factory=list)
    kwargs: dict = field(default_factory=dict)

@dataclass
class MessageQueuePayload(JobPayload):
    queue_url: str
    message: dict
    delay_seconds: int = 0


class Job:
    """
    Scheduled job aggregate.
    Enforces state machine and retry logic.
    """
    
    def __init__(self, job_id: UUID, name: str, payload: JobPayload,
                 scheduled_at: datetime, priority: JobPriority,
                 retry_policy: RetryPolicy, cron_expression: Optional[str] = None,
                 depends_on: Optional[UUID] = None):
        self.id = job_id
        self.name = name
        self.payload = payload
        self.scheduled_at = scheduled_at
        self.priority = priority
        self.retry_policy = retry_policy
        self.cron_expression = cron_expression
        self.depends_on = depends_on
        
        self._status = JobStatus.SCHEDULED
        self._attempt_count = 0
        self._executions: List[JobExecution] = []
        self._claimed_by: Optional[str] = None
        self._claim_expires_at: Optional[datetime] = None
        self._events = []
    
    @property
    def status(self): return self._status
    @property
    def attempt_count(self): return self._attempt_count
    @property
    def is_recurring(self): return self.cron_expression is not None
    
    def claim(self, worker_id: str, claim_ttl_seconds: int = 300) -> bool:
        """Atomic claim — only one worker wins. Returns True if claimed."""
        if self._status != JobStatus.SCHEDULED:
            return False
        if self._claim_expires_at and datetime.now() < self._claim_expires_at:
            return False  # already claimed by another worker
        
        self._status = JobStatus.RUNNING
        self._claimed_by = worker_id
        self._claim_expires_at = datetime.now().replace(
            second=datetime.now().second + claim_ttl_seconds
        )
        self._attempt_count += 1
        
        execution = JobExecution(
            job_id=self.id, worker_id=worker_id,
            attempt_number=self._attempt_count
        )
        self._executions.append(execution)
        return True
    
    def complete(self, output: Any = None):
        if self._status != JobStatus.RUNNING:
            raise InvalidStateTransition(f"Cannot complete job in {self._status} state")
        
        self._status = JobStatus.COMPLETED
        self._claimed_by = None
        
        if self._executions:
            self._executions[-1].status = "COMPLETED"
            self._executions[-1].completed_at = datetime.now()
            self._executions[-1].output = output
        
        self._events.append(JobCompleted(job_id=self.id))
        
        # If recurring, schedule next run
        if self.is_recurring:
            self._events.append(JobRecurringScheduleNext(
                job_id=self.id, cron=self.cron_expression
            ))
    
    def fail(self, error: str):
        if self._status != JobStatus.RUNNING:
            raise InvalidStateTransition(f"Cannot fail job in {self._status} state")
        
        if self._executions:
            self._executions[-1].status = "FAILED"
            self._executions[-1].completed_at = datetime.now()
            self._executions[-1].error = error
        
        if self._attempt_count <= self.retry_policy.max_retries:
            # Reschedule with backoff
            delay = self.retry_policy.next_delay(self._attempt_count)
            self.scheduled_at = datetime.now().replace(
                second=datetime.now().second + delay
            )
            self._status = JobStatus.SCHEDULED
            self._claimed_by = None
            self._events.append(JobRetryScheduled(
                job_id=self.id, attempt=self._attempt_count,
                next_run_at=self.scheduled_at
            ))
        else:
            self._status = JobStatus.FAILED
            self._events.append(JobFailed(job_id=self.id, error=error,
                                         attempts=self._attempt_count))
    
    def cancel(self, reason: str = ""):
        if self._status in (JobStatus.COMPLETED, JobStatus.FAILED):
            raise InvalidStateTransition("Cannot cancel terminal job")
        self._status = JobStatus.CANCELLED
        self._events.append(JobCancelled(job_id=self.id, reason=reason))
    
    def get_events(self): return list(self._events)
    def clear_events(self): self._events.clear()


# executors.py — Strategy pattern: execute different job types
class JobExecutor(ABC):
    @abstractmethod
    def can_execute(self, payload: JobPayload) -> bool: pass
    
    @abstractmethod
    def execute(self, payload: JobPayload) -> Any: pass


class HttpWebhookExecutor(JobExecutor):
    def can_execute(self, payload): return isinstance(payload, HttpWebhookPayload)
    
    def execute(self, payload: HttpWebhookPayload) -> dict:
        import requests
        response = requests.request(
            method=payload.method,
            url=payload.url,
            headers=payload.headers,
            json=payload.body,
            timeout=payload.timeout_seconds
        )
        response.raise_for_status()
        return {"status_code": response.status_code, "body": response.text[:1000]}


class FunctionExecutor(JobExecutor):
    def can_execute(self, payload): return isinstance(payload, FunctionPayload)
    
    def execute(self, payload: FunctionPayload) -> Any:
        import importlib
        module = importlib.import_module(payload.module)
        func = getattr(module, payload.function)
        return func(*payload.args, **payload.kwargs)


class MessageQueueExecutor(JobExecutor):
    def __init__(self, sqs_client):
        self._sqs = sqs_client
    
    def can_execute(self, payload): return isinstance(payload, MessageQueuePayload)
    
    def execute(self, payload: MessageQueuePayload) -> dict:
        import json
        result = self._sqs.send_message(
            QueueUrl=payload.queue_url,
            MessageBody=json.dumps(payload.message),
            DelaySeconds=payload.delay_seconds
        )
        return {"message_id": result["MessageId"]}


# scheduler.py — Distributed scheduler with Redis-based locking
class JobScheduler:
    """
    Polls for due jobs, claims via distributed lock, executes.
    Multiple instances can run; each claims separate jobs.
    """
    
    def __init__(self, job_repo, executors: List[JobExecutor],
                 redis_client, event_bus, worker_id: str = None):
        self._repo = job_repo
        self._executors = executors
        self._redis = redis_client
        self._bus = event_bus
        self._worker_id = worker_id or f"worker-{uuid4().hex[:8]}"
        self._running = False
    
    def start(self, poll_interval: float = 1.0):
        """Main loop — polls for due jobs continuously."""
        self._running = True
        logger.info(f"Scheduler {self._worker_id} started")
        
        while self._running:
            try:
                self._process_due_jobs()
            except Exception as e:
                logger.error(f"Scheduler error: {e}", exc_info=True)
            time.sleep(poll_interval)
    
    def stop(self):
        self._running = False
    
    def _process_due_jobs(self):
        """Fetch and process jobs due now, ordered by priority."""
        due_jobs = self._repo.find_due(
            before=datetime.now(),
            statuses=[JobStatus.SCHEDULED],
            limit=10,
            order_by_priority=True
        )
        
        for job in due_jobs:
            # Check dependency: skip if dependency not completed
            if job.depends_on:
                dep = self._repo.find_by_id(job.depends_on)
                if not dep or dep.status != JobStatus.COMPLETED:
                    continue
            
            # Distributed lock: only one worker claims each job
            lock_key = f"job:lock:{job.id}"
            acquired = self._redis.set(lock_key, self._worker_id,
                                       nx=True, ex=300)  # 5-min lock
            if not acquired:
                continue  # another worker got it
            
            try:
                claimed = job.claim(self._worker_id)
                if not claimed:
                    self._redis.delete(lock_key)
                    continue
                
                self._repo.save(job)
                self._execute_job(job)
            finally:
                self._redis.delete(lock_key)
    
    def _execute_job(self, job: Job):
        executor = self._find_executor(job.payload)
        if not executor:
            job.fail(f"No executor for {type(job.payload).__name__}")
            self._repo.save(job)
            return
        
        try:
            output = executor.execute(job.payload)
            job.complete(output)
            logger.info(f"Job {job.id} ({job.name}) completed")
        except Exception as e:
            error = str(e)
            logger.warning(f"Job {job.id} failed (attempt {job.attempt_count}): {error}")
            job.fail(error)
        
        self._repo.save(job)
        
        for event in job.get_events():
            self._bus.publish(event)
        job.clear_events()
    
    def _find_executor(self, payload: JobPayload) -> Optional[JobExecutor]:
        return next((e for e in self._executors if e.can_execute(payload)), None)


# Stale job recovery — run periodically
class StaleJobRecovery:
    """Reclaims jobs that were running but worker died before completing."""
    
    def __init__(self, job_repo, stale_threshold_minutes: int = 15):
        self._repo = job_repo
        self._threshold = stale_threshold_minutes
    
    def recover(self):
        cutoff = datetime.now().replace(
            minute=datetime.now().minute - self._threshold
        )
        stale = self._repo.find_stale_running(claimed_before=cutoff)
        
        for job in stale:
            logger.warning(f"Recovering stale job {job.id} (worker: {job._claimed_by})")
            job.fail(f"Worker {job._claimed_by} died — requeued by recovery")
            # fail() will reschedule if retries remain
            self._repo.save(job)

## Step 4: Patterns Used

|Pattern|Where|Why|
|---|---|---|
|**Command**|`JobPayload` subclasses|Encapsulate executable work — serializable, retryable|
|**State**|`Job._status`|Enforce valid transitions (RUNNING→COMPLETED, FAILED→SCHEDULED)|
|**Strategy**|`JobExecutor`|Swap HTTP/Function/Queue execution without changing scheduler|
|**Observer**|`JobCompleted`, `JobFailed` events|Dependency chain, notifications, analytics decoupled|
|**Template Method**|`_process_due_jobs` → `_execute_job`|Fixed schedule loop, variable execution per job type|

---

## Step 5: Alternatives Rejected

|Alternative|Why Rejected|
|---|---|
|Single-process in-memory scheduler|Doesn't survive restarts, can't scale|
|DB polling with no locking|Multiple workers execute same job|
|Cron-only (no one-time jobs)|Insufficient for dynamic scheduling|
|Stateless job execution|Can't retry intelligently, no history|
