# Build Your Own: Feature Flag System

> **Revision tags:** #build-your-own #feature-flags  
> **Related:** [[03.18 - Feature Flags]]

---

## Goal

Build a feature flag evaluator that supports:
- On/off global flags
- Percentage rollouts (consistent per user — no flickering)
- User allowlist / blocklist
- Attribute-based targeting (e.g., plan == "enterprise")
- Local caching with TTL
- Flag definitions stored in JSON (simulating a config service)

---

## Core Design

```
[Flag Store] → JSON / config service → flag definitions
      │
[Flag Evaluator]
  For a given (flag_name, user_context):
    1. Check overrides (allowlist / blocklist)
    2. Evaluate rules in order (first match wins)
    3. Percentage rollout (hash-based, stable per user)
    4. Return default
      │
[Local Cache] → TTL-based, avoid network call per request
```

---

## Flag Definition Schema

```json
{
  "new_checkout_flow": {
    "enabled": true,
    "description": "New React checkout UI",
    "rules": [
      {
        "condition": {"attribute": "email", "operator": "ends_with", "value": "@mycompany.com"},
        "result": true
      },
      {
        "condition": {"attribute": "plan", "operator": "equals", "value": "enterprise"},
        "result": true
      },
      {
        "rollout_percent": 20,
        "result": true
      }

    "default": false
  },
  "maintenance_mode": {
    "enabled": true,
    "rules": [],
    "default": true
  }
}
```

## Implementation

```python
import hashlib
import json
import time
import threading
import logging
from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional

logger = logging.getLogger(__name__)


# ── User context ──────────────────────────────────────────────────────────────

@dataclass
class UserContext:
    """Attributes used for flag evaluation."""
    user_id: str
    email: Optional[str] = None
    plan: Optional[str] = None
    country: Optional[str] = None
    is_internal: bool = False
    extra: Dict[str, Any] = field(default_factory=dict)

    def get_attribute(self, name: str) -> Optional[Any]:
        """Retrieve an attribute by name, checking all fields."""
        if hasattr(self, name):
            return getattr(self, name)
        return self.extra.get(name)


# ── Rule evaluator ────────────────────────────────────────────────────────────

def evaluate_condition(condition: dict, context: UserContext) -> bool:
    """
    Evaluate a single targeting condition against a user context.
    Supported operators: equals, not_equals, contains, ends_with,
                         starts_with, in, not_in, is_true
    """
    attribute = condition.get("attribute")
    operator  = condition.get("operator")
    expected  = condition.get("value")

    actual = context.get_attribute(attribute)
    if actual is None:
        return False

    actual_str = str(actual).lower()
    expected_str = str(expected).lower() if expected is not None else ""

    if operator == "equals":
        return actual_str == expected_str
    elif operator == "not_equals":
        return actual_str != expected_str
    elif operator == "contains":
        return expected_str in actual_str
    elif operator == "ends_with":
        return actual_str.endswith(expected_str)
    elif operator == "starts_with":
        return actual_str.startswith(expected_str)
    elif operator == "in":
        return actual_str in [str(v).lower() for v in expected]
    elif operator == "not_in":
        return actual_str not in [str(v).lower() for v in expected]
    elif operator == "is_true":
        return bool(actual)
    else:
        logger.warning(f"Unknown operator: {operator}")
        return False


def rollout_bucket(user_id: str, flag_name: str) -> int:
    """
    Returns a stable 0-99 bucket for a user+flag combination.
    Same user always gets the same bucket for a given flag.
    Uses MD5 hash for uniform distribution.
    """
    hash_input = f"{flag_name}:{user_id}"
    digest = hashlib.md5(hash_input.encode()).hexdigest()
    return int(digest[:8], 16) % 100


# ── Flag definition ───────────────────────────────────────────────────────────

@dataclass
class FlagDefinition:
    name: str
    enabled: bool
    rules: List[dict]
    default: bool
    description: str = ""

    def evaluate(self, context: UserContext) -> bool:
        """
        Evaluate this flag for a given user context.
        Rules are evaluated in order; first match wins.
        """
        if not self.enabled:
            return False

        for rule in self.rules:
            # Attribute-based condition
            if "condition" in rule:
                if evaluate_condition(rule["condition"], context):
                    return rule["result"]

            # Percentage rollout
            elif "rollout_percent" in rule:
                bucket = rollout_bucket(context.user_id, self.name)
                if bucket < rule["rollout_percent"]:
                    return rule["result"]

        return self.default


# ── Cached flag store ─────────────────────────────────────────────────────────

class FlagStore:
    """
    Holds flag definitions with a local cache + TTL.
    In production, the _load_flags method would call a remote config service.
    """

    def __init__(self, source: str, cache_ttl: float = 30.0):
        """
        Args:
            source:    Path to JSON file (or URL to config service)
            cache_ttl: How long to cache flag definitions locally (seconds)
        """
        self._source = source
        self._cache_ttl = cache_ttl
        self._flags: Dict[str, FlagDefinition] = {}
        self._loaded_at: float = 0
        self._lock = threading.Lock()

        self._load_flags()

    def get_flag(self, name: str) -> Optional[FlagDefinition]:
        with self._lock:
            self._refresh_if_stale()
            return self._flags.get(name)

    def all_flags(self) -> Dict[str, FlagDefinition]:
        with self._lock:
            self._refresh_if_stale()
            return dict(self._flags)

    def _refresh_if_stale(self):
        if time.monotonic() - self._loaded_at > self._cache_ttl:
            self._load_flags()

    def _load_flags(self):
        """Load flag definitions from source (JSON file or config service)."""
        try:
            with open(self._source) as f:
                raw = json.load(f)

            self._flags = {
                name: FlagDefinition(
                    name=name,
                    enabled=definition.get("enabled", True),
                    rules=definition.get("rules", []),
                    default=definition.get("default", False),
                    description=definition.get("description", ""),
                )
                for name, definition in raw.items()
            }
            self._loaded_at = time.monotonic()
            logger.debug(f"[FlagStore] Loaded {len(self._flags)} flags from {self._source}")
        except Exception as e:
            logger.error(f"[FlagStore] Failed to load flags: {e}")
            # Keep stale flags — better than returning all defaults


# ── Feature flag client ───────────────────────────────────────────────────────

class FeatureFlags:
    """
    The main interface for flag evaluation.
    Wraps the store and provides a clean is_enabled() API.
    """

    def __init__(self, store: FlagStore):
        self._store = store
        self._evaluation_log: List[dict] = []

    def is_enabled(self, flag_name: str, context: UserContext,
                   default: bool = False) -> bool:
        """
        Evaluate a feature flag for a given user.

        Args:
            flag_name: The flag identifier
            context:   User attributes for targeting
            default:   Fallback if flag not found

        Returns:
            bool: Whether the feature is enabled for this user
        """
        flag = self._store.get_flag(flag_name)

        if flag is None:
            logger.warning(f"[FeatureFlags] Unknown flag: '{flag_name}', using default={default}")
            return default

        result = flag.evaluate(context)

        # Optionally log evaluations for analytics
        self._evaluation_log.append({
            "flag": flag_name,
            "user_id": context.user_id,
            "result": result,
            "timestamp": time.time()
        })

        return result

    def get_all_flags(self, context: UserContext) -> Dict[str, bool]:
        """Evaluate all flags for a given user (useful for frontend bootstrapping)."""
        return {
            name: flag.evaluate(context)
            for name, flag in self._store.all_flags().items()
        }
```

## Usage

```python
import json, tempfile, os

# Create a sample flag config file
flags_config = {
    "new_checkout_flow": {
        "enabled": True,
        "description": "New checkout UI experiment",
        "rules": [
            {"condition": {"attribute": "is_internal", "operator": "is_true"}, "result": True},
            {"condition": {"attribute": "plan", "operator": "equals", "value": "enterprise"}, "result": True},
            {"rollout_percent": 20, "result": True}
        ],
        "default": False
    },
    "dark_mode": {
        "enabled": True,
        "rules": [{"rollout_percent": 50, "result": True}],
        "default": False
    },
    "maintenance_mode": {
        "enabled": False,
        "rules": [],
        "default": False
    }
}

with tempfile.NamedTemporaryFile(mode="w", suffix=".json", delete=False) as f:
    json.dump(flags_config, f)
    config_path = f.name

store = FlagStore(source=config_path, cache_ttl=30.0)
flags = FeatureFlags(store)

# Internal user — always gets new_checkout_flow
internal_user = UserContext(user_id="user:1", email="dev@mycompany.com", is_internal=True)
print(flags.is_enabled("new_checkout_flow", internal_user))   # True

# Enterprise user — always gets it
enterprise_user = UserContext(user_id="user:2", plan="enterprise")
print(flags.is_enabled("new_checkout_flow", enterprise_user)) # True

# Free user — depends on their 0–99 bucket
free_user = UserContext(user_id="user:999")
bucket = rollout_bucket("user:999", "new_checkout_flow")
print(f"Bucket: {bucket} → {'enabled' if bucket < 20 else 'disabled'}")

# All flags for a user (for frontend bootstrap)
all_flags = flags.get_all_flags(free_user)
print(all_flags)
# {'new_checkout_flow': False, 'dark_mode': True, 'maintenance_mode': False}

# Cleanup
os.unlink(config_path)
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Remote config service | We load from file; production pulls from LaunchDarkly/Unleash API |
| Streaming updates | LaunchDarkly SDK receives flag changes in < 200ms via SSE |
| Evaluation analytics | Track exposure counts per variant for A/B significance testing |
| Kill switch API | One-click disable of any flag via CLI or UI |
| Audit log | Who changed which flag, when, with before/after values |
| Multi-variate flags | String/number variants, not just boolean |
| SDK for multiple languages | TypeScript, Go, Java SDKs with consistent evaluation |
| Context propagation | Evaluate once at request entry, pass result downstream |

---

## Key Takeaways

- `hash(user_id + flag_name) % 100` is the entire rollout mechanism — simple and stable
- Rules are ordered — first match wins; put most specific rules first
- The cache TTL is the propagation delay tradeoff — 30s lag vs network call per request
- `is_enabled()` must never throw — flags are always evaluated with a safe default
- Local evaluation (vs network call per check) is what makes flags fast enough to use everywhere
