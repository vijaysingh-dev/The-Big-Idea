# Neural Networks Intuition

## Why This Matters for AI Engineers

You don't need to implement backprop from scratch, but you need enough intuition to:

- Understand why models behave a certain way
- Debug when something goes wrong (why does the model fail on this input?)
- Make informed decisions about fine-tuning vs prompting
- Read architecture papers without being completely lost

---

## What a Neural Network Actually Is

A neural network is a **function approximator**. Given input X, it learns to produce output Y by adjusting millions of numerical parameters (weights) through exposure to examples.

The key insight: **it learns the mapping, not the rules**. You don't code "if the email says 'discount', it's spam." The network figures out the pattern from millions of examples.

---

## Building Up Intuition

### Step 1: A Single Neuron

A neuron takes N inputs, multiplies each by a weight, sums them, adds a bias, and passes through an activation function:

```
output = activation(w1*x1 + w2*x2 + ... + wN*xN + bias)
```

In Python terms:

```python
# A single neuron
def neuron(inputs, weights, bias):
    # Weighted sum
    z = sum(w * x for w, x in zip(weights, inputs)) + bias
    # Activation (e.g., ReLU)
    return max(0, z)
```

The **activation function** introduces non-linearity. Without it, no matter how many layers you stack, you just get a linear function — which can't represent complex patterns.

Common activations:

- **ReLU**: `max(0, x)` — default for hidden layers; simple, fast
- **Sigmoid**: `1/(1+e^-x)` → squashes to [0,1]; used for binary output
- **Softmax**: normalizes outputs to a probability distribution; used for classification

### Step 2: Layers

Stack neurons in layers. Each layer's output becomes the next layer's input:

```
Input Layer → Hidden Layer 1 → Hidden Layer 2 → Output Layer
[x1, x2, x3]   [h1...h64]      [h1...h32]      [y1...y10]
```

Early layers learn simple features (edges, word patterns). Later layers learn complex combinations (faces, sentence meaning). This is called **hierarchical feature learning** — one of the core reasons deep learning works.

### Step 3: Forward Pass

Computing the output for a given input by passing data through all layers:

```python
# Simplified forward pass
def forward(x, weights_list, biases_list):
    activation = x
    for W, b in zip(weights_list, biases_list):
        # Matrix multiply + bias + ReLU
        activation = relu(activation @ W + b)
    return activation
```

### Step 4: Loss Function

After the forward pass, compare the output to the correct answer using a **loss function**. Loss measures "how wrong" the network is:

- **Cross-entropy loss**: for classification (most LLM training)
- **MSE**: for regression (predicting a number)

The network's goal is to minimize loss.

### Step 5: Backpropagation

The mechanism by which the network learns. It works backward through the network, computing how much each weight contributed to the loss, then adjusting weights to reduce the loss:

```
Loss
 │
 ▼
Compute gradient of loss w.r.t. each weight  ← chain rule
 │
 ▼
Update each weight: w = w - lr * gradient     ← gradient descent
```

`lr` is the **learning rate** — how big a step to take. Too large = unstable training. Too small = learns very slowly.

---

## What Weights Encode

After training, the weights of the network encode learned patterns. For language models:

- Early layers: syntax, word form patterns
- Middle layers: semantic relationships, facts
- Later layers: task-specific behavior, reasoning patterns

This is why **fine-tuning works**: the base model has already learned language; you're just adjusting later layers to specialize behavior.

## Key Concepts for AI Engineers

|Concept|What it means in practice|
|---|---|
|**Parameters / weights**|The model's "knowledge" — what gets loaded into GPU memory|
|**Gradient**|Direction to adjust weights to reduce loss|
|**Overfitting**|Model memorizes training data, fails on new data|
|**Underfitting**|Model too simple to capture the pattern|
|**Batch size**|How many examples processed per gradient update|
|**Epochs**|How many times the full dataset is seen during training|
|**Inference**|Running a trained model on new input (no weight updates)|

## Why LLMs are Neural Networks

LLMs are very large neural networks trained on text. The "language model" objective during pretraining is:

> Given the preceding tokens, predict the next token.

This seemingly simple objective, applied across hundreds of billions of tokens, forces the network to learn grammar, facts, reasoning, and world knowledge — because the only way to predict the next word well is to understand everything that came before.

The specific architecture used is the **Transformer** — covered in depth in [[02.3 - Transformer Architecture]].
