## Goal

Build an LRU cache with TTL support from scratch — no external dependencies. Then extend it to a write-through cache with a backing store, to understand how application-layer caches actually work.

## Part 1: LRU Cache with TTL

### Core Design

```
Data structure: doubly-linked list + hash map
  - Hash map: O(1) lookup by key
  - Linked list: O(1) move-to-front (mark as recently used)
  - Eviction: remove from tail (least recently used)

TTL: store expiry timestamp with each entry
  - On get: check if expired → treat as cache miss, remove entry
  - Background reaper: periodically remove expired entries
```

```python
import threading
import time
from collections import OrderedDict
from typing import Any, Optional, Callable

# ── Cache Entry ───────────────────────────────────────────────────────────────

class CacheEntry:
    __slots__ = ('value', 'expires_at')

    def __init__(self, value: Any, ttl: Optional[float]):
        self.value = value
        self.expires_at = (time.monotonic() + ttl) if ttl else None

    def is_expired(self) -> bool:
        if self.expires_at is None:
            return False
        return time.monotonic() > self.expires_at


# ── LRU Cache with TTL ────────────────────────────────────────────────────────

class LRUCache:
    """
    Thread-safe LRU cache with optional per-entry TTL.
    Uses OrderedDict as the linked hash map (Python's OrderedDict
    maintains insertion order and supports O(1) move_to_end).
    """

    def __init__(self, capacity: int, default_ttl: Optional[float] = None,
                 reap_interval: float = 60.0):
        self.capacity = capacity
        self.default_ttl = default_ttl
        self._store: OrderedDict[str, CacheEntry] = OrderedDict()
        self._lock = threading.Lock()

        # Stats
        self._hits = 0
        self._misses = 0
        self._evictions = 0

        # Background TTL reaper
        if reap_interval > 0:
            self._reaper = threading.Thread(
                target=self._reap_loop,
                args=(reap_interval,),
                daemon=True
            )
            self._reaper.start()

    # ── Core operations ───────────────────────────────────────────────────────

    def get(self, key: str) -> Optional[Any]:
        """
        Retrieve a value. Returns None on miss or expiry.
        Moves entry to front (marks as recently used).
        """
        with self._lock:
            entry = self._store.get(key)

            if entry is None:
                self._misses += 1
                return None

            if entry.is_expired():
                del self._store[key]
                self._misses += 1
                return None

            # Move to end = most recently used
            self._store.move_to_end(key)
            self._hits += 1
            return entry.value

    def set(self, key: str, value: Any,
            ttl: Optional[float] = None) -> None:
        """
        Insert or update a key.
        Evicts least recently used entry if at capacity.
        """
        effective_ttl = ttl if ttl is not None else self.default_ttl

        with self._lock:
            if key in self._store:
                # Update existing — move to front
                self._store.move_to_end(key)
                self._store[key] = CacheEntry(value, effective_ttl)
            else:
                # New entry — evict LRU if full
                if len(self._store) >= self.capacity:
                    evicted_key, _ = self._store.popitem(last=False)
                    self._evictions += 1

                self._store[key] = CacheEntry(value, effective_ttl)

    def delete(self, key: str) -> bool:
        """Explicitly remove a key. Returns True if it existed."""
        with self._lock:
            if key in self._store:
                del self._store[key]
                return True
            return False

    def exists(self, key: str) -> bool:
        """Check if key exists and is not expired."""
        return self.get(key) is not None

    def clear(self):
        with self._lock:
            self._store.clear()

    # ── Stats & introspection ─────────────────────────────────────────────────

    @property
    def size(self) -> int:
        with self._lock:
            return len(self._store)

    @property
    def hit_rate(self) -> float:
        total = self._hits + self._misses
        return (self._hits / total) if total > 0 else 0.0

    def stats(self) -> dict:
        return {
            "size": self.size,
            "capacity": self.capacity,
            "hits": self._hits,
            "misses": self._misses,
            "evictions": self._evictions,
            "hit_rate": f"{self.hit_rate:.1%}"
        }

    # ── TTL reaper ────────────────────────────────────────────────────────────

    def _reap_loop(self, interval: float):
        """
        Background thread: periodically removes expired entries.
        Prevents memory leak from entries that are never accessed after expiry.
        """
        while True:
            time.sleep(interval)
            with self._lock:
                expired = [
                    k for k, v in self._store.items()
                    if v.is_expired()
                ]
                for k in expired:
                    del self._store[k]
```

## Part 2: Cache-Aside with Backing Store

Wraps the LRU cache with cache-aside logic — transparently fetches from source on miss.

```python
class CacheAsideStore:
    """
    Cache-aside (lazy loading) pattern.
    On cache miss: fetches from backing store, populates cache.
    On write: writes through to backing store AND invalidates cache.
    """

    def __init__(self, cache: LRUCache,
                 fetch_fn: Callable[[str], Any],
                 default_ttl: float = 300.0):
        """
        Args:
            cache:       LRU cache instance
            fetch_fn:    Function to fetch value from backing store (e.g., DB)
            default_ttl: How long to cache fetched values
        """
        self._cache = cache
        self._fetch = fetch_fn
        self._ttl = default_ttl
        self._pending: dict = {}     # in-flight fetches (stampede prevention)
        self._pending_lock = threading.Lock()

    def get(self, key: str) -> Optional[Any]:
        """
        Get a value. Cache hit: return immediately.
        Cache miss: fetch from backing store, cache result.
        """
        # Fast path: cache hit
        value = self._cache.get(key)
        if value is not None:
            return value

        # Cache miss: prevent stampede — only one fetch per key at a time
        with self._pending_lock:
            if key in self._pending:
                event = self._pending[key]
            else:
                event = threading.Event()
                self._pending[key] = event
                event = None   # signal: we are the fetcher

        if event is not None:
            # Another thread is fetching this key — wait for it
            event.wait(timeout=5.0)
            return self._cache.get(key)

        # We are the fetcher
        try:
            value = self._fetch(key)
            if value is not None:
                self._cache.set(key, value, ttl=self._ttl)
            return value
        finally:
            with self._pending_lock:
                done_event = self._pending.pop(key, None)
            if done_event:
                done_event.set()   # wake up waiting threads

    def invalidate(self, key: str):
        """Invalidate a cache entry (e.g., after a write to the backing store)."""
        self._cache.delete(key)

    def set_and_invalidate(self, key: str, write_fn: Callable, *args, **kwargs):
        """
        Write-through helper: call write_fn (DB write), then invalidate cache.
        Next read will fetch fresh data from DB.
        """
        write_fn(*args, **kwargs)
        self.invalidate(key)
```

## Usage

```python
# ── Standalone LRU cache ──────────────────────────────────────────────────────
cache = LRUCache(capacity=1000, default_ttl=300.0)

cache.set("user:42", {"name": "Vijay", "email": "v@example.com"})
cache.set("user:43", {"name": "Alice"}, ttl=60.0)   # custom TTL

user = cache.get("user:42")   # hit
missing = cache.get("user:99") # miss → None

print(cache.stats())
# {'size': 2, 'capacity': 1000, 'hits': 1, 'misses': 1,
#  'evictions': 0, 'hit_rate': '50.0%'}


# ── Cache-aside with DB ───────────────────────────────────────────────────────
def fetch_user_from_db(key: str) -> dict:
    user_id = key.split(":")[1]
    # Simulate DB query
    return db.query("SELECT * FROM users WHERE id = ?", user_id)

lru = LRUCache(capacity=10_000, default_ttl=300.0)
user_cache = CacheAsideStore(lru, fetch_fn=fetch_user_from_db)

# First call: cache miss → DB fetch → cached
user = user_cache.get("user:42")

# Second call: cache hit → no DB
user = user_cache.get("user:42")

# After update: invalidate
def update_user_in_db(user_id, data):
    db.execute("UPDATE users SET ...", user_id, data)

user_cache.set_and_invalidate(
    "user:42",
    update_user_in_db, 42, {"name": "Updated Name"}
)
```

## Verifying LRU Eviction

```python
cache = LRUCache(capacity=3)
cache.set("a", 1)
cache.set("b", 2)
cache.set("c", 3)

cache.get("a")   # access "a" → moves to front
cache.set("d", 4)  # capacity exceeded → evicts LRU = "b"

print(cache.get("a"))  # 1   ✅
print(cache.get("b"))  # None ✅ (evicted)
print(cache.get("c"))  # 3   ✅
print(cache.get("d"))  # 4   ✅
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Distributed cache | Our cache is per-process; Redis is the shared version |
| Serialization | Redis stores bytes; need to serialize/deserialize objects |
| Write-through | Writes update cache AND backing store simultaneously |
| Read-through | Cache fetches from backing store automatically (our cache-aside does this) |
| Cache warming | Pre-populate cache on startup to avoid cold-start stampede |
| Metrics export | Hit rate, eviction rate, memory usage exposed to Prometheus |
| Sharded cache | Consistent hashing across multiple cache nodes |
| Eviction policies | Redis supports LRU, LFU, allkeys-random, volatile-ttl |

## Key Takeaways

- LRU = OrderedDict: O(1) get/set/evict using Python's built-in
- TTL check happens at read time — lazy expiration is sufficient for most cases
- The reaper prevents memory accumulation from keys that are written but never read again
- Stampede prevention (the `_pending` event map) is critical for high-concurrency caches
- The cache-aside wrapper is where real application logic lives — the LRU is just storage
