# Case Study: Workflow Engine

**Difficulty:** Hard | **Patterns:** State, Chain of Responsibility, Command, Observer, Strategy, Template Method

---

## Step 1: Requirements

### Functional

- Define workflows as a sequence of steps (nodes)
- Support: sequential, parallel, conditional branching, loops
- Step types: HTTP call, Function execution, Wait/delay, Human approval, Sub-workflow
- Each step can have retries, timeouts, compensations
- Pause and resume workflows (human-in-the-loop)
- Workflow versioning (don't break in-flight instances when definition changes)
- Full audit trail: which step ran, when, with what input/output
- Trigger workflows from API, scheduler, or events

### Non-Functional

- A workflow step executes within 5s of becoming ready
- 10K concurrent workflow instances
- Durable: survive restarts (DB-persisted state)
- Exactly-once step execution

---

## Step 2: Core Abstractions

```
WorkflowDefinition  → the blueprint (steps, transitions, version)
WorkflowInstance    → a running execution of a definition
StepDefinition      → configuration of one step in a workflow
StepExecution       → runtime record of one step's execution
Transition          → condition-based edge from one step to next
WorkflowContext     → shared data bag passed between steps
```

---

## Step 3: State Machines

```
WorkflowInstance:
  PENDING ──[start()]──▶ RUNNING
  RUNNING ──[all steps done]──▶ COMPLETED
          ──[step fails, no retry]──▶ FAILED
          ──[human approval needed]──▶ WAITING
          ──[cancel()]──▶ CANCELLED
  WAITING ──[approved/resumed]──▶ RUNNING
  COMPLETED, FAILED, CANCELLED → terminal

StepExecution:
  PENDING ──[worker claims]──▶ RUNNING
  RUNNING ──[success]──▶ COMPLETED
          ──[failure, retry available]──▶ PENDING (retry with delay)
          ──[failure, max retries]──▶ FAILED
          ──[timeout]──▶ TIMED_OUT → PENDING (retry) or FAILED
  COMPLETED, FAILED, TIMED_OUT → terminal per execution
```

```python
# workflow_definition.py
from dataclasses import dataclass, field
from typing import Optional, List, Any
from uuid import UUID, uuid4
from enum import Enum

class StepType(Enum):
    HTTP_CALL  = "http_call"
    FUNCTION   = "function"
    WAIT       = "wait"
    APPROVAL   = "approval"
    PARALLEL   = "parallel"
    CONDITION  = "condition"
    SUB_WORKFLOW = "sub_workflow"

@dataclass
class RetryConfig:
    max_attempts: int = 3
    backoff_seconds: int = 60
    backoff_multiplier: float = 2.0
    max_backoff_seconds: int = 3600
    retryable_errors: List[str] = field(default_factory=lambda: ["TransientError", "TimeoutError"])
    
    def next_delay(self, attempt: int) -> int:
        delay = self.backoff_seconds * (self.backoff_multiplier ** (attempt - 1))
        return int(min(delay, self.max_backoff_seconds))

@dataclass
class StepDefinition:
    step_id: str                     # unique within workflow, e.g. "validate_payment"
    name: str
    step_type: StepType
    config: dict                     # type-specific config (url, function name, etc.)
    retry: RetryConfig = field(default_factory=RetryConfig)
    timeout_seconds: int = 300
    compensation_step_id: Optional[str] = None   # step to run if this fails after commit
    on_success: Optional[str] = None             # next step_id
    on_failure: Optional[str] = None             # step_id or "fail_workflow"
    condition: Optional[str] = None              # Python expression for CONDITION type

@dataclass
class WorkflowDefinition:
    definition_id: UUID
    name: str
    version: int
    steps: List[StepDefinition]
    start_step_id: str
    
    def get_step(self, step_id: str) -> Optional[StepDefinition]:
        return next((s for s in self.steps if s.step_id == step_id), None)
    
    def get_next_step(self, current_step_id: str,
                      outcome: str, context: dict) -> Optional[str]:
        step = self.get_step(current_step_id)
        if not step:
            return None
        
        if step.step_type == StepType.CONDITION:
            return self._evaluate_condition(step, context)
        
        if outcome == "success":
            return step.on_success
        else:
            return step.on_failure
    
    def _evaluate_condition(self, step: StepDefinition, context: dict) -> str:
        """Evaluate Python condition expression safely."""
        try:
            result = eval(step.condition, {"ctx": context})   # type: ignore
            return step.on_success if result else step.on_failure
        except Exception as e:
            raise WorkflowDefinitionError(f"Condition evaluation failed: {e}")


# workflow_instance.py — Aggregate
from datetime import datetime
from enum import Enum

class WorkflowStatus(Enum):
    PENDING    = "PENDING"
    RUNNING    = "RUNNING"
    WAITING    = "WAITING"      # waiting for human approval or external event
    COMPLETED  = "COMPLETED"
    FAILED     = "FAILED"
    CANCELLED  = "CANCELLED"

class StepStatus(Enum):
    PENDING   = "PENDING"
    RUNNING   = "RUNNING"
    COMPLETED = "COMPLETED"
    FAILED    = "FAILED"
    SKIPPED   = "SKIPPED"
    TIMED_OUT = "TIMED_OUT"

@dataclass
class StepExecution:
    execution_id: UUID = field(default_factory=uuid4)
    instance_id: UUID = None
    step_id: str = ""
    attempt_number: int = 1
    status: StepStatus = StepStatus.PENDING
    input_data: dict = field(default_factory=dict)
    output_data: dict = field(default_factory=dict)
    error: Optional[str] = None
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    worker_id: Optional[str] = None
    next_retry_at: Optional[datetime] = None


class WorkflowInstance:
    """
    Running execution of a WorkflowDefinition.
    Stores all context and execution history.
    """
    
    def __init__(self, instance_id: UUID, definition_id: UUID,
                 definition_version: int, trigger_data: dict):
        self.id = instance_id
        self.definition_id = definition_id
        self.definition_version = definition_version
        self._status = WorkflowStatus.PENDING
        self._context: dict = dict(trigger_data)   # shared mutable data bag
        self._current_step_id: Optional[str] = None
        self._step_executions: List[StepExecution] = []
        self._events = []
        self.created_at = datetime.now()
        self.completed_at: Optional[datetime] = None
    
    @property
    def status(self) -> WorkflowStatus: return self._status
    @property
    def context(self) -> dict: return dict(self._context)
    @property
    def current_step_id(self) -> Optional[str]: return self._current_step_id
    
    def start(self, first_step_id: str):
        if self._status != WorkflowStatus.PENDING:
            raise InvalidStateTransition("Workflow already started")
        self._status = WorkflowStatus.RUNNING
        self._current_step_id = first_step_id
        self._create_step_execution(first_step_id)
        self._events.append(WorkflowStarted(instance_id=self.id))
    
    def begin_step(self, step_id: str, worker_id: str) -> StepExecution:
        execution = self._get_pending_execution(step_id)
        execution.status = StepStatus.RUNNING
        execution.started_at = datetime.now()
        execution.worker_id = worker_id
        self._events.append(StepStarted(instance_id=self.id, step_id=step_id))
        return execution
    
    def complete_step(self, step_id: str, output: dict, next_step_id: Optional[str]):
        execution = self._get_running_execution(step_id)
        execution.status = StepStatus.COMPLETED
        execution.output_data = output
        execution.completed_at = datetime.now()
        
        # Merge step output into shared context
        self._context.update(output)
        
        self._events.append(StepCompleted(instance_id=self.id, step_id=step_id, output=output))
        
        if next_step_id:
            self._current_step_id = next_step_id
            self._create_step_execution(next_step_id)
        else:
            self._complete_workflow()
    
    def fail_step(self, step_id: str, error: str,
                  retry_at: Optional[datetime] = None):
        execution = self._get_running_execution(step_id)
        execution.error = error
        execution.completed_at = datetime.now()
        
        if retry_at:
            execution.status = StepStatus.FAILED
            # Create a new pending execution for the retry
            new_execution = StepExecution(
                instance_id=self.id, step_id=step_id,
                attempt_number=execution.attempt_number + 1,
                next_retry_at=retry_at
            )
            self._step_executions.append(new_execution)
            self._events.append(StepRetryScheduled(
                instance_id=self.id, step_id=step_id, retry_at=retry_at
            ))
        else:
            execution.status = StepStatus.FAILED
            self._status = WorkflowStatus.FAILED
            self.completed_at = datetime.now()
            self._events.append(WorkflowFailed(
                instance_id=self.id, step_id=step_id, error=error
            ))
    
    def wait_for_approval(self, step_id: str, approver_role: str):
        """Pause workflow pending human approval."""
        self._status = WorkflowStatus.WAITING
        self._events.append(WorkflowWaitingForApproval(
            instance_id=self.id, step_id=step_id, approver_role=approver_role
        ))
    
    def resume(self, approved: bool, approved_by: str,
               next_step_id: Optional[str], fail_step_id: Optional[str] = None):
        if self._status != WorkflowStatus.WAITING:
            raise InvalidStateTransition("Workflow is not waiting")
        
        self._status = WorkflowStatus.RUNNING
        
        if approved and next_step_id:
            self._current_step_id = next_step_id
            self._create_step_execution(next_step_id)
            self._events.append(WorkflowResumed(instance_id=self.id, approved_by=approved_by))
        else:
            self._status = WorkflowStatus.FAILED
            self.completed_at = datetime.now()
            self._events.append(WorkflowFailed(
                instance_id=self.id,
                step_id=self._current_step_id,
                error=f"Rejected by {approved_by}"
            ))
    
    def cancel(self, reason: str):
        if self._status in (WorkflowStatus.COMPLETED, WorkflowStatus.FAILED):
            raise InvalidStateTransition("Cannot cancel terminal workflow")
        self._status = WorkflowStatus.CANCELLED
        self.completed_at = datetime.now()
        self._events.append(WorkflowCancelled(instance_id=self.id, reason=reason))
    
    def get_step_executions(self) -> List[StepExecution]:
        return list(self._step_executions)
    
    def get_events(self): return list(self._events)
    def clear_events(self): self._events.clear()
    
    def _complete_workflow(self):
        self._status = WorkflowStatus.COMPLETED
        self._current_step_id = None
        self.completed_at = datetime.now()
        self._events.append(WorkflowCompleted(instance_id=self.id, context=self._context))
    
    def _create_step_execution(self, step_id: str):
        self._step_executions.append(StepExecution(
            instance_id=self.id, step_id=step_id
        ))
    
    def _get_pending_execution(self, step_id: str) -> StepExecution:
        return self._find_execution(step_id, StepStatus.PENDING)
    
    def _get_running_execution(self, step_id: str) -> StepExecution:
        return self._find_execution(step_id, StepStatus.RUNNING)
    
    def _find_execution(self, step_id: str, status: StepStatus) -> StepExecution:
        ex = next((e for e in reversed(self._step_executions)
                   if e.step_id == step_id and e.status == status), None)
        if not ex:
            raise StepExecutionNotFound(step_id, status)
        return ex


# step_executors.py — Strategy: one executor per StepType
class StepExecutor(ABC):
    @abstractmethod
    def can_execute(self, step_type: StepType) -> bool: pass
    
    @abstractmethod
    def execute(self, step: StepDefinition, context: dict) -> dict:
        """Returns output dict to merge into context."""
        pass

class HttpCallExecutor(StepExecutor):
    def can_execute(self, t): return t == StepType.HTTP_CALL
    
    def execute(self, step, context):
        import requests, json
        cfg = step.config
        url = cfg["url"].format(**context)  # e.g. "https://api.x.com/orders/{order_id}"
        method = cfg.get("method", "POST")
        body = {k: context.get(v, v) for k, v in cfg.get("body_map", {}).items()}
        
        resp = requests.request(method, url, json=body,
                                headers=cfg.get("headers", {}),
                                timeout=step.timeout_seconds)
        resp.raise_for_status()
        return {"http_status": resp.status_code, **resp.json()}

class FunctionExecutor(StepExecutor):
    def can_execute(self, t): return t == StepType.FUNCTION
    
    def execute(self, step, context):
        import importlib
        mod = importlib.import_module(step.config["module"])
        fn = getattr(mod, step.config["function"])
        return fn(context) or {}

class WaitExecutor(StepExecutor):
    """Schedules a delayed continuation — does not block the worker."""
    def can_execute(self, t): return t == StepType.WAIT
    
    def execute(self, step, context):
        delay = step.config.get("seconds", 0)
        # Signal the engine to re-schedule this step after delay
        raise WaitRequested(delay_seconds=delay)

class ApprovalExecutor(StepExecutor):
    def __init__(self, notification_service):
        self._notifier = notification_service
    
    def can_execute(self, t): return t == StepType.APPROVAL
    
    def execute(self, step, context):
        role = step.config["approver_role"]
        self._notifier.send_approval_request(
            role=role,
            instance_id=context.get("instance_id"),
            step_id=step.step_id,
            data=context
        )
        raise ApprovalRequested(approver_role=role)


# workflow_engine.py — Orchestrator (Template Method for run loop)
class WorkflowEngine:
    """
    Claims and executes ready step executions from the DB.
    Template Method: fixed engine loop, variable step execution.
    """
    
    def __init__(self, instance_repo, definition_repo,
                 executors: List[StepExecutor], event_bus,
                 redis_client, worker_id: str):
        self._instances = instance_repo
        self._definitions = definition_repo
        self._executors = executors
        self._bus = event_bus
        self._redis = redis_client
        self._worker_id = worker_id
    
    def run_cycle(self):
        """Main loop iteration: find ready steps, execute them."""
        ready = self._instances.find_instances_with_ready_steps(limit=20)
        for instance in ready:
            self._process_instance(instance)
    
    def _process_instance(self, instance: WorkflowInstance):
        step_id = instance.current_step_id
        if not step_id:
            return
        
        # Distributed lock: one worker per instance
        lock_key = f"wf:lock:{instance.id}"
        if not self._redis.set(lock_key, self._worker_id, nx=True, ex=120):
            return
        
        try:
            definition = self._definitions.get(
                instance.definition_id, instance.definition_version
            )
            step_def = definition.get_step(step_id)
            if not step_def:
                return
            
            executor = self._find_executor(step_def.step_type)
            if not executor:
                instance.fail_step(step_id, f"No executor for {step_def.step_type}")
                self._save_and_publish(instance)
                return
            
            instance.begin_step(step_id, self._worker_id)
            self._instances.save(instance)
            
            self._execute_step(instance, step_def, executor, definition)
        finally:
            self._redis.delete(lock_key)
    
    def _execute_step(self, instance: WorkflowInstance, step: StepDefinition,
                      executor: StepExecutor, definition: WorkflowDefinition):
        """Execute one step and handle all outcomes."""
        try:
            output = executor.execute(step, instance.context)
            next_step = definition.get_next_step(step.step_id, "success", instance.context)
            instance.complete_step(step.step_id, output, next_step)
        
        except ApprovalRequested as e:
            instance.wait_for_approval(step.step_id, e.approver_role)
        
        except WaitRequested as e:
            from datetime import timedelta
            retry_at = datetime.now() + timedelta(seconds=e.delay_seconds)
            # Re-queue the same step to run after delay
            instance.fail_step(step.step_id, "wait", retry_at=retry_at)
        
        except Exception as e:
            self._handle_step_failure(instance, step, e, definition)
        
        finally:
            self._save_and_publish(instance)
    
    def _handle_step_failure(self, instance: WorkflowInstance,
                             step: StepDefinition, error: Exception,
                             definition: WorkflowDefinition):
        current_executions = [
            ex for ex in instance.get_step_executions()
            if ex.step_id == step.step_id
        ]
        attempt = len(current_executions)
        error_type = type(error).__name__
        
        can_retry = (
            attempt < step.retry.max_attempts
            and error_type in step.retry.retryable_errors
        )
        
        if can_retry:
            delay = step.retry.next_delay(attempt)
            from datetime import timedelta
            retry_at = datetime.now() + timedelta(seconds=delay)
            instance.fail_step(step.step_id, str(error), retry_at=retry_at)
        else:
            # Check if there's an on_failure path
            next_on_fail = definition.get_next_step(step.step_id, "failure", instance.context)
            if next_on_fail and next_on_fail != "fail_workflow":
                instance.fail_step(step.step_id, str(error))
                instance.complete_step(step.step_id, {}, next_on_fail)
            else:
                instance.fail_step(step.step_id, str(error), retry_at=None)
    
    def _find_executor(self, step_type: StepType) -> Optional[StepExecutor]:
        return next((e for e in self._executors if e.can_execute(step_type)), None)
    
    def _save_and_publish(self, instance: WorkflowInstance):
        self._instances.save(instance)
        for event in instance.get_events():
            self._bus.publish(event)
        instance.clear_events()
    
    # ── Public API for workflow management ───────────────────
    
    def trigger(self, definition_name: str, version: int = None,
                trigger_data: dict = None) -> WorkflowInstance:
        """Start a new workflow instance."""
        definition = self._definitions.get_latest(definition_name, version)
        
        instance = WorkflowInstance(
            instance_id=uuid4(),
            definition_id=definition.definition_id,
            definition_version=definition.version,
            trigger_data=trigger_data or {}
        )
        instance.start(definition.start_step_id)
        self._save_and_publish(instance)
        return instance
    
    def approve(self, instance_id: UUID, approved: bool, approved_by: str):
        """Resume a workflow waiting for human approval."""
        instance = self._instances.get_or_raise(instance_id)
        definition = self._definitions.get(
            instance.definition_id, instance.definition_version
        )
        step = definition.get_step(instance.current_step_id)
        
        if approved:
            next_step = step.on_success
            instance.resume(True, approved_by, next_step)
        else:
            instance.resume(False, approved_by, None)
        
        self._save_and_publish(instance)
    
    def cancel(self, instance_id: UUID, reason: str):
        instance = self._instances.get_or_raise(instance_id)
        instance.cancel(reason)
        self._save_and_publish(instance)
```

## Step 6: Patterns Used

|Pattern|Where|Why|
|---|---|---|
|**State**|`WorkflowInstance._status`, `StepExecution.status`|Complex lifecycle with guarded transitions|
|**Command**|`StepDefinition` config + `StepExecutor.execute()`|Each step is a serializable, retryable unit of work|
|**Chain of Responsibility**|Compensation steps in `on_failure` chain|Failure triggers cleanup chain|
|**Strategy**|`StepExecutor` per `StepType`|HTTP, Function, Approval all interchangeable|
|**Template Method**|`WorkflowEngine.run_cycle`|Fixed engine loop, variable step execution|
|**Observer**|Domain events via `event_bus`|Monitoring, alerts, external triggers decoupled|

## Step 7: Alternatives Rejected

|Alternative|Why Rejected|
|---|---|
|In-memory state machine|Doesn't survive restarts — not durable|
|Hardcoded workflow per use case|Can't reuse engine; every workflow = new code|
|Blocking HTTP at each step|Worker threads held; doesn't scale to 10K instances|
|Single step-type handler|Can't add new step types without modifying engine|
