# Parameters and Arguments

#python #functions #fundamentals

> **In one line:** Python matches arguments to parameters in a fixed order (positional, then `*args`, then keyword, then `**kwargs`), and `/` and `*` let you force how callers pass them. Default values are evaluated once, when `def` runs, which is the most famous trap in the language.

---

## The Full Signature

```python
def f(a, b, /, c, d=4, *args, e, f=6, **kwargs):
    ...
#     │  │   │  │  │     │      │  │      └─ extra keyword args → dict
#     │  │   │  │  │     │      └──┴──────── keyword-only (after * or *args)
#     │  │   │  │  │     └─────────────────── extra positional args → tuple
#     │  │   │  └──┴───────────────────────── positional-or-keyword
#     └──┴───┴──────────────────────────────── positional-only (before /)
```

| Kind | Caller can pass | Why you would use it |
|---|---|---|
| **Positional-only** (`/`, 3.8+) | Only by position | The name is meaningless or may change: `len(obj)`, `pow(x, y)`. Frees the name for `**kwargs`. |
| Positional-or-keyword | Either | The default |
| **Keyword-only** (after `*`) | Only by name | Booleans and options: `sort(key=..., reverse=True)`. Makes call sites readable and safe to reorder. |
| `*args` | Any number of extra positionals | Wrappers, variadic functions |
| `**kwargs` | Any number of extra keywords | Wrappers, forwarding options |

💡 **Make flags keyword-only.** `send(msg, True, False)` is unreadable and fragile. `send(msg, *, retry=True, urgent=False)` forces `send(msg, retry=True)`. This is the single most useful signature habit for API design.

```python
def connect(host, port=5432, *, timeout=10.0, ssl=True): ...

connect("db", 5432, 5.0)          # TypeError — timeout must be named
connect("db", timeout=5.0)        # clear
```

## How Arguments Are Bound

1. Positional arguments fill parameters left to right.
2. Extra positionals go into `*args` (or raise `TypeError` if there is none).
3. Keyword arguments fill parameters by name.
4. Unknown keywords go into `**kwargs` (or raise).
5. Missing parameters use defaults (or raise).

```python
def f(a, b=2, *args, c, **kw):
    return a, b, args, c, kw

f(1, c=3)                    # (1, 2, (), 3, {})
f(1, 5, 6, 7, c=3, z=9)      # (1, 5, (6, 7), 3, {'z': 9})
```

### Unpacking at the call site

```python
args = (1, 2)
opts = {"timeout": 5}
connect(*args, **opts)

first, *middle, last = [1, 2, 3, 4, 5]     # middle = [2, 3, 4]
merged = {**defaults, **overrides}         # later keys win
```

## The Mutable Default Trap

Default values are evaluated **once**, when the `def` statement executes, and stored on the function object:

```python
def append_to(item, target=[]):
    target.append(item)
    return target

append_to(1)        # [1]
append_to(2)        # [1, 2]   ← same list
append_to.__defaults__   # ([1, 2],)
```

The same applies to any expression:

```python
from datetime import datetime

def log(msg, when=datetime.now()):   # the time the MODULE WAS IMPORTED
    print(when, msg)
```

**Fix: use `None` (or a sentinel) and create the value inside.**

```python
def append_to(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target

_MISSING = object()          # when None is a valid value
def get(key, default=_MISSING):
    ...
    if default is _MISSING:
        raise KeyError(key)
```

💡 **There is a legitimate use:** a deliberate per-function cache, e.g. `def fib(n, _memo={}):`. It works, but `functools.cache` says it more clearly ([[02.4 - Decorators]]).

Framework note: FastAPI's `def endpoint(q: list[str] = Query([]))` and Pydantic's `tags: list[str] = []` look like this trap but are safe. The framework copies defaults per request or instance. Plain functions and dataclasses do not (dataclasses raise an error for a mutable default and make you use `default_factory`).

## Forwarding Arguments Correctly

Wrappers should forward everything unchanged:

```python
def logged(func):
    def wrapper(*args, **kwargs):
        print("calling", func.__name__)
        return func(*args, **kwargs)
    return wrapper
```

For typed forwarding, use `ParamSpec` so type checkers keep the original signature ([[07.1 - Type Hints and Static Checking]]):

```python
from typing import Callable, ParamSpec, TypeVar
P = ParamSpec("P"); R = TypeVar("R")

def logged(func: Callable[P, R]) -> Callable[P, R]:
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        return func(*args, **kwargs)
    return wrapper
```

## Inspecting Signatures

```python
import inspect
sig = inspect.signature(connect)
for name, p in sig.parameters.items():
    print(name, p.kind, p.default)
# host POSITIONAL_OR_KEYWORD <class 'inspect._empty'>
# port POSITIONAL_OR_KEYWORD 5432
# timeout KEYWORD_ONLY 10.0
sig.bind("db", timeout=3).arguments
```

This is exactly how FastAPI works out which parameters are path params, query params or bodies, and how pytest decides which fixtures to inject ([[07.5 - Testing With pytest]]).
