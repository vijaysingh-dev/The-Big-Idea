# Adapter Pattern

## At a Glance

|||
|---|---|
|**Type**|Structural|
|**Intent**|Convert one interface into another that clients expect — makes incompatible interfaces work together|
|**Also Known As**|Wrapper|
|**Frequency in Backend**|★★★★★ — third-party SDK integration, legacy system wrapping|

---

## The Problem It Solves

You have an existing interface your code depends on. A new library or legacy service has a different interface. You can't change either — Adapter bridges the gap.

```
Your code expects:  StorageProvider.save(file_id, data)
S3 SDK offers:      s3_client.put_object(Bucket=..., Key=..., Body=...)
Adapter translates: StorageProvider.save() → s3_client.put_object()
```

---

## Full Backend Example: Storage Provider Adapters

```python
# storage_provider.py — Your stable interface
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Optional, BinaryIO

@dataclass
class StoredFile:
    file_id: str
    url: str
    size_bytes: int
    content_type: str

class StorageProvider(ABC):
    """Interface your application code depends on."""
    
    @abstractmethod
    def save(self, file_id: str, data: bytes, content_type: str) -> StoredFile:
        pass
    
    @abstractmethod
    def retrieve(self, file_id: str) -> bytes:
        pass
    
    @abstractmethod
    def delete(self, file_id: str) -> bool:
        pass
    
    @abstractmethod
    def get_url(self, file_id: str, expires_in_seconds: int = 3600) -> str:
        pass


# s3_adapter.py — Adapts boto3 S3 client to StorageProvider
class S3StorageAdapter(StorageProvider):
    """
    Adapter: translates StorageProvider calls to boto3 S3 API.
    Your app never imports boto3 directly.
    """
    
    def __init__(self, bucket_name: str, region: str, cdn_base_url: Optional[str] = None):
        import boto3
        self._s3 = boto3.client("s3", region_name=region)
        self._bucket = bucket_name
        self._cdn_base = cdn_base_url
    
    def save(self, file_id: str, data: bytes, content_type: str) -> StoredFile:
        self._s3.put_object(
            Bucket=self._bucket,
            Key=file_id,
            Body=data,
            ContentType=content_type,
        )
        return StoredFile(
            file_id=file_id,
            url=self.get_url(file_id),
            size_bytes=len(data),
            content_type=content_type
        )
    
    def retrieve(self, file_id: str) -> bytes:
        response = self._s3.get_object(Bucket=self._bucket, Key=file_id)
        return response["Body"].read()
    
    def delete(self, file_id: str) -> bool:
        try:
            self._s3.delete_object(Bucket=self._bucket, Key=file_id)
            return True
        except self._s3.exceptions.NoSuchKey:
            return False
    
    def get_url(self, file_id: str, expires_in_seconds: int = 3600) -> str:
        if self._cdn_base:
            return f"{self._cdn_base}/{file_id}"
        return self._s3.generate_presigned_url(
            "get_object",
            Params={"Bucket": self._bucket, "Key": file_id},
            ExpiresIn=expires_in_seconds
        )


# gcs_adapter.py — Google Cloud Storage, completely different SDK
class GCSStorageAdapter(StorageProvider):
    """Adapter: translates StorageProvider calls to GCS client library."""
    
    def __init__(self, bucket_name: str, project_id: str):
        from google.cloud import storage
        self._client = storage.Client(project=project_id)
        self._bucket = self._client.bucket(bucket_name)
    
    def save(self, file_id: str, data: bytes, content_type: str) -> StoredFile:
        blob = self._bucket.blob(file_id)
        blob.upload_from_string(data, content_type=content_type)
        return StoredFile(
            file_id=file_id,
            url=blob.public_url,
            size_bytes=len(data),
            content_type=content_type
        )
    
    def retrieve(self, file_id: str) -> bytes:
        blob = self._bucket.blob(file_id)
        return blob.download_as_bytes()
    
    def delete(self, file_id: str) -> bool:
        blob = self._bucket.blob(file_id)
        if blob.exists():
            blob.delete()
            return True
        return False
    
    def get_url(self, file_id: str, expires_in_seconds: int = 3600) -> str:
        from datetime import timedelta
        blob = self._bucket.blob(file_id)
        return blob.generate_signed_url(expiration=timedelta(seconds=expires_in_seconds))


# local_storage_adapter.py — For local dev / tests
class LocalStorageAdapter(StorageProvider):
    def __init__(self, base_dir: str = "/tmp/storage", base_url: str = "http://localhost:8000/files"):
        import os
        self._base_dir = base_dir
        self._base_url = base_url
        os.makedirs(base_dir, exist_ok=True)
    
    def save(self, file_id: str, data: bytes, content_type: str) -> StoredFile:
        import os
        path = os.path.join(self._base_dir, file_id.replace("/", "_"))
        with open(path, "wb") as f:
            f.write(data)
        return StoredFile(file_id=file_id, url=self.get_url(file_id),
                         size_bytes=len(data), content_type=content_type)
    
    def retrieve(self, file_id: str) -> bytes:
        import os
        path = os.path.join(self._base_dir, file_id.replace("/", "_"))
        with open(path, "rb") as f:
            return f.read()
    
    def delete(self, file_id: str) -> bool:
        import os
        path = os.path.join(self._base_dir, file_id.replace("/", "_"))
        if os.path.exists(path):
            os.remove(path)
            return True
        return False
    
    def get_url(self, file_id: str, expires_in_seconds: int = 3600) -> str:
        return f"{self._base_url}/{file_id}"


# Your service — never imports boto3/gcs/etc directly
class DocumentService:
    def __init__(self, storage: StorageProvider):
        self._storage = storage
    
    def upload_invoice(self, order_id: str, pdf_bytes: bytes) -> str:
        file = self._storage.save(
            file_id=f"invoices/{order_id}.pdf",
            data=pdf_bytes,
            content_type="application/pdf"
        )
        return file.url
    
    def download_invoice(self, order_id: str) -> bytes:
        return self._storage.retrieve(f"invoices/{order_id}.pdf")
```

|---|---|
|`EmailSender.send()`|SendGrid SDK, SES boto3, SMTP|
|`PaymentGateway.charge()`|Stripe, Razorpay, PayPal|

|`MapProvider.geocode()`|Google Maps, MapBox, HERE|
|Legacy DB `UserStore`|New ORM + DB|

---

## Adapter vs Facade

||Adapter|Facade|
|---|---|---|
|Purpose|Interface _conversion_|Interface _simplification_|
|Target|One incompatible interface|Complex subsystem|
|Client changes?|No — adapter makes it fit|No — hides complexity|
|Existing interface?|Yes, adapting to it|No, defining new one|

---

## When NOT to Use Adapter

- **You control both interfaces** — just align them, no adapter needed
- **Many adapters for same interface** — consider if the interface itself is wrong
- **Thin wrapper with no real translation** — may be unnecessary indirection

---

## Tradeoffs

|Pro|Con|
|---|---|
|Isolate third-party dependencies|Extra class/layer to maintain|
|Swap providers without app changes|If adaptee's model fundamentally differs, adapter gets complex|
|Testable — mock the interface|Developers must know to use interface, not SDK directly|
|Follows DIP||
