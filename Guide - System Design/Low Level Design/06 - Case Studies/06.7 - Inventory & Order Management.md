# Case Study: Inventory & Order Management

**Difficulty:** Hard | **Patterns:** Saga, Repository, Unit of Work, State, Observer, Strategy

---

## Step 1: Requirements

### Functional

- Product catalog with variants (size, color)
- Inventory tracking per SKU per warehouse
- Reserve inventory when order placed, release on cancel
- Support backorders (allow orders when inventory low, fulfill later)
- Multi-warehouse: pick from nearest warehouse with stock
- Automatic low-stock alerts
- Bulk inventory adjustments (receiving shipments, write-offs)
- Inventory history / audit trail

### Non-Functional

- No overselling (strong consistency on reserve/release)
- Inventory updates visible within 1 second
- Support 10K concurrent orders
- Full audit trail of every inventory change

---

## Step 2: Core Entities

```
Product          → catalog info (name, description, images)
ProductVariant   → SKU, size/color combination
InventoryItem    → quantity at a specific warehouse for a SKU
Warehouse        → location, capacity
InventoryMovement → audit: every +/- with reason
Reservation      → hold quantity for an order (with expiry)
Order            → placed by customer, references variants
```

```python
# inventory_item.py — Core aggregate for inventory
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from datetime import datetime
from typing import Optional, List
from enum import Enum

class MovementReason(Enum):
    ORDER_RESERVED    = "order_reserved"
    ORDER_RELEASED    = "order_released"     # cancellation
    ORDER_FULFILLED   = "order_fulfilled"     # shipped
    RECEIVED_SHIPMENT = "received_shipment"
    ADJUSTMENT        = "adjustment"          # manual correction
    WRITE_OFF         = "write_off"           # damaged/expired
    TRANSFER_IN       = "transfer_in"
    TRANSFER_OUT      = "transfer_out"

@dataclass
class InventoryMovement:
    """Immutable audit record of every inventory change."""
    movement_id: UUID = field(default_factory=uuid4)
    sku: str = ""
    warehouse_id: UUID = None
    quantity_delta: int = 0      # positive = increase, negative = decrease
    reason: MovementReason = None
    reference_id: Optional[str] = None   # order_id, shipment_id, etc.
    occurred_at: datetime = field(default_factory=datetime.now)
    performed_by: str = "system"

@dataclass
class Reservation:
    reservation_id: UUID = field(default_factory=uuid4)
    sku: str = ""
    warehouse_id: UUID = None
    quantity: int = 0
    order_id: UUID = None
    expires_at: Optional[datetime] = None
    status: str = "ACTIVE"   # ACTIVE, FULFILLED, RELEASED


class InventoryItem:
    """
    Tracks inventory for one SKU at one warehouse.
    All mutations are recorded as movements (event sourcing lite).
    """
    
    def __init__(self, sku: str, warehouse_id: UUID,
                 quantity_on_hand: int = 0, reorder_point: int = 0):
        self.sku = sku
        self.warehouse_id = warehouse_id
        self._on_hand = quantity_on_hand
        self._reserved = 0         # held for active orders
        self.reorder_point = reorder_point
        self._movements: List[InventoryMovement] = []
        self._reservations: List[Reservation] = []
        self._events = []
    
    @property
    def on_hand(self) -> int: return self._on_hand
    
    @property
    def reserved(self) -> int: return self._reserved
    
    @property
    def available(self) -> int:
        """Quantity available for new orders."""
        return self._on_hand - self._reserved
    
    @property
    def is_low_stock(self) -> bool:
        return self.available <= self.reorder_point and self.reorder_point > 0
    
    def reserve(self, quantity: int, order_id: UUID,
                expires_at: Optional[datetime] = None) -> Reservation:
        if quantity <= 0:
            raise ValueError("Quantity must be positive")
        if self.available < quantity:
            raise InsufficientStockError(
                sku=self.sku, available=self.available, requested=quantity
            )
        
        reservation = Reservation(
            sku=self.sku, warehouse_id=self.warehouse_id,
            quantity=quantity, order_id=order_id, expires_at=expires_at
        )
        self._reservations.append(reservation)
        self._reserved += quantity
        
        self._record_movement(
            delta=-0,  # reserved doesn't change on_hand
            reason=MovementReason.ORDER_RESERVED,
            reference_id=str(order_id)
        )
        
        if self.is_low_stock:
            self._events.append(LowStockAlert(sku=self.sku, available=self.available))
        
        return reservation
    
    def release_reservation(self, reservation_id: UUID):
        """Release held stock (e.g., order cancelled)."""
        reservation = self._find_reservation(reservation_id)
        if reservation.status != "ACTIVE":
            raise InvalidStateTransition(f"Cannot release {reservation.status} reservation")
        
        self._reserved -= reservation.quantity
        reservation.status = "RELEASED"
        
        self._record_movement(
            delta=0,
            reason=MovementReason.ORDER_RELEASED,
            reference_id=str(reservation.order_id)
        )
    
    def fulfill_reservation(self, reservation_id: UUID):
        """Deduct from on-hand when order ships."""
        reservation = self._find_reservation(reservation_id)
        if reservation.status != "ACTIVE":
            raise InvalidStateTransition(f"Cannot fulfill {reservation.status} reservation")
        
        self._on_hand -= reservation.quantity
        self._reserved -= reservation.quantity
        reservation.status = "FULFILLED"
        
        self._record_movement(
            delta=-reservation.quantity,
            reason=MovementReason.ORDER_FULFILLED,
            reference_id=str(reservation.order_id)
        )
    
    def receive_stock(self, quantity: int, reference: str, performed_by: str):
        """Add stock from incoming shipment."""
        if quantity <= 0:
            raise ValueError("Received quantity must be positive")
        
        self._on_hand += quantity
        self._record_movement(
            delta=quantity,
            reason=MovementReason.RECEIVED_SHIPMENT,
            reference_id=reference, performed_by=performed_by
        )
    
    def adjust(self, quantity_delta: int, reason: str, performed_by: str):
        """Manual adjustment (audit, write-off, count correction)."""
        if self._on_hand + quantity_delta < 0:
            raise ValueError("Adjustment would result in negative on-hand stock")
        
        self._on_hand += quantity_delta
        reason_enum = MovementReason.ADJUSTMENT if quantity_delta > 0 else MovementReason.WRITE_OFF
        self._record_movement(
            delta=quantity_delta, reason=reason_enum,
            reference_id=reason, performed_by=performed_by
        )
    
    def expire_reservations(self, now: datetime = None):
        """Release reservations past their expiry (background job)."""
        now = now or datetime.now()
        for res in self._reservations:
            if res.status == "ACTIVE" and res.expires_at and res.expires_at < now:
                self.release_reservation(res.reservation_id)
                self._events.append(ReservationExpired(
                    reservation_id=res.reservation_id,
                    order_id=res.order_id
                ))
    
    def get_movements(self) -> List[InventoryMovement]:
        return list(self._movements)
    
    def get_events(self): return list(self._events)
    def clear_events(self): self._events.clear()
    
    def _record_movement(self, delta: int, reason: MovementReason,
                         reference_id: str = None, performed_by: str = "system"):
        self._movements.append(InventoryMovement(
            sku=self.sku, warehouse_id=self.warehouse_id,
            quantity_delta=delta, reason=reason,
            reference_id=reference_id, performed_by=performed_by
        ))
    
    def _find_reservation(self, reservation_id: UUID) -> Reservation:
        res = next((r for r in self._reservations if r.reservation_id == reservation_id), None)
        if not res:
            raise ReservationNotFoundError(reservation_id)
        return res


# warehouse_selector.py — Strategy for multi-warehouse allocation
class WarehouseSelector(ABC):
    @abstractmethod
    def select(self, sku: str, quantity: int,
               delivery_address: "Location",
               inventory_items: List[InventoryItem]) -> Optional[InventoryItem]: pass

class NearestWarehouseSelector(WarehouseSelector):
    def __init__(self, warehouse_repo):
        self._warehouses = warehouse_repo
    
    def select(self, sku, quantity, delivery_address, inventory_items):
        eligible = [item for item in inventory_items
                    if item.sku == sku and item.available >= quantity]
        if not eligible:
            return None
        
        # Sort by distance from delivery address
        warehouses = {w.id: w for w in self._warehouses.find_all()}
        eligible_with_dist = [
            (item, warehouses[item.warehouse_id].location.distance_km(delivery_address))
            for item in eligible
            if item.warehouse_id in warehouses
        ]
        return min(eligible_with_dist, key=lambda x: x[1])[0]


# inventory_service.py — orchestrates multi-warehouse operations
class InventoryService:
    def __init__(self, inventory_repo, warehouse_selector: WarehouseSelector,
                 uow_factory, event_bus):
        self._repo = inventory_repo
        self._selector = warehouse_selector
        self._uow_factory = uow_factory
        self._bus = event_bus
    
    def reserve_for_order(self, order_id: UUID, items: List[dict],
                          delivery_address: "Location") -> List[Reservation]:
        """
        Reserve inventory for all items in an order.
        All-or-nothing: if any item is unavailable, reserve nothing.
        """
        reservations = []
        
        with self._uow_factory() as uow:
            for item_req in items:
                sku = item_req["sku"]
                quantity = item_req["quantity"]
                
                all_items = uow.inventory.find_by_sku(sku)
                selected = self._selector.select(sku, quantity, delivery_address, all_items)
                
                if not selected:
                    raise InsufficientStockError(sku=sku, available=0, requested=quantity)
                
                reservation = selected.reserve(quantity, order_id,
                                               expires_at=self._reservation_expiry())
                reservations.append(reservation)
                uow.inventory.save(selected)
                
                for event in selected.get_events():
                    self._bus.publish(event)
                selected.clear_events()
        
        return reservations
    
    def release_order_reservations(self, order_id: UUID):
        """Release all reservations for an order (e.g., cancellation)."""
        reservations = self._repo.find_active_reservations_for_order(order_id)
        
        with self._uow_factory() as uow:
            for reservation in reservations:
                item = uow.inventory.get(reservation.sku, reservation.warehouse_id)
                item.release_reservation(reservation.reservation_id)
                uow.inventory.save(item)
    
    def fulfill_order(self, order_id: UUID):
        """Deduct on-hand when order ships."""
        reservations = self._repo.find_active_reservations_for_order(order_id)
        
        with self._uow_factory() as uow:
            for reservation in reservations:
                item = uow.inventory.get(reservation.sku, reservation.warehouse_id)
                item.fulfill_reservation(reservation.reservation_id)
                uow.inventory.save(item)
    
    def _reservation_expiry(self):
        from datetime import timedelta
        return datetime.now() + timedelta(minutes=30)
```

## Step 4: Patterns Used

|Pattern|Where|Why|
|---|---|---|
|**Repository**|`InventoryRepository`|Domain isolated from persistence|
|**Unit of Work**|`uow_factory`|All-or-nothing multi-item reservation|
|**Strategy**|`WarehouseSelector`|Nearest/cheapest/fastest warehouse selection swappable|
|**Observer**|`LowStockAlert`, domain events|Purchasing team notified without tight coupling|
|**State**|`Reservation.status`|ACTIVE → FULFILLED/RELEASED transition|
|**Event Sourcing (lite)**|`InventoryMovement` log|Full audit trail of every change|

## Step 5: Preventing Overselling

```python
# Database-level atomic decrement (critical for correctness)
# SQL: UPDATE inventory SET reserved = reserved + :qty
#       WHERE sku = :sku AND warehouse_id = :wh
#       AND (on_hand - reserved) >= :qty
# RETURNING on_hand, reserved

# If rows_affected == 0: insufficient stock (atomic — no race condition)
# This beats optimistic locking for high-contention inventory
```
