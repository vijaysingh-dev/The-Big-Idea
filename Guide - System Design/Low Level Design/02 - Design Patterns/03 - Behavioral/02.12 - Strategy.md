# Strategy Pattern

## At a Glance

|||
|---|---|
|**Type**|Behavioral|
|**Intent**|Define a family of algorithms, encapsulate each, make them interchangeable|
|**Also Known As**|Policy Pattern|
|**Frequency in Backend**|★★★★★ — extremely common|

---

## The Problem It Solves

You have a class that needs to do "something" but the _how_ varies. Without Strategy, you write `if/elif` chains. Every new variant = modify the class = break existing behavior.

```python
# ❌ Before Strategy — every new method touches PaymentService
class PaymentService:
    def process(self, order, method: str):
        if method == "stripe":
            # 20 lines of Stripe logic
        elif method == "paypal":
            # 20 lines of PayPal logic
        elif method == "razorpay":   # new requirement = open existing file
            # 20 lines of Razorpay logic
        # Testing this class requires mocking ALL payment providers
```

## Full Backend Example: Payment Processing

```python
# payment_strategy.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from decimal import Decimal
from typing import Optional

@dataclass
class PaymentRequest:
    amount: Decimal
    currency: str
    user_id: str
    metadata: dict

@dataclass
class PaymentResult:
    success: bool
    transaction_id: Optional[str]
    provider: str
    error_message: Optional[str] = None
    
    @classmethod
    def success_result(cls, tx_id: str, provider: str) -> "PaymentResult":
        return cls(success=True, transaction_id=tx_id, provider=provider)
    
    @classmethod
    def failure_result(cls, error: str, provider: str) -> "PaymentResult":
        return cls(success=False, transaction_id=None, provider=provider, error_message=error)


class PaymentStrategy(ABC):
    """Strategy interface — all payment providers must implement this."""
    
    @abstractmethod
    def process(self, request: PaymentRequest) -> PaymentResult:
        pass
    
    @abstractmethod
    def refund(self, transaction_id: str, amount: Decimal) -> PaymentResult:
        pass
    
    @abstractmethod
    def supports_currency(self, currency: str) -> bool:
        pass


# stripe_strategy.py
class StripePaymentStrategy(PaymentStrategy):
    
    def __init__(self, api_key: str, webhook_secret: str):
        self._client = stripe.Client(api_key)
        self._webhook_secret = webhook_secret
    
    def process(self, request: PaymentRequest) -> PaymentResult:
        try:
            intent = self._client.payment_intents.create(
                amount=int(request.amount * 100),  # Stripe uses cents
                currency=request.currency.lower(),
                metadata={"user_id": request.user_id, **request.metadata}
            )
            return PaymentResult.success_result(intent.id, "stripe")
        except stripe.CardError as e:
            return PaymentResult.failure_result(e.user_message, "stripe")
        except stripe.StripeError as e:
            raise PaymentProviderError(f"Stripe error: {e}") from e
    
    def refund(self, transaction_id: str, amount: Decimal) -> PaymentResult:
        try:
            refund = self._client.refunds.create(
                payment_intent=transaction_id,
                amount=int(amount * 100)
            )
            return PaymentResult.success_result(refund.id, "stripe")
        except stripe.StripeError as e:
            return PaymentResult.failure_result(str(e), "stripe")
    
    def supports_currency(self, currency: str) -> bool:
        return currency.upper() in {"USD", "EUR", "GBP", "INR", "SGD"}


# razorpay_strategy.py
class RazorpayPaymentStrategy(PaymentStrategy):
    
    def __init__(self, key_id: str, key_secret: str):
        self._client = razorpay.Client(auth=(key_id, key_secret))
    
    def process(self, request: PaymentRequest) -> PaymentResult:
        try:
            order = self._client.order.create({
                "amount": int(request.amount * 100),  # Razorpay uses paise
                "currency": request.currency,
                "notes": {"user_id": request.user_id}
            })
            return PaymentResult.success_result(order["id"], "razorpay")
        except razorpay.errors.BadRequestError as e:
            return PaymentResult.failure_result(str(e), "razorpay")
    
    def refund(self, transaction_id: str, amount: Decimal) -> PaymentResult:
        refund = self._client.payment.refund(transaction_id, {
            "amount": int(amount * 100)
        })
        return PaymentResult.success_result(refund["id"], "razorpay")
    
    def supports_currency(self, currency: str) -> bool:
        return currency.upper() == "INR"


# payment_service.py  (Context)
class PaymentService:
    """Context — unaware of which strategy is active."""
    
    def __init__(self, strategies: list[PaymentStrategy]):
        self._strategies = strategies
    
    def process_payment(self, request: PaymentRequest) -> PaymentResult:
        strategy = self._select_strategy(request.currency)
        return strategy.process(request)
    
    def refund(self, transaction_id: str, amount: Decimal, currency: str) -> PaymentResult:
        strategy = self._select_strategy(currency)
        return strategy.refund(transaction_id, amount)
    
    def _select_strategy(self, currency: str) -> PaymentStrategy:
        for strategy in self._strategies:
            if strategy.supports_currency(currency):
                return strategy
        raise UnsupportedCurrencyError(f"No payment provider supports {currency}")


# main.py / DI wiring
payment_service = PaymentService(strategies=[
    RazorpayPaymentStrategy(key_id=..., key_secret=...),
    StripePaymentStrategy(api_key=..., webhook_secret=...),
])
```

## When NOT to Use Strategy

- **Only one algorithm** — don't abstract what doesn't vary
- **Algorithm never changes at runtime** — simple polymorphism via subclassing may suffice
- **Algorithm is one line** — overkill to wrap in a class
- **Tight performance requirements** — virtual dispatch overhead (rare concern in Python/JVM)

---

## Tradeoffs

|Pro|Con|
|---|---|
|Open/Closed — add strategies without modifying context|More classes/files to manage|
|Testable — mock one strategy in isolation|Client must know which strategy to pick (or need a selector)|
|Eliminates type-based conditionals|Can be over-engineered for simple cases|
|Runtime switching possible|Strategy interface must fit all implementations|

---

## Common Mistakes

1. **Making strategy stateful** — strategies should be stateless; state belongs in `PaymentRequest`
2. **Strategy interface too fat** — one strategy can't implement all methods → use ISP
3. **Context doing strategy selection** — extract selection to a factory or registry
4. **Not handling strategy not found** — always have a fallback or clear error

## Interview Perspective

> "Design a notification system that supports Email, SMS, and Push."

Immediately reach for Strategy. Interviewers want to see:

- `NotificationStrategy` interface
- Concrete strategies per channel
- A `NotificationService` (Context) that takes strategies
- Mention: strategies could be selected based on user preferences, priority, or cost

> "How would you add WhatsApp notifications without changing existing code?"

= Add `WhatsAppStrategy` implementing `NotificationStrategy`. Zero changes to `NotificationService`. This demonstrates OCP via Strategy.

## Senior Engineer Lens

Strategy is best combined with:

- **Factory Method** — for strategy instantiation
- **Decorator** — to add retry/logging to any strategy
- **Registry** — to allow runtime registration of new strategies without code changes

```python
# Strategy + Decorator: add retry to any payment strategy
class RetryPaymentStrategy(PaymentStrategy):
    def __init__(self, delegate: PaymentStrategy, max_retries: int = 3):
        self._delegate = delegate
        self._max_retries = max_retries
    
    def process(self, request: PaymentRequest) -> PaymentResult:
        for attempt in range(self._max_retries):
            result = self._delegate.process(request)
            if result.success or attempt == self._max_retries - 1:
                return result
        return result
    
    def refund(self, *args, **kwargs):
        return self._delegate.refund(*args, **kwargs)
    
    def supports_currency(self, currency):
        return self._delegate.supports_currency(currency)
```
