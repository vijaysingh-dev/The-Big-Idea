# Build Your Own: Notification System

> **Revision tags:** #build-your-own #notifications  
> **Related:** [[03.16 - Notification Systems]]

---

## Goal

Build a multi-channel notification dispatcher that:
- Accepts notification requests with channel preferences
- Routes to the right channel handler (email, push, SMS)
- Retries failed deliveries per channel
- Deduplicates notifications (at-least-once delivery safety)
- Tracks delivery status per notification

---

## Core Design

```
[Trigger]  →  NotificationRequest
                    │
              [NotificationService]
                    │
              ┌─────┼──────┐
              ▼     ▼      ▼
          [Email] [Push] [SMS]
           Handler Handler Handler
                    │
              [DeliveryLog]
              [DedupeStore]
```

## Implementation

```python
import uuid
import time
import threading
import logging
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Set
from enum import Enum

logger = logging.getLogger(__name__)


# ── Domain types ──────────────────────────────────────────────────────────────

class Channel(Enum):
    EMAIL = "email"
    PUSH  = "push"
    SMS   = "sms"

class DeliveryStatus(Enum):
    PENDING   = "pending"
    SENT      = "sent"
    FAILED    = "failed"
    SKIPPED   = "skipped"   # filtered by user prefs or dedup
    RETRYING  = "retrying"

@dataclass
class NotificationRequest:
    user_id: str
    template: str               # e.g. "order.shipped", "payment.failed"
    payload: dict               # template variables
    channels: List[Channel]     # desired channels
    idempotency_key: str = field(default_factory=lambda: str(uuid.uuid4()))
    priority: int = 5           # 1=critical, 10=low

@dataclass
class UserPreferences:
    user_id: str
    email: Optional[str]
    push_token: Optional[str]
    phone: Optional[str]
    opt_outs: Set[str] = field(default_factory=set)      # opted-out templates
    quiet_hours: Optional[tuple] = None                  # (start_hour, end_hour)
    enabled_channels: Set[Channel] = field(
        default_factory=lambda: {Channel.EMAIL, Channel.PUSH, Channel.SMS}
    )

@dataclass
class DeliveryRecord:
    notification_id: str
    user_id: str
    channel: Channel
    template: str
    status: DeliveryStatus
    created_at: float = field(default_factory=time.time)
    sent_at: Optional[float] = None
    error: Optional[str] = None
    attempts: int = 0


# ── Channel handlers ──────────────────────────────────────────────────────────

class ChannelHandler(ABC):
    """Base class for all channel handlers."""

    @abstractmethod
    def send(self, user_prefs: UserPreferences, template: str,
             payload: dict) -> bool:
        """Send notification. Returns True on success."""
        pass

    @property
    @abstractmethod
    def channel(self) -> Channel:
        pass


class EmailHandler(ChannelHandler):
    channel = Channel.EMAIL

    def send(self, user_prefs: UserPreferences, template: str,
             payload: dict) -> bool:
        if not user_prefs.email:
            logger.warning(f"No email for user {user_prefs.user_id}")
            return False
        # In production: call SendGrid/SES API here
        subject, body = self._render(template, payload)
        logger.info(f"[Email] → {user_prefs.email} | {subject}")
        # Simulate occasional failure
        import random
        if random.random() < 0.1:   # 10% failure rate for demo
            raise RuntimeError("SMTP timeout")
        return True

    def _render(self, template: str, payload: dict) -> tuple:
        templates = {
            "order.shipped": (
                "Your order has shipped!",
                f"Order #{payload.get('order_id')} is on its way."
            ),
            "payment.failed": (
                "Payment failed",
                f"We couldn't process your payment of ${payload.get('amount')}."
            ),
        }
        return templates.get(template, (template, str(payload)))


class PushHandler(ChannelHandler):
    channel = Channel.PUSH

    def send(self, user_prefs: UserPreferences, template: str,
             payload: dict) -> bool:
        if not user_prefs.push_token:
            logger.warning(f"No push token for user {user_prefs.user_id}")
            return False
        # In production: call APNs/FCM API here
        title, body = self._render(template, payload)
        logger.info(f"[Push] → token:{user_prefs.push_token[:8]}... | {title}")
        return True

    def _render(self, template: str, payload: dict) -> tuple:
        templates = {
            "order.shipped": ("Order shipped 📦", "Your order is on the way!"),
            "payment.failed": ("Payment failed ❌", "Please update your payment method."),
        }
        return templates.get(template, (template, ""))


class SMSHandler(ChannelHandler):
    channel = Channel.SMS

    def send(self, user_prefs: UserPreferences, template: str,
             payload: dict) -> bool:
        if not user_prefs.phone:
            return False
        message = self._render(template, payload)
        logger.info(f"[SMS] → {user_prefs.phone} | {message[:40]}...")
        return True

    def _render(self, template: str, payload: dict) -> str:
        templates = {
            "order.shipped": f"Your order #{payload.get('order_id')} has shipped.",
            "payment.failed": f"Payment of ${payload.get('amount')} failed. Update your card.",
        }
        return templates.get(template, template)


# ── Notification Service ───────────────────────────────────────────────────────

class NotificationService:
    """
    Central dispatcher: validates preferences, deduplicates,
    dispatches to channel handlers, retries failures, logs delivery.
    """

    def __init__(self,
                 prefs_store: Dict[str, UserPreferences],
                 max_retries: int = 3,
                 retry_delay: float = 1.0):
        self._prefs = prefs_store
        self._max_retries = max_retries
        self._retry_delay = retry_delay

        # Register channel handlers
        self._handlers: Dict[Channel, ChannelHandler] = {
            Channel.EMAIL: EmailHandler(),
            Channel.PUSH:  PushHandler(),
            Channel.SMS:   SMSHandler(),
        }

        # Deduplication store: idempotency_key+channel → True
        self._sent: Dict[str, bool] = {}
        self._dedup_lock = threading.Lock()

        # Delivery log
        self._delivery_log: List[DeliveryRecord] = []
        self._log_lock = threading.Lock()

    def send(self, request: NotificationRequest):
        """
        Process a notification request.
        Dispatches to each requested channel in parallel.
        """
        prefs = self._prefs.get(request.user_id)
        if not prefs:
            logger.warning(f"No preferences found for user {request.user_id}")
            return

        # Check if user has opted out of this template
        if request.template in prefs.opt_outs:
            logger.info(f"User {request.user_id} opted out of {request.template}")
            return

        # Check quiet hours for non-critical notifications
        if request.priority > 2 and self._in_quiet_hours(prefs):
            logger.info(f"Suppressed: user {request.user_id} in quiet hours")
            return

        # Dispatch to each channel concurrently
        threads = []
        for channel in request.channels:
            if channel not in prefs.enabled_channels:
                continue
            t = threading.Thread(
                target=self._dispatch_channel,
                args=(request, prefs, channel),
                daemon=True
            )
            threads.append(t)
            t.start()

        for t in threads:
            t.join()

    def _dispatch_channel(self, request: NotificationRequest,
                          prefs: UserPreferences, channel: Channel):
        """Send on one channel with dedup check and retry logic."""
        dedup_key = f"{request.idempotency_key}:{channel.value}"

        # Deduplication check
        with self._dedup_lock:
            if dedup_key in self._sent:
                logger.info(f"Duplicate suppressed: {dedup_key}")
                self._log(request, channel, DeliveryStatus.SKIPPED)
                return
            self._sent[dedup_key] = True

        handler = self._handlers.get(channel)
        if not handler:
            return

        record = DeliveryRecord(
            notification_id=request.idempotency_key,
            user_id=request.user_id,
            channel=channel,
            template=request.template,
            status=DeliveryStatus.PENDING
        )

        # Retry loop
        for attempt in range(1, self._max_retries + 1):
            record.attempts = attempt
            try:
                success = handler.send(prefs, request.template, request.payload)
                if success:
                    record.status = DeliveryStatus.SENT
                    record.sent_at = time.time()
                    break
                else:
                    record.status = DeliveryStatus.FAILED
                    record.error = "Handler returned False (missing contact info)"
                    break   # don't retry — missing contact info won't fix itself
            except Exception as e:
                record.error = str(e)
                if attempt < self._max_retries:
                    record.status = DeliveryStatus.RETRYING
                    delay = self._retry_delay * (2 ** (attempt - 1))
                    logger.warning(
                        f"[{channel.value}] Attempt {attempt} failed: {e}. "
                        f"Retrying in {delay:.1f}s"
                    )
                    time.sleep(delay)
                else:
                    record.status = DeliveryStatus.FAILED
                    logger.error(
                        f"[{channel.value}] All {self._max_retries} attempts "
                        f"failed for user {request.user_id}: {e}"
                    )

        self._log_record(record)

    def _log(self, request: NotificationRequest,
             channel: Channel, status: DeliveryStatus):
        record = DeliveryRecord(
            notification_id=request.idempotency_key,
            user_id=request.user_id,
            channel=channel,
            template=request.template,
            status=status
        )
        self._log_record(record)

    def _log_record(self, record: DeliveryRecord):
        with self._log_lock:
            self._delivery_log.append(record)

    def _in_quiet_hours(self, prefs: UserPreferences) -> bool:
        if not prefs.quiet_hours:
            return False
        start, end = prefs.quiet_hours
        hour = time.localtime().tm_hour
        if start <= end:
            return start <= hour < end
        return hour >= start or hour < end   # wraps midnight

    def get_delivery_log(self, user_id: Optional[str] = None) -> List[DeliveryRecord]:
        with self._log_lock:
            if user_id:
                return [r for r in self._delivery_log if r.user_id == user_id]
            return list(self._delivery_log)
```

## Usage

```python
logging.basicConfig(level=logging.INFO)

# User preferences store (in production: fetched from DB/Redis)
prefs_store = {
    "user:42": UserPreferences(
        user_id="user:42",
        email="vijay@example.com",
        push_token="tok_abc123",
        phone="+91-9999999999",
        opt_outs={"marketing.weekly"},
        quiet_hours=(22, 8),   # 10 PM to 8 AM
    ),
    "user:99": UserPreferences(
        user_id="user:99",
        email="alice@example.com",
        push_token=None,       # no push token
        phone=None,
        enabled_channels={Channel.EMAIL}
    ),
}

svc = NotificationService(prefs_store, max_retries=3)

# Trigger: order shipped
svc.send(NotificationRequest(
    user_id="user:42",
    template="order.shipped",
    payload={"order_id": "ORD-8821"},
    channels=[Channel.EMAIL, Channel.PUSH, Channel.SMS],
    idempotency_key="ship-event-8821"
))

# Retry on duplicate send (idempotency)
svc.send(NotificationRequest(
    user_id="user:42",
    template="order.shipped",
    payload={"order_id": "ORD-8821"},
    channels=[Channel.EMAIL, Channel.PUSH, Channel.SMS],
    idempotency_key="ship-event-8821"   # same key → deduplicated
))

# Check delivery log
for record in svc.get_delivery_log("user:42"):
    print(f"{record.channel.value:8} | {record.status.value:10} | "
          f"attempts={record.attempts}")
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Async fan-out via Kafka | For 10M users, dispatch via queue not threads |
| Real provider integration | APNs, FCM, SendGrid API calls with auth |
| Token refresh | Remove/update stale push tokens on 410 response |
| Template rendering engine | Jinja2/Handlebars for rich HTML email |
| Per-user rate limiting | Max N notifications per day per channel |
| Delivery webhooks | Email opened/bounced callbacks from providers |
| Preference UI sync | Opt-outs persist to DB, reflected in real-time |
| Priority queues | Critical alerts bypass queue backlogs |

---

## Key Takeaways

- The dedup store (idempotency_key + channel) is the safety net for at-least-once delivery
- Channels dispatch in parallel — one slow channel doesn't delay others
- Missing contact info (no push token) is a non-retryable failure — don't retry it
- Network failures (SMTP timeout) are retryable — exponential backoff applies
- Quiet hours only apply to low-priority notifications — security alerts always go through
