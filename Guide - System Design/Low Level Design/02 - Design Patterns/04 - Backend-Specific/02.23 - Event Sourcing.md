# Event Sourcing Pattern

## At a Glance

|||
|---|---|
|**Type**|Backend / Enterprise|
|**Intent**|Store state as a sequence of domain events instead of current snapshot. Reconstruct state by replaying events|
|**Frequency in Backend**|★★★☆☆ — financial systems, audit trails, complex domains|

---

## Core Idea

```
Traditional (snapshot):          Event Sourcing:
┌────────────────────┐           ┌───────────────────────────────┐
│ orders table       │           │ order_events table            │
│ id | status | total│           │ OrderPlaced    {total:500}    │
│ 123 | PAID  | 500  │           │ OrderConfirmed {}             │
│                    │           │ PaymentReceived {tx:"abc"}    │
│ Only current state │           │ OrderShipped   {carrier:"DHL"}│
└────────────────────┘           └───────────────────────────────┘
                                 Current state = replay all events
```

## Full Backend Example: Bank Account

```python
# events.py
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from decimal import Decimal
from datetime import datetime
from typing import List, Any

@dataclass(frozen=True)
class DomainEvent:
    event_id: UUID = field(default_factory=uuid4)
    occurred_at: datetime = field(default_factory=datetime.now)
    aggregate_id: UUID = None
    aggregate_version: int = 0

@dataclass(frozen=True)
class AccountOpened(DomainEvent):
    owner_id: UUID = None
    initial_balance: Decimal = Decimal("0")
    currency: str = "INR"

@dataclass(frozen=True)
class MoneyDeposited(DomainEvent):
    amount: Decimal = None
    reference: str = ""

@dataclass(frozen=True)
class MoneyWithdrawn(DomainEvent):
    amount: Decimal = None
    reference: str = ""

@dataclass(frozen=True)
class AccountFrozen(DomainEvent):
    reason: str = ""

@dataclass(frozen=True)
class AccountUnfrozen(DomainEvent):
    pass


# account.py — Event-sourced aggregate
class Account:
    """
    State is reconstructed by replaying events.
    Never set state directly — only via apply(event).
    """
    
    def __init__(self):
        self.id: UUID = None
        self.owner_id: UUID = None
        self.balance: Decimal = Decimal("0")
        self.currency: str = "INR"
        self.is_frozen: bool = False
        self._version: int = 0
        self._pending_events: List[DomainEvent] = []
    
    # ── Factory / reconstitution ─────────────────────────────
    
    @classmethod
    def open(cls, owner_id: UUID, initial_balance: Decimal = Decimal("0"),
             currency: str = "INR") -> "Account":
        account = cls()
        account._raise(AccountOpened(
            aggregate_id=uuid4(),
            owner_id=owner_id,
            initial_balance=initial_balance,
            currency=currency
        ))
        return account
    
    @classmethod
    def from_events(cls, events: List[DomainEvent]) -> "Account":
        """Reconstruct account by replaying its event history."""
        account = cls()
        for event in events:
            account._apply(event)
            account._version = event.aggregate_version
        return account
    
    # ── Commands (generate events) ───────────────────────────
    
    def deposit(self, amount: Decimal, reference: str):
        if amount <= 0:
            raise DomainError("Deposit amount must be positive")
        if self.is_frozen:
            raise DomainError("Cannot deposit to frozen account")
        
        self._raise(MoneyDeposited(
            aggregate_id=self.id,
            amount=amount,
            reference=reference
        ))
    
    def withdraw(self, amount: Decimal, reference: str):
        if amount <= 0:
            raise DomainError("Withdrawal amount must be positive")
        if self.is_frozen:
            raise DomainError("Cannot withdraw from frozen account")
        if self.balance < amount:
            raise InsufficientFundsError(
                f"Balance {self.balance} insufficient for withdrawal {amount}"
            )
        
        self._raise(MoneyWithdrawn(
            aggregate_id=self.id,
            amount=amount,
            reference=reference
        ))
    
    def freeze(self, reason: str):
        if self.is_frozen:
            raise DomainError("Account is already frozen")
        self._raise(AccountFrozen(aggregate_id=self.id, reason=reason))
    
    def unfreeze(self):
        if not self.is_frozen:
            raise DomainError("Account is not frozen")
        self._raise(AccountUnfrozen(aggregate_id=self.id))
    
    # ── Event application (pure state mutation) ──────────────
    
    def _apply(self, event: DomainEvent):
        """Apply event to update state. No side effects — pure state change."""
        handler = {
            AccountOpened:    self._on_account_opened,
            MoneyDeposited:   self._on_money_deposited,
            MoneyWithdrawn:   self._on_money_withdrawn,
            AccountFrozen:    self._on_account_frozen,
            AccountUnfrozen:  self._on_account_unfrozen,
        }.get(type(event))
        
        if handler:
            handler(event)
    
    def _on_account_opened(self, e: AccountOpened):
        self.id = e.aggregate_id
        self.owner_id = e.owner_id
        self.balance = e.initial_balance
        self.currency = e.currency
    
    def _on_money_deposited(self, e: MoneyDeposited):
        self.balance += e.amount
    
    def _on_money_withdrawn(self, e: MoneyWithdrawn):
        self.balance -= e.amount
    
    def _on_account_frozen(self, e: AccountFrozen):
        self.is_frozen = True
    
    def _on_account_unfrozen(self, e: AccountUnfrozen):
        self.is_frozen = False
    
    # ── Internal helpers ─────────────────────────────────────
    
    def _raise(self, event: DomainEvent):
        """Record event and immediately apply it."""
        versioned = self._version_event(event)
        self._apply(versioned)
        self._pending_events.append(versioned)
        self._version += 1
    
    def _version_event(self, event: DomainEvent) -> DomainEvent:
        return type(event)(
            **{**event.__dict__, 
               "aggregate_version": self._version + 1,
               "aggregate_id": self.id or event.aggregate_id}
        )
    
    def get_pending_events(self) -> List[DomainEvent]:
        return list(self._pending_events)
    
    def clear_pending_events(self):
        self._pending_events.clear()
    
    @property
    def version(self) -> int:
        return self._version


# event_store.py — Persistence for events
import json
from abc import ABC, abstractmethod

class EventStore(ABC):
    @abstractmethod
    def append(self, events: List[DomainEvent], expected_version: int): pass
    
    @abstractmethod
    def load(self, aggregate_id: UUID, from_version: int = 0) -> List[DomainEvent]: pass


class SqlEventStore(EventStore):
    """
    Append-only event log in a SQL table.
    Optimistic concurrency via expected_version.
    """
    
    def __init__(self, db):
        self._db = db
    
    def append(self, events: List[DomainEvent], expected_version: int):
        for event in events:
            try:
                self._db.execute("""
                    INSERT INTO event_store 
                    (event_id, aggregate_id, aggregate_version, event_type, payload, occurred_at)
                    VALUES (%s, %s, %s, %s, %s, %s)
                """, (
                    str(event.event_id),
                    str(event.aggregate_id),
                    event.aggregate_version,
                    type(event).__name__,
                    json.dumps(self._serialize(event)),
                    event.occurred_at
                ))
            except UniqueConstraintError:
                raise ConcurrencyConflict(
                    f"Version conflict at {event.aggregate_version} — "
                    f"another process modified this aggregate"
                )
    
    def load(self, aggregate_id: UUID, from_version: int = 0) -> List[DomainEvent]:
        rows = self._db.execute("""
            SELECT event_type, payload, aggregate_version, occurred_at, event_id
            FROM event_store
            WHERE aggregate_id = %s AND aggregate_version > %s
            ORDER BY aggregate_version ASC
        """, (str(aggregate_id), from_version))
        
        return [self._deserialize(row) for row in rows]
    
    def _serialize(self, event: DomainEvent) -> dict:
        data = {}
        for key, value in event.__dict__.items():
            if isinstance(value, (UUID, Decimal)):
                data[key] = str(value)
            elif isinstance(value, datetime):
                data[key] = value.isoformat()
            else:
                data[key] = value
        return data
    
    def _deserialize(self, row: dict) -> DomainEvent:
        event_class = EVENT_REGISTRY[row["event_type"]]
        payload = json.loads(row["payload"])
        # Reconstruct typed fields
        return event_class(**payload)

EVENT_REGISTRY = {
    "AccountOpened": AccountOpened,
    "MoneyDeposited": MoneyDeposited,
    "MoneyWithdrawn": MoneyWithdrawn,
    "AccountFrozen": AccountFrozen,
    "AccountUnfrozen": AccountUnfrozen,
}


# account_repository.py — Event-sourced repository
class EventSourcedAccountRepository:
    
    def __init__(self, event_store: EventStore):
        self._store = event_store
    
    def save(self, account: Account):
        pending = account.get_pending_events()
        if not pending:
            return
        
        # Optimistic concurrency: expected version = current version before new events
        expected_version = account.version - len(pending)
        self._store.append(pending, expected_version)
        account.clear_pending_events()
    
    def get(self, account_id: UUID) -> Account:
        events = self._store.load(account_id)
        if not events:
            raise AccountNotFoundError(account_id)
        return Account.from_events(events)
    
    def get_with_snapshot(self, account_id: UUID, snapshot_store) -> Account:
        """Optimization: load from snapshot + only recent events."""
        snapshot = snapshot_store.load(account_id)
        from_version = snapshot.version if snapshot else 0
        
        recent_events = self._store.load(account_id, from_version=from_version)
        
        if snapshot:
            account = snapshot.account
            for event in recent_events:
                account._apply(event)
            return account
        else:
            return Account.from_events(recent_events)


# Usage
repo = EventSourcedAccountRepository(SqlEventStore(db))

# Create
account = Account.open(owner_id=user_id, initial_balance=Decimal("1000"))
repo.save(account)

# Load and modify — full history preserved
account = repo.get(account.id)
account.deposit(Decimal("500"), reference="SALARY_JAN")
account.withdraw(Decimal("200"), reference="RENT_FEB")
repo.save(account)

# Point-in-time query — replay only up to a version
events = event_store.load(account.id)
account_at_v2 = Account.from_events(events[:2])
print(account_at_v2.balance)  # state after only first 2 events
```

## Snapshots

For aggregates with thousands of events, replaying all from scratch is slow. Periodically snapshot:

```python
@dataclass
class AccountSnapshot:
    account_id: UUID
    version: int
    balance: Decimal
    is_frozen: bool
    taken_at: datetime

class SnapshotStore:
    def save(self, account: Account):
        self._db.upsert(AccountSnapshot(
            account_id=account.id,
            version=account.version,
            balance=account.balance,
            is_frozen=account.is_frozen,
            taken_at=datetime.now()
        ))
    
    def load(self, account_id: UUID) -> Optional[AccountSnapshot]:
        return self._db.find_latest(account_id)

# Snapshot every 50 events
if account.version % 50 == 0:
    snapshot_store.save(account)
```

## Event Sourcing Benefits

|Benefit|Why|
|---|---|
|Full audit trail|Every state change is a stored event|
|Point-in-time queries|Replay to any version|
|Debugging|Replay production events locally|
|Event-driven integration|Events drive CQRS projections, notifications|
|Temporal queries|"What was the account balance on Jan 15?"|

---

## When NOT to Use Event Sourcing

- **Simple CRUD** — massive overhead for no benefit
- **No audit requirements** — snapshot is simpler
- **Team unfamiliar with pattern** — high learning curve
- **Simple reporting** — projection complexity may not be worth it

---

## Tradeoffs

|Pro|Con|
|---|---|
|Complete history|Querying current state requires projection|
|Natural audit log|Event schema evolution is hard|
|Enables CQRS naturally|Eventual consistency between write and read|
|Replay and debug|Storage grows unboundedly (need archiving)|
