# Build Your Own: Service Discovery

> **Revision tags:** #build-your-own #service-discovery #infrastructure  
> **Related:** [[03.13 - Service Discovery and Config]]

---

## Goal

Build a service registry with:
- Service registration with health metadata
- Heartbeat-based liveness (deregister unresponsive instances)
- Client-side load balancing (round-robin over healthy instances)
- Watch API (notify clients when instances change)
- TTL-based automatic deregistration on crash

---

## Core Design

```
[Service Instance A]  →  register(name, host, port, ttl=30)
[Service Instance B]  →  register(name, host, port, ttl=30)

[Registry]
  services:
    "payment-service":
      instance-1: {host, port, healthy, last_heartbeat, ttl}
      instance-2: {host, port, healthy, last_heartbeat, ttl}

[Service Instance A] → heartbeat(instance_id)  every ttl/3 seconds

[Client]  →  resolve("payment-service")  → [host:port]  (round-robin)
          →  watch("payment-service")    → callback on change
```

## Implementation

```python
import uuid
import time
import threading
import logging
from dataclasses import dataclass, field
from typing import Callable, Dict, List, Optional, Set
from collections import defaultdict

logger = logging.getLogger(__name__)


# ── Service instance ──────────────────────────────────────────────────────────

@dataclass
class ServiceInstance:
    instance_id: str
    service_name: str
    host: str
    port: int
    ttl: float                       # seconds before considered dead
    metadata: Dict[str, str] = field(default_factory=dict)
    registered_at: float = field(default_factory=time.monotonic)
    last_heartbeat: float = field(default_factory=time.monotonic)
    healthy: bool = True

    @property
    def address(self) -> str:
        return f"{self.host}:{self.port}"

    def is_expired(self) -> bool:
        return (time.monotonic() - self.last_heartbeat) > self.ttl

    def touch(self):
        self.last_heartbeat = time.monotonic()
        self.healthy = True


# ── Service Registry ──────────────────────────────────────────────────────────

class ServiceRegistry:
    """
    Central registry storing all registered service instances.
    Runs a background TTL checker that removes stale instances.
    """

    def __init__(self, ttl_check_interval: float = 5.0):
        # service_name → {instance_id → ServiceInstance}
        self._services: Dict[str, Dict[str, ServiceInstance]] = defaultdict(dict)
        self._lock = threading.RLock()

        # Watch callbacks: service_name → list of callbacks
        self._watchers: Dict[str, List[Callable]] = defaultdict(list)

        # TTL expiry checker
        self._checker = threading.Thread(
            target=self._ttl_checker_loop,
            args=(ttl_check_interval,),
            daemon=True
        )
        self._checker.start()

    # ── Registration ──────────────────────────────────────────────────────────

    def register(self, service_name: str, host: str, port: int,
                 ttl: float = 30.0,
                 metadata: Optional[Dict[str, str]] = None) -> str:
        """
        Register a new service instance.
        Returns the instance_id to use for heartbeats and deregistration.
        """
        instance_id = str(uuid.uuid4())
        instance = ServiceInstance(
            instance_id=instance_id,
            service_name=service_name,
            host=host,
            port=port,
            ttl=ttl,
            metadata=metadata or {}
        )

        with self._lock:
            self._services[service_name][instance_id] = instance
            logger.info(f"[Registry] Registered {service_name} @ {host}:{port} "
                        f"(id={instance_id[:8]})")
            self._notify_watchers(service_name)

        return instance_id

    def deregister(self, service_name: str, instance_id: str):
        """Explicitly deregister an instance (graceful shutdown)."""
        with self._lock:
            if instance_id in self._services.get(service_name, {}):
                del self._services[service_name][instance_id]
                logger.info(f"[Registry] Deregistered {service_name} "
                             f"(id={instance_id[:8]})")
                self._notify_watchers(service_name)

    def heartbeat(self, service_name: str, instance_id: str) -> bool:
        """
        Renew the TTL for a registered instance.
        Returns False if the instance is not found (re-registration needed).
        """
        with self._lock:
            instance = self._services.get(service_name, {}).get(instance_id)
            if instance is None:
                return False
            instance.touch()
            return True

    # ── Discovery ─────────────────────────────────────────────────────────────

    def get_instances(self, service_name: str,
                      healthy_only: bool = True) -> List[ServiceInstance]:
        """Return all (optionally healthy) instances for a service."""
        with self._lock:
            instances = list(self._services.get(service_name, {}).values())
            if healthy_only:
                instances = [i for i in instances if i.healthy and not i.is_expired()]
            return instances

    def get_instance(self, service_name: str,
                     instance_id: str) -> Optional[ServiceInstance]:
        with self._lock:
            return self._services.get(service_name, {}).get(instance_id)

    # ── Watch API ─────────────────────────────────────────────────────────────

    def watch(self, service_name: str, callback: Callable[[List[ServiceInstance]], None]):
        """
        Register a callback fired whenever instances of a service change.
        callback receives the current healthy instance list.
        """
        with self._lock:
            self._watchers[service_name].append(callback)
            # Fire immediately with current state
            current = self.get_instances(service_name)
        callback(current)

    def _notify_watchers(self, service_name: str):
        """Must be called with self._lock held."""
        instances = [
            i for i in self._services.get(service_name, {}).values()
            if i.healthy and not i.is_expired()
        ]
        for cb in self._watchers.get(service_name, []):
            try:
                threading.Thread(target=cb, args=(instances,), daemon=True).start()
            except Exception as e:
                logger.error(f"[Registry] Watcher callback error: {e}")

    # ── TTL checker ───────────────────────────────────────────────────────────

    def _ttl_checker_loop(self, interval: float):
        """
        Background thread: periodically removes expired instances.
        An instance is expired if it hasn't sent a heartbeat within its TTL.
        """
        while True:
            time.sleep(interval)
            with self._lock:
                for service_name, instances in list(self._services.items()):
                    expired = [
                        iid for iid, inst in instances.items()
                        if inst.is_expired()
                    ]
                    for iid in expired:
                        inst = instances.pop(iid)
                        logger.warning(
                            f"[Registry] TTL expired: {service_name} @ "
                            f"{inst.address} (id={iid[:8]})"
                        )
                    if expired:
                        self._notify_watchers(service_name)

    def stats(self) -> dict:
        with self._lock:
            return {
                svc: {
                    "total": len(instances),
                    "healthy": sum(
                        1 for i in instances.values()
                        if i.healthy and not i.is_expired()
                    )
                }
                for svc, instances in self._services.items()
            }


# ── Service client with client-side load balancing ────────────────────────────

class ServiceClient:
    """
    Client-side load balancer backed by the service registry.
    Maintains a local list of healthy instances, updated via watch callback.
    Uses round-robin to select instances.
    """

    def __init__(self, registry: ServiceRegistry, service_name: str):
        self._service_name = service_name
        self._instances: List[ServiceInstance] = []
        self._index = 0
        self._lock = threading.Lock()

        # Subscribe to changes — list stays fresh automatically
        registry.watch(service_name, self._on_instances_changed)

    def _on_instances_changed(self, instances: List[ServiceInstance]):
        with self._lock:
            self._instances = instances
            self._index = self._index % max(len(instances), 1)
            logger.debug(f"[Client] {self._service_name}: "
                         f"{len(instances)} healthy instances")

    def resolve(self) -> Optional[ServiceInstance]:
        """Get the next healthy instance (round-robin)."""
        with self._lock:
            if not self._instances:
                return None
            instance = self._instances[self._index % len(self._instances)]
            self._index = (self._index + 1) % len(self._instances)
            return instance

    def resolve_address(self) -> Optional[str]:
        """Convenience: get just the host:port string."""
        instance = self.resolve()
        return instance.address if instance else None


# ── Heartbeat sender (runs inside each service instance) ─────────────────────

class HeartbeatSender:
    """Runs in a service instance to renew its registry TTL."""

    def __init__(self, registry: ServiceRegistry,
                 service_name: str, instance_id: str, ttl: float):
        self._registry = registry
        self._service_name = service_name
        self._instance_id = instance_id
        self._interval = ttl / 3    # send every ttl/3 seconds
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._running = False

    def start(self):
        self._running = True
        self._thread.start()

    def stop(self):
        self._running = False

    def _run(self):
        while self._running:
            time.sleep(self._interval)
            ok = self._registry.heartbeat(self._service_name, self._instance_id)
            if not ok:
                logger.warning(
                    f"[Heartbeat] Instance {self._instance_id[:8]} not found "
                    f"in registry — may need to re-register"
                )
```

## Usage

```python
# Create a shared registry (in production: this is Consul/etcd)
registry = ServiceRegistry(ttl_check_interval=5.0)

# Service instances register themselves on startup
id1 = registry.register("payment-service", "10.0.1.10", 8080, ttl=15.0)
id2 = registry.register("payment-service", "10.0.1.11", 8080, ttl=15.0)
id3 = registry.register("payment-service", "10.0.1.12", 8080, ttl=15.0)

# Each instance starts sending heartbeats
hb1 = HeartbeatSender(registry, "payment-service", id1, ttl=15.0)
hb2 = HeartbeatSender(registry, "payment-service", id2, ttl=15.0)
# hb3 deliberately not started → will expire after 15s

hb1.start()
hb2.start()

# Client resolves service addresses (round-robin)
client = ServiceClient(registry, "payment-service")

for i in range(6):
    addr = client.resolve_address()
    print(f"Request {i+1} → {addr}")

print(registry.stats())
# {'payment-service': {'total': 3, 'healthy': 3}}

# Wait for instance 3 to expire
time.sleep(20)
print(registry.stats())
# {'payment-service': {'total': 2, 'healthy': 2}}  ← instance 3 removed

# Graceful shutdown
registry.deregister("payment-service", id1)
hb1.stop()
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Persistence | Registry state lost on restart; Consul/etcd persist to disk |
| Distributed consensus | Multiple registry nodes agree via Raft; no split-brain |
| DNS interface | Services discoverable via DNS (`svc.consul`) |
| Health check types | Active HTTP probes, not just heartbeat |
| ACLs | Services only visible to authorized clients |
| Multi-datacenter | Federation across regions |
| gRPC/HTTP transport | Our registry is in-process; real ones communicate over network |
| Metrics | Registration counts, TTL expirations, watch latency |

---

## Key Takeaways

- TTL + heartbeat is the core mechanism: instance proves liveness by renewing within TTL window
- The watch API is what makes client-side LB reactive — no polling needed
- Heartbeat interval = TTL/3: three missed heartbeats before expiry → tolerates brief network hiccups
- Deregistration on graceful shutdown eliminates the full TTL wait before traffic drains
- The registry itself must be highly available — it's infrastructure that everything depends on
