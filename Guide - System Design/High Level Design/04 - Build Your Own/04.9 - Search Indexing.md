# Build Your Own: Search Indexing

> **Revision tags:** #build-your-own #search  
> **Related:** [[03.10 - Search Systems]]

---

## Goal

Build a minimal in-memory search engine with:
- Inverted index construction from documents
- Text analysis pipeline (tokenize, lowercase, stop words, stemming)
- TF-IDF scoring for relevance ranking
- Boolean AND query support
- Incremental index updates (add/remove documents)

---

## Core Design

```
[Documents] → Analyzer → [Inverted Index]
                              │
                              ▼
[Query] → Analyzer → Token lookup → Intersection → TF-IDF Ranking → Results
```

---

## Implementation

```python
import re
import math
from collections import defaultdict
from typing import Dict, List, Set, Optional, Tuple

# ── Text Analyzer ─────────────────────────────────────────────────────────────

STOP_WORDS = {
    "a", "an", "the", "and", "or", "but", "in", "on", "at",
    "to", "for", "of", "with", "by", "is", "was", "are", "be",
    "it", "as", "this", "that", "from", "have", "has", "had"
}

def simple_stem(word: str) -> str:
    """
    Very simplified stemmer — strips common English suffixes.
    Production systems use Porter Stemmer or Snowball.
    """
    if len(word) <= 3:
        return word
    suffixes = ["ing", "tion", "ness", "ment", "ers", "es", "ed", "er", "ly", "s"]
    for suffix in suffixes:
        if word.endswith(suffix) and len(word) - len(suffix) >= 3:
            return word[:-len(suffix)]
    return word

def analyze(text: str, use_stemming: bool = True) -> List[str]:
    """
    Full text analysis pipeline:
      1. Lowercase
      2. Tokenize (split on non-alphanumeric)
      3. Remove stop words
      4. Stem
    """
    text = text.lower()
    tokens = re.findall(r'[a-z0-9]+', text)
    tokens = [t for t in tokens if t not in STOP_WORDS and len(t) > 1]
    if use_stemming:
        tokens = [simple_stem(t) for t in tokens]
    return tokens


# ── Inverted Index ────────────────────────────────────────────────────────────

class SearchIndex:
    """
    In-memory inverted index with TF-IDF scoring.

    Inverted index structure:
        term → { doc_id: term_frequency, ... }

    Document registry:
        doc_id → { title, body, field_lengths, ... }
    """

    def __init__(self):
        # term → {doc_id → term_frequency}
        self._index: Dict[str, Dict[str, int]] = defaultdict(dict)

        # doc_id → document data + metadata
        self._documents: Dict[str, dict] = {}

        # doc_id → set of terms (for removal)
        self._doc_terms: Dict[str, Set[str]] = defaultdict(set)

    # ── Indexing ──────────────────────────────────────────────────────────────

    def add_document(self, doc_id: str, title: str, body: str,
                     extra_fields: Optional[dict] = None):
        """
        Index a document.
        Title tokens get a 2× weight boost (simulate field boosting).
        """
        # Combine title (boosted) and body
        title_tokens = analyze(title)
        body_tokens  = analyze(body)

        # Count term frequencies (title counts double)
        term_freq: Dict[str, int] = defaultdict(int)
        for token in title_tokens:
            term_freq[token] += 2    # title boost
        for token in body_tokens:
            term_freq[token] += 1

        # Store document
        self._documents[doc_id] = {
            "title": title,
            "body": body,
            "term_count": len(body_tokens) + len(title_tokens),
            **(extra_fields or {})
        }

        # Update inverted index
        for term, freq in term_freq.items():
            self._index[term][doc_id] = freq
            self._doc_terms[doc_id].add(term)

    def remove_document(self, doc_id: str):
        """Remove a document from the index."""
        if doc_id not in self._documents:
            return

        # Remove from all term postings
        for term in self._doc_terms.get(doc_id, set()):
            self._index[term].pop(doc_id, None)
            if not self._index[term]:
                del self._index[term]

        del self._documents[doc_id]
        del self._doc_terms[doc_id]

    # ── Querying ──────────────────────────────────────────────────────────────

    def search(self, query: str, top_k: int = 10) -> List[dict]:
        """
        Search for documents matching all query terms (AND semantics).
        Results ranked by TF-IDF score.
        """
        query_terms = analyze(query)
        if not query_terms:
            return []

        # AND: find docs containing ALL query terms
        candidate_sets = [
            set(self._index.get(term, {}).keys())
            for term in query_terms
        ]
        matching_doc_ids = candidate_sets[0]
        for s in candidate_sets[1:]:
            matching_doc_ids = matching_doc_ids & s

        if not matching_doc_ids:
            return []

        # Score each candidate
        scores = [
            (doc_id, self._score(doc_id, query_terms))
            for doc_id in matching_doc_ids
        ]

        # Sort by score descending, return top_k
        scores.sort(key=lambda x: x[1], reverse=True)

        return [
            {
                "doc_id": doc_id,
                "score": round(score, 4),
                **{k: v for k, v in self._documents[doc_id].items()
                   if k not in ("term_count",)}
            }
            for doc_id, score in scores[:top_k]
        ]

    # ── TF-IDF Scoring ────────────────────────────────────────────────────────

    def _tf(self, doc_id: str, term: str) -> float:
        """
        Term Frequency: normalized by document length.
        TF = count(term in doc) / total terms in doc
        """
        freq = self._index.get(term, {}).get(doc_id, 0)
        doc_length = self._documents[doc_id]["term_count"]
        return freq / doc_length if doc_length > 0 else 0.0

    def _idf(self, term: str) -> float:
        """
        Inverse Document Frequency: log(N / df)
        Rare terms get higher IDF (more discriminative).
        """
        N = len(self._documents)
        df = len(self._index.get(term, {}))   # docs containing term
        if df == 0:
            return 0.0
        return math.log(N / df)

    def _score(self, doc_id: str, query_terms: List[str]) -> float:
        """
        TF-IDF score = sum of TF-IDF for each query term.
        """
        return sum(
            self._tf(doc_id, term) * self._idf(term)
            for term in query_terms
        )

    # ── Stats ─────────────────────────────────────────────────────────────────

    def stats(self) -> dict:
        return {
            "documents": len(self._documents),
            "unique_terms": len(self._index),
            "index_size_approx": sum(
                len(postings) for postings in self._index.values()
            )
        }
```

## Usage

```python
index = SearchIndex()

# Index some documents
index.add_document("p1",
    title="Python programming language",
    body="Python is a high-level programming language known for simplicity and readability.")

index.add_document("p2",
    title="Java programming guide",
    body="Java is a strongly typed object-oriented programming language used for enterprise applications.")

index.add_document("p3",
    title="Machine learning with Python",
    body="Python is widely used in machine learning and data science for its rich ecosystem of libraries.")

index.add_document("p4",
    title="Database design patterns",
    body="Good database design involves normalization and efficient indexing strategies.")

# Search
results = index.search("python programming")
for r in results:
    print(f"{r['score']:.4f}  {r['title']}")

# Output (TF-IDF ranked):
# 0.0891  Python programming language         ← highest: both terms, title match
# 0.0445  Machine learning with Python        ← 'python' in title, not 'programming'
# 0.0223  Java programming guide              ← 'programming' matches, not 'python'

# Exact match advantage
results = index.search("machine learning")
print(results[0]["title"])   # Machine learning with Python

# Update: remove stale doc, add updated version
index.remove_document("p1")
index.add_document("p1",
    title="Python 3.12 programming language",
    body="Python 3.12 introduced new performance improvements and syntax features.")

print(index.stats())
# {'documents': 4, 'unique_terms': 67, 'index_size_approx': 134}
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Persistent storage | Index stored in memory; Elasticsearch uses Lucene segments on disk |
| BM25 scoring | More accurate than TF-IDF; adds term saturation + length normalization |
| Phrase queries | "exact phrase" matching — requires positional index (store token positions) |
| Fuzzy matching | "pythno" → "python"; uses edit distance / n-gram index |
| Faceted search | Filter by category, price range — requires structured field indexing |
| Distributed sharding | Index split across nodes; query fans out to all shards |
| Near-real-time indexing | Lucene segments flushed on interval; new docs visible in < 1s |
| Synonym expansion | "buy" → "purchase", "shop" |
| Query DSL | AND, OR, NOT, field-specific queries, boosts |
| Autocomplete | Prefix trie or edge n-gram index |

---

## Key Takeaways

- The inverted index is just a dictionary of term → {doc: count}
- The hard work is text analysis — two documents match only if their tokens overlap after the same pipeline is applied to both
- TF-IDF answers "how important is this term to this document vs the corpus" — it's two multiplied numbers
- AND query = set intersection across posting lists — this is O(min posting list size), not O(corpus)
- Title boosting is field-level weighting — a simple form of what Elasticsearch's field boosts do
