# Decorators

#python #functions #decorators

> **In one line:** A decorator is a function that takes a function and returns a replacement, applied with `@` at definition time. With closures and `functools.wraps` you can build retries, timing, caching, auth checks and registration, and decorator factories add parameters with one more layer.

---

## The Idea

```python
@timed
def handler(): ...
```

is exactly:

```python
def handler(): ...
handler = timed(handler)
```

That is all the `@` syntax does. It runs **once, when the `def` executes** (usually at import time), not on every call.

---

## A Correct Decorator

```python
import functools, time

def timed(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            print(f"{func.__qualname__} took {time.perf_counter() - start:.4f}s")
    return wrapper
```

Three things every decorator needs:

| Part | Why |
|---|---|
| `*args, **kwargs` | Works for any signature ([[02.1 - Parameters and Arguments]]) |
| `return func(...)` | Do not swallow the return value. Forgetting it is the most common decorator bug. |
| **`@functools.wraps(func)`** | Copies `__name__`, `__qualname__`, `__doc__`, `__module__`, `__annotations__`, and sets `__wrapped__`. Without it, every decorated function is called `wrapper`, which breaks logging, debugging, FastAPI routing, Celery task names and `inspect.signature`. |

## Decorators With Arguments: Factories

`@retry(times=3)` calls `retry(times=3)` first, and **its return value** is the decorator. That is three layers:

```python
import asyncio, functools, random

def retry(times=3, *, exceptions=(Exception,), base_delay=0.1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions:
                    if attempt == times:
                        raise
                    time.sleep(base_delay * 2 ** (attempt - 1) * random.uniform(0.5, 1.5))
        return wrapper
    return decorator

@retry(times=5, exceptions=(ConnectionError,))
def fetch(): ...
```

```
retry(times=5)  ──► decorator  ──► decorator(fetch) ──► wrapper
 (factory)          (the real decorator)               (replaces fetch)
```

Backoff with jitter is explained properly in [[12.2 - Timeouts Retries and Jitter]]. In real code, use `tenacity` or `stamina` rather than writing your own, but write one once so you can read theirs.

### Supporting both `@deco` and `@deco(...)`

```python
def deco(func=None, *, level="info"):
    if func is None:
        return functools.partial(deco, level=level)
    @functools.wraps(func)
    def wrapper(*a, **kw): ...
    return wrapper
```

## Async Functions Need Async Wrappers

A sync wrapper around a coroutine function returns the coroutine without awaiting it, so timing measures nothing and exceptions escape the `try`:

```python
import inspect

def timed(func):
    if inspect.iscoroutinefunction(func):
        @functools.wraps(func)
        async def awrapper(*args, **kwargs):
            start = time.perf_counter()
            try:
                return await func(*args, **kwargs)
            finally:
                log(func, time.perf_counter() - start)
        return awrapper

    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        ...
    return wrapper
```

⚠️ A sync `time.sleep` inside a retry decorator applied to an `async def` blocks the whole event loop. See [[01.6 - The Blocking Call Problem]].

## Stacking

```python
@a
@b
def f(): ...
# f = a(b(f)) — the decorator nearest the function is applied first and runs innermost
```

Order matters. `@app.get("/")` above `@cache` registers the cached version. Reverse them and the route is registered with the uncached function, and the cache wraps something nobody calls.

---

## Decorators That Do Not Wrap: Registration

Some decorators just record the function and return it unchanged:

```python
ROUTES = {}

def route(path):
    def register(func):
        ROUTES[path] = func
        return func          # unchanged
    return register

@route("/health")
def health(): return "ok"
```

That is how `@app.get`, `@celery.task`, `@pytest.fixture` and `@click.command` work at heart: registration plus some metadata.

## Class Decorators and Decorator Classes

```python
# A decorator applied to a class — modify or register it
def register_model(cls):
    MODELS[cls.__name__] = cls
    return cls

@register_model
class User: ...
```

`@dataclass` is the famous class decorator ([[07.2 - Dataclasses]]). And a class with `__call__` can be a decorator when you need state with methods:

```python
class CountCalls:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.calls = 0
    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)
```

⚠️ An instance like this used on a **method** loses `self` binding, because it is not a descriptor. Function-based decorators bind correctly. The reason is in [[06.5 - Descriptors]].

## The Standard Library's Best Decorators

| Decorator | Does | Watch out for |
|---|---|---|
| `@functools.cache` / `@lru_cache(maxsize=N)` | Memoise by arguments | Arguments must be hashable. On methods, the cache holds `self`, a memory leak for short-lived objects. Unbounded `cache` grows forever. |
| `@functools.cached_property` | Compute once per instance, store in `__dict__` | Not thread-safe since 3.12 (the lock was removed). Does not work with `__slots__`. |
| `@functools.singledispatch` | Choose an implementation by the first argument's type | Dispatches on type only, not value |
| `@contextlib.contextmanager` | Turn a generator into a context manager | [[04.6 - Context Managers]] |
| `@property`, `@classmethod`, `@staticmethod` | Descriptors for classes | [[06.1 - Classes and Instances]] |
| `@typing.override`, `@typing.final` | Hints for type checkers (3.12) | No runtime effect |

```python
from functools import singledispatch
from datetime import datetime
from decimal import Decimal

@singledispatch
def to_json(obj):
    raise TypeError(f"cannot serialise {type(obj).__name__}")

@to_json.register
def _(obj: datetime): return obj.isoformat()

@to_json.register
def _(obj: Decimal): return str(obj)
```
