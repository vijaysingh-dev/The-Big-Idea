# Build Your Own: Message Queue

> **Revision tags:** #build-your-own #messaging  
> **Related:** [[03.8 - Message Queues and Kafka]]

---

## Goal

Build a message queue that supports:
- Producer publishes messages
- Consumer polls and receives messages (one consumer per message)
- Explicit ACK / NACK — unacked messages are redelivered
- Dead letter queue after N failures
- Persistence to disk (basic)

This is the RabbitMQ / SQS model, not the Kafka log model.

---

## Core Design

```
[Producer] → enqueue(message)
                  │
            [Queue Storage]
              - pending: deque of messages
              - in_flight: {msg_id → (message, ack_deadline, delivery_count)}
                  │
[Consumer] → poll() → receive message (moved to in_flight)
           → ack(msg_id) → message deleted
           → nack(msg_id) → message returned to pending (or DLQ if max retries)

[Redelivery loop] → background thread
  checks in_flight for messages past ack_deadline
  → moves them back to pending
```

## Implementation

```python
import uuid
import time
import json
import threading
import os
from collections import deque
from dataclasses import dataclass, field
from typing import Dict, Optional, List

# ── Message ──────────────────────────────────────────────────────────────────

@dataclass
class Message:
    body: dict
    id: str = field(default_factory=lambda: str(uuid.uuid4()))
    delivery_count: int = 0
    enqueued_at: float = field(default_factory=time.time)

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "body": self.body,
            "delivery_count": self.delivery_count,
            "enqueued_at": self.enqueued_at
        }

    @classmethod
    def from_dict(cls, d: dict) -> "Message":
        m = cls(body=d["body"], id=d["id"])
        m.delivery_count = d["delivery_count"]
        m.enqueued_at = d["enqueued_at"]
        return m


# ── In-flight entry ──────────────────────────────────────────────────────────

@dataclass
class InFlightEntry:
    message: Message
    ack_deadline: float   # unix timestamp — redeliver if not acked by this


# ── Message Queue ─────────────────────────────────────────────────────────────

class MessageQueue:
    def __init__(self,
                 name: str,
                 visibility_timeout: int = 30,
                 max_delivery_attempts: int = 3,
                 persist_path: Optional[str] = None):
        self.name = name
        self.visibility_timeout = visibility_timeout
        self.max_delivery_attempts = max_delivery_attempts
        self.persist_path = persist_path

        self._pending: deque[Message] = deque()
        self._in_flight: Dict[str, InFlightEntry] = {}
        self._dlq: List[Message] = []
        self._lock = threading.Lock()

        # Load persisted messages if path given
        if persist_path:
            self._load()

        # Background thread: redeliver timed-out in-flight messages
        self._redelivery_thread = threading.Thread(
            target=self._redelivery_loop, daemon=True
        )
        self._redelivery_thread.start()

    # ── Producer API ─────────────────────────────────────────────────────────

    def enqueue(self, body: dict) -> str:
        """Add a message to the queue. Returns message ID."""
        message = Message(body=body)
        with self._lock:
            self._pending.append(message)
            self._persist()
        return message.id

    # ── Consumer API ─────────────────────────────────────────────────────────

    def poll(self) -> Optional[Message]:
        """
        Retrieve the next available message.
        Message is hidden from other consumers until ack/nack or timeout.
        """
        with self._lock:
            if not self._pending:
                return None

            message = self._pending.popleft()
            message.delivery_count += 1

            # Place in in-flight with deadline
            self._in_flight[message.id] = InFlightEntry(
                message=message,
                ack_deadline=time.time() + self.visibility_timeout
            )
            self._persist()
            return message

    def ack(self, message_id: str) -> bool:
        """Acknowledge successful processing — message is deleted."""
        with self._lock:
            if message_id not in self._in_flight:
                return False
            del self._in_flight[message_id]
            self._persist()
            return True

    def nack(self, message_id: str) -> bool:
        """
        Negative acknowledge — processing failed.
        Returns message to pending queue, or moves to DLQ after max attempts.
        """
        with self._lock:
            if message_id not in self._in_flight:
                return False

            entry = self._in_flight.pop(message_id)
            message = entry.message

            if message.delivery_count >= self.max_delivery_attempts:
                # Exhausted retries — send to dead letter queue
                print(f"[DLQ] Message {message.id} moved to DLQ after "
                      f"{message.delivery_count} attempts")
                self._dlq.append(message)
            else:
                # Return to pending for retry
                self._pending.appendleft(message)

            self._persist()
            return True

    # ── Dead Letter Queue ─────────────────────────────────────────────────────

    def get_dlq_messages(self) -> List[Message]:
        with self._lock:
            return list(self._dlq)

    def replay_dlq(self):
        """Move all DLQ messages back to pending for reprocessing."""
        with self._lock:
            while self._dlq:
                msg = self._dlq.pop(0)
                msg.delivery_count = 0
                self._pending.append(msg)
            self._persist()

    # ── Redelivery loop ───────────────────────────────────────────────────────

    def _redelivery_loop(self):
        """
        Background thread: check in-flight messages whose visibility timeout
        has expired and return them to the pending queue.
        """
        while True:
            time.sleep(5)
            now = time.time()
            with self._lock:
                timed_out = [
                    msg_id for msg_id, entry in self._in_flight.items()
                    if entry.ack_deadline < now
                ]
                for msg_id in timed_out:
                    entry = self._in_flight.pop(msg_id)
                    print(f"[Redelivery] Message {msg_id} timed out, requeuing "
                          f"(attempt {entry.message.delivery_count})")

                    if entry.message.delivery_count >= self.max_delivery_attempts:
                        self._dlq.append(entry.message)
                    else:
                        self._pending.appendleft(entry.message)

    # ── Persistence ───────────────────────────────────────────────────────────

    def _persist(self):
        """Append-style persistence: write current state to disk."""
        if not self.persist_path:
            return
        state = {
            "pending": [m.to_dict() for m in self._pending],
            "in_flight": {k: v.message.to_dict() for k, v in self._in_flight.items()},
            "dlq": [m.to_dict() for m in self._dlq]
        }
        with open(self.persist_path, "w") as f:
            json.dump(state, f)

    def _load(self):
        """Load persisted state from disk on startup."""
        if not os.path.exists(self.persist_path):
            return
        with open(self.persist_path) as f:
            state = json.load(f)
        self._pending = deque(Message.from_dict(m) for m in state.get("pending", []))
        self._dlq = [Message.from_dict(m) for m in state.get("dlq", [])]
        # In-flight messages at restart: return to pending (consumer may have crashed)
        for m_dict in state.get("in_flight", {}).values():
            self._pending.appendleft(Message.from_dict(m_dict))

    def stats(self) -> dict:
        with self._lock:
            return {
                "pending": len(self._pending),
                "in_flight": len(self._in_flight),
                "dlq": len(self._dlq)
            }
```

## Usage Example

```python
# Producer
q = MessageQueue("orders", visibility_timeout=10, max_delivery_attempts=3)

q.enqueue({"order_id": 1, "action": "process_payment"})
q.enqueue({"order_id": 2, "action": "process_payment"})
q.enqueue({"order_id": 3, "action": "process_payment"})

print(q.stats())  # {'pending': 3, 'in_flight': 0, 'dlq': 0}

# Consumer — happy path
msg = q.poll()
print(f"Processing order {msg.body['order_id']}")
# ... do work ...
q.ack(msg.id)
print(q.stats())  # {'pending': 2, 'in_flight': 0, 'dlq': 0}

# Consumer — failure path
msg = q.poll()
print(f"Processing order {msg.body['order_id']}")
# ... something fails ...
q.nack(msg.id)
print(q.stats())  # {'pending': 2, 'in_flight': 0, 'dlq': 0} (returned to front)

# After max_delivery_attempts failures — goes to DLQ
for _ in range(3):
    msg = q.poll()
    q.nack(msg.id)
print(q.stats())  # {'pending': 1, 'in_flight': 0, 'dlq': 1}
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Network transport | Our queue is in-process; real queues communicate over TCP |
| Multiple queues | Queue management, routing, exchange layer (RabbitMQ) |
| Consumer groups | Multiple consumers sharing work, group-level offset tracking |
| Durable persistence | We do basic JSON dump; production uses append-only log with fsync |
| At-least-once over network | Requires two-phase commit or WAL-based delivery |
| Ordering guarantees | Our deque is FIFO per queue; across consumers, ordering is hard |
| Horizontal scaling | Partitioning messages across multiple queue shards |
| Message TTL | Expire unprocessed messages after N seconds |
| Backpressure | Producer blocks when queue depth exceeds threshold |
| Monitoring | Queue depth, consume rate, DLQ size metrics |

---

## Key Takeaways

- The essential state is: **pending** (waiting) + **in_flight** (being processed)
- The visibility timeout is the mechanism that enables at-least-once delivery — hidden, not deleted
- The redelivery loop is a background concern, not on the hot path
- Persistence at startup must move in-flight back to pending — the consumer holding them may have crashed
- DLQ is just another queue — messages that failed too many times, quarantined for investigation
