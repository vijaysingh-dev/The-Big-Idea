# Saga Pattern

## At a Glance

|||
|---|---|
|**Type**|Backend / Enterprise|
|**Intent**|Manage distributed transactions across microservices using a sequence of local transactions, with compensating transactions for rollback|
|**Frequency in Backend**|★★★★☆ — any microservice workflow spanning multiple services|

---

## The Problem It Solves

In microservices, you can't use a single DB transaction across services. When placing an order, you need:

1. Reserve inventory (Inventory Service)
2. Charge payment (Payment Service)
3. Create order record (Order Service)
4. Send confirmation (Notification Service)

If step 3 fails, steps 1 and 2 must be _undone_ (compensated). There's no distributed rollback — you do it manually.

---

## Two Saga Styles

```
Choreography:                    Orchestration:
Each service reacts to events    Central orchestrator directs steps

OrderService                     SagaOrchestrator
    │ emits OrderCreated              │
    ▼                                 ├──▶ InventoryService.reserve()
InventoryService                      │    ◀── OK
    │ emits InventoryReserved         │
    ▼                                 ├──▶ PaymentService.charge()
PaymentService                        │    ◀── OK
    │ emits PaymentCharged            │
    ▼                                 ├──▶ OrderService.confirm()
NotificationService                   │    ◀── OK
                                      │
No central coordinator           Central state, easier to debug
Hard to follow the flow          Single point of failure risk
```

## Full Backend Example: Order Placement Saga (Orchestration)

```python
# saga_state.py
from enum import Enum
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from datetime import datetime
from typing import Optional, List
from decimal import Decimal

class SagaStatus(Enum):
    STARTED = "STARTED"
    COMPENSATING = "COMPENSATING"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"

class StepStatus(Enum):
    PENDING = "PENDING"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"
    COMPENSATED = "COMPENSATED"

@dataclass
class SagaStep:
    name: str
    status: StepStatus = StepStatus.PENDING
    result: Optional[dict] = None
    error: Optional[str] = None
    compensated_at: Optional[datetime] = None

@dataclass
class OrderSagaState:
    saga_id: UUID
    order_id: UUID
    user_id: UUID
    items: list
    payment_method_id: str
    status: SagaStatus = SagaStatus.STARTED
    steps: List[SagaStep] = field(default_factory=list)
    created_at: datetime = field(default_factory=datetime.now)
    
    # Results from completed steps (needed for compensation)
    reservation_id: Optional[str] = None
    payment_transaction_id: Optional[str] = None
    

# saga_orchestrator.py
class OrderPlacementSaga:
    """
    Orchestrates order placement across:
    - InventoryService (reserve stock)
    - PaymentService (charge customer)
    - OrderService (create order record)
    - NotificationService (send confirmation)
    
    Each step has a compensation action for rollback.
    """
    
    def __init__(self, inventory_client, payment_client, 
                 order_repo, notification_client, saga_repo):
        self._inventory = inventory_client
        self._payments = payment_client
        self._orders = order_repo
        self._notifications = notification_client
        self._saga_repo = saga_repo
    
    def execute(self, command: PlaceOrderCommand) -> OrderSagaState:
        state = OrderSagaState(
            saga_id=uuid4(),
            order_id=uuid4(),
            user_id=command.user_id,
            items=command.items,
            payment_method_id=command.payment_method_id
        )
        self._saga_repo.save(state)
        
        # Execute steps in order — compensate backwards on failure
        steps = [
            self._step_reserve_inventory,
            self._step_charge_payment,
            self._step_create_order,
            self._step_send_notification,
        ]
        
        completed_steps = []
        
        for step in steps:
            try:
                step(state)
                completed_steps.append(step)
                self._saga_repo.save(state)
            except Exception as e:
                logger.error(f"Saga {state.saga_id} failed at {step.__name__}: {e}")
                state.status = SagaStatus.COMPENSATING
                self._saga_repo.save(state)
                
                # Compensate in reverse order
                self._compensate(state, completed_steps)
                
                state.status = SagaStatus.FAILED
                self._saga_repo.save(state)
                raise SagaFailedError(f"Order placement failed: {e}") from e
        
        state.status = SagaStatus.COMPLETED
        self._saga_repo.save(state)
        return state
    
    # ── Forward steps ────────────────────────────────────────
    
    def _step_reserve_inventory(self, state: OrderSagaState):
        step = SagaStep("reserve_inventory")
        try:
            result = self._inventory.reserve(
                items=state.items,
                order_id=state.order_id,
                idempotency_key=f"{state.saga_id}:inventory"
            )
            state.reservation_id = result.reservation_id
            step.status = StepStatus.COMPLETED
            step.result = {"reservation_id": result.reservation_id}
        except Exception as e:
            step.status = StepStatus.FAILED
            step.error = str(e)
            state.steps.append(step)
            raise
        state.steps.append(step)
    
    def _step_charge_payment(self, state: OrderSagaState):
        step = SagaStep("charge_payment")
        total = self._calculate_total(state.items)
        
        try:
            result = self._payments.charge(
                method_id=state.payment_method_id,
                amount=total,
                order_id=state.order_id,
                idempotency_key=f"{state.saga_id}:payment"
            )
            state.payment_transaction_id = result.transaction_id
            step.status = StepStatus.COMPLETED
            step.result = {"transaction_id": result.transaction_id}
        except PaymentDeclinedError as e:
            step.status = StepStatus.FAILED
            step.error = f"Payment declined: {e}"
            state.steps.append(step)
            raise
        state.steps.append(step)
    
    def _step_create_order(self, state: OrderSagaState):
        step = SagaStep("create_order")
        try:
            order = Order(
                id=state.order_id,
                user_id=state.user_id,
                items=state.items,
                payment_transaction_id=state.payment_transaction_id,
                status=OrderStatus.CONFIRMED
            )
            self._orders.save(order)
            step.status = StepStatus.COMPLETED
        except Exception as e:
            step.status = StepStatus.FAILED
            step.error = str(e)
            state.steps.append(step)
            raise
        state.steps.append(step)
    
    def _step_send_notification(self, state: OrderSagaState):
        """Non-critical step — failure here shouldn't fail the saga."""
        step = SagaStep("send_notification")
        try:
            self._notifications.send_order_confirmation(
                user_id=state.user_id,
                order_id=state.order_id
            )
            step.status = StepStatus.COMPLETED
        except Exception as e:
            # Notification failure is non-critical — log and continue
            logger.warning(f"Notification failed for saga {state.saga_id}: {e}")
            step.status = StepStatus.FAILED
            step.error = str(e)
            # Don't re-raise — notification failure doesn't fail the saga
        state.steps.append(step)
    
    # ── Compensation (rollback) ──────────────────────────────
    
    def _compensate(self, state: OrderSagaState, completed_steps: list):
        """Execute compensation in reverse order."""
        compensations = {
            self._step_reserve_inventory: self._compensate_inventory,
            self._step_charge_payment: self._compensate_payment,
            self._step_create_order: self._compensate_order,
        }
        
        for step in reversed(completed_steps):
            compensation = compensations.get(step)
            if compensation:
                try:
                    compensation(state)
                except Exception as e:
                    # Compensation failure — needs human intervention
                    logger.critical(
                        f"COMPENSATION FAILED for saga {state.saga_id}: {e}. "
                        f"Manual intervention required."
                    )
                    alert_ops(state.saga_id, step.__name__, str(e))
    
    def _compensate_inventory(self, state: OrderSagaState):
        if state.reservation_id:
            self._inventory.release_reservation(
                reservation_id=state.reservation_id,
                idempotency_key=f"{state.saga_id}:inventory:compensate"
            )
            logger.info(f"Saga {state.saga_id}: inventory reservation released")
    
    def _compensate_payment(self, state: OrderSagaState):
        if state.payment_transaction_id:
            self._payments.refund(
                transaction_id=state.payment_transaction_id,
                idempotency_key=f"{state.saga_id}:payment:compensate"
            )
            logger.info(f"Saga {state.saga_id}: payment refunded")
    
    def _compensate_order(self, state: OrderSagaState):
        order = self._orders.find_by_id(state.order_id)
        if order:
            order.cancel("Saga compensation")
            self._orders.save(order)
    
    def _calculate_total(self, items: list) -> Decimal:
        return sum(Decimal(str(item["price"])) * item["quantity"] for item in items)
```

## Choreography Example (Event-driven)

```python
# Each service reacts to events and emits its own
# No central orchestrator

# inventory_service.py
class InventoryEventHandler:
    def on_order_placed(self, event: OrderPlacedEvent):
        """Triggered by OrderService publishing OrderPlaced."""
        try:
            reservation = self._inventory.reserve(event.items, event.order_id)
            event_bus.publish(InventoryReserved(
                order_id=event.order_id,
                reservation_id=reservation.id
            ))
        except InsufficientStockError:
            event_bus.publish(InventoryReservationFailed(
                order_id=event.order_id,
                reason="Insufficient stock"
            ))

# payment_service.py
class PaymentEventHandler:
    def on_inventory_reserved(self, event: InventoryReservedEvent):
        try:
            payment = self._payments.charge(event.order_id)
            event_bus.publish(PaymentCharged(order_id=event.order_id, ...))
        except PaymentDeclinedError:
            event_bus.publish(PaymentFailed(order_id=event.order_id, ...))
    
    def on_inventory_reservation_failed(self, event):
        # No payment was attempted — nothing to compensate
        pass

# inventory_service.py (compensation)
class InventoryEventHandler:
    def on_payment_failed(self, event: PaymentFailedEvent):
        """Compensate: release reservation when payment fails."""
        self._inventory.release(order_id=event.order_id)
        event_bus.publish(InventoryReleased(order_id=event.order_id))
```

## Orchestration vs Choreography

||Orchestration|Choreography|
|---|---|---|
|Control|Central orchestrator|Distributed, event-driven|
|Visibility|Easy to see full flow|Hard — must trace events|
|Coupling|Orchestrator knows all services|Services know only events|
|Debugging|Easier|Harder — event chain tracing|
|Adding steps|Modify orchestrator|Add new consumer|
|Failure|Orchestrator is SPOF|No SPOF|
|Use when|Complex flows, clear owner|Loose coupling priority|

---

## Critical Saga Requirements

1. **Idempotent steps** — every step must be safe to retry
2. **Idempotent compensations** — compensations may run multiple times
3. **Durable saga state** — persist state before/after each step
4. **Dead letter queue** — if compensation fails, alert ops + DLQ
5. **Timeouts** — saga must not run forever; timeout + compensate

---

## Tradeoffs

|Pro|Con|
|---|---|
|Distributed transactions without 2PC|Complex compensation logic|
|Services stay independently deployable|Eventual consistency only|
|Failure is explicit and handled|No atomicity guarantee|
|Full audit trail (orchestration)|Testing distributed sagas is hard|
