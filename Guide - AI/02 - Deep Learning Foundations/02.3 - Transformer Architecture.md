# Transformer Architecture

## Overview

The Transformer (Vaswani et al., 2017) replaced RNNs as the dominant architecture for sequence modeling. It uses **attention exclusively** — no recurrence, no convolution.

Core properties:

- Fully parallelizable (unlike RNNs)
- Captures long-range dependencies directly
- Scales with data and compute better than any prior architecture

---

## Full Architecture Diagram

```
INPUT TOKENS: ["The", "cat", "sat"]
       │
  [Token Embedding]      ← learned lookup table: token_id → vector
       │
  [Positional Encoding]  ← adds position information (tokens have no inherent order)
       │
  ┌────▼────────────────────────────────────┐
  │         TRANSFORMER BLOCK × N           │
  │                                         │
  │  ┌─────────────────────────────────┐    │
  │  │    Multi-Head Self-Attention    │    │
  │  └──────────────┬──────────────────┘    │
  │                 │                       │
  │         [Add & LayerNorm]  ← residual   │
  │                 │                       │
  │  ┌──────────────▼──────────────────┐    │
  │  │    Feed-Forward Network (FFN)   │    │
  │  └──────────────┬──────────────────┘    │
  │                 │                       │
  │         [Add & LayerNorm]  ← residual   │
  └─────────────────┼───────────────────────┘
                    │
              (repeat N times)
                    │
            [Final LayerNorm]
                    │
            [Linear + Softmax]  ← project to vocab size → token probabilities
```

## Component-by-Component Breakdown

### 1. Token Embeddings

Each token in the vocabulary maps to a learned dense vector (e.g., 768 or 4096 dimensions). This is a simple lookup table:

```python
# Embedding table: vocab_size × d_model
embedding = nn.Embedding(vocab_size, d_model)
x = embedding(token_ids)   # shape: (batch, seq_len, d_model)
```

The model learns what these vectors should be during training. Similar tokens end up with similar vectors.

---

### 2. Positional Encoding

Attention has no notion of order — it treats the sequence as a set, not a sequence. Position encoding injects order information.

**Original paper (sinusoidal)**:

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

Each dimension of the position vector oscillates at a different frequency, creating a unique "fingerprint" per position. The math ensures that relative positions have consistent relationships.

**Learned positional encoding** (used in GPT-2, BERT): just another embedding table, but indexed by position. Simpler, often works as well or better within training distribution.

**RoPE (Rotary Position Embedding)**: used in Llama, Mistral, modern LLMs. Encodes position as a rotation applied to Q and K vectors at attention time. Better extrapolation to longer sequences.

---

### 3. Multi-Head Self-Attention

Covered in depth in [[02.2 - Attention Mechanism]]. Summary:

- Each token attends to all others (or masked-to-left for decoders)
- Multiple heads run in parallel, each learning different relationship types
- Output is a weighted blend of value vectors

---

### 4. Residual Connections (Add & LayerNorm)

After every sublayer (attention, FFN), the input is **added back** to the output:

```
output = LayerNorm(x + sublayer(x))
```

Why residual connections?

- **Gradient flow**: during backprop, gradients can skip layers. Without residuals, gradients vanish in deep networks.
- **Identity preservation**: if a layer learns nothing useful, it can just output ~0 and the residual carries the signal unchanged.
- This is why you can stack 96+ layers in GPT-4 class models.

Why LayerNorm?

- Normalizes activations across the feature dimension (not the batch)
- Stabilizes training, allows higher learning rates
- Modern models use **RMSNorm** (simpler, faster — Llama family)

---

### 5. Feed-Forward Network (FFN)

After attention, each position independently passes through a 2-layer MLP:

```python
def ffn(x, W1, W2):
    return W2 @ gelu(W1 @ x)    # expand then contract
```

Typical expansion: `d_model → 4*d_model → d_model`

For `d_model = 4096`: FFN goes `4096 → 16384 → 4096`.

**What does the FFN do?** Current research suggests FFNs act as **key-value memory stores** — they store factual associations learned during pretraining. Attention routes information; FFN retrieves stored knowledge.

---

### 6. Output Layer

After N transformer blocks, a final linear projection maps from `d_model` to `vocab_size`, followed by softmax to produce a probability distribution over the next token:

```python
logits = x @ W_lm_head          # (seq_len, d_model) → (seq_len, vocab_size)
probs = softmax(logits, dim=-1)  # probability over next token at each position
```

During training: cross-entropy loss against the actual next token. During inference: sample or take argmax from this distribution.

## Hyperparameters That Matter

|Parameter|GPT-2 (small)|GPT-3 (175B)|Llama 3 (8B)|
|---|---|---|---|
|`d_model`|768|12288|4096|
|`n_layers`|12|96|32|
|`n_heads`|12|96|32|
|`d_head`|64|128|128|
|`vocab_size`|50257|50257|128256|
|`context_length`|1024|2048|8192|

Scaling these up (more layers, wider model, more data) is what produced the jump from GPT-2 to GPT-3 to GPT-4 class capabilities.

---

## Why Transformers Beat RNNs

|Property|RNN/LSTM|Transformer|
|---|---|---|
|Long-range dependencies|Weak (vanishing gradient)|Strong (direct attention)|
|Parallelism|None (sequential)|Full (all positions in parallel)|
|Training speed|Slow|Fast|
|Memory usage|O(n)|O(n²) for attention|
|Scaling behavior|Plateaus|Continues improving with scale|

The O(n²) attention cost is the Transformer's main weakness. For very long sequences (books, codebases), this requires engineering solutions (sparse attention, flash attention, ring attention).
