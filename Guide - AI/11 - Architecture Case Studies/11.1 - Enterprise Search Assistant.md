# Architecture Case Study: Enterprise Search Assistant

## Product Definition

An enterprise search assistant allows employees to query all company knowledge (Confluence, Slack, Drive, Jira, GitHub, etc.) in natural language and receive cited answers.

**Core value**: Replace hours of digging through tools with one natural language query.

---

## Requirements Clarification

```
Functional:
- Natural language Q&A over all connected knowledge sources
- Results scoped to user's permissions (never show unauthorized content)
- Cited answers with clickable source links
- Multi-turn conversation (follow-up questions)
- Freshness: index updated within 1 hour of source changes

Non-functional:
- Latency: first token < 1s, full response < 5s (P95)
- Availability: 99.5% (internal tool; enterprise SLA)
- Scale: 10K employees, ~2K DAU, peak 200 concurrent queries
- Compliance: SOC 2 Type II, data stays within company VPC
```

## Retrieval Design

```python
async def enterprise_search(query, user_id, config):
    # 1. Transform query
    rewritten = await rewrite_query(query, user_id)  # resolve pronouns, expand
    
    # 2. Parallel retrieval
    dense_future = vector_store.search(await embed(rewritten), top_k=50)
    sparse_future = bm25_store.search(rewritten, top_k=50)
    dense, sparse = await asyncio.gather(dense_future, sparse_future)
    
    # 3. Fuse
    fused = rrf_fusion(dense, sparse)[:50]
    
    # 4. Permission filter (critical — before reranker)
    user_groups = await get_user_groups(user_id)
    authorized = [r for r in fused if is_authorized(r, user_id, user_groups)]
    
    # 5. Rerank
    reranked = await reranker.rerank(query, authorized[:20])
    
    # 6. Return top-10 for context
    return reranked[:10]
```

## Cost Analysis

```
Per-query costs (at scale):
  Embedding (query): $0.00002
  LLM call (4K input + 500 output tokens): $0.015
  Reranker (API): $0.001
  Total per query: ~$0.016

At 2,000 DAU × 10 queries/day:
  20,000 queries/day × $0.016 = $320/day = ~$9,600/month

Optimization applied:
  - Embedding cache (80% hit rate) → saves $3.2/day
  - GPT-4o-mini for query rewrite → saves $1/day
  - Prompt caching for repeated context → saves $40/day
  Optimized: ~$6,400/month (-33%)
```

## Alternatives Rejected

|Alternative|Rejected Because|
|---|---|
|Elasticsearch only|No ANN; poor semantic search for natural language queries|
|Pinecone|Cost at enterprise scale; US-only data residency doesn't meet EU requirements|
|Single-model approach|GPT-4 for everything = 5× higher cost; gpt-4o-mini insufficient for synthesis|
|Full re-index nightly|1-hour freshness requirement not met|

## Observability Stack

- **Traces**: Langfuse (self-hosted in VPC) — every query traced with stages
- **Metrics**: Prometheus + Grafana — latency, cache hit rate, retrieval quality proxy scores
- **Logs**: Elasticsearch (existing) — structured JSON logs
- **Evals**: Weekly automated run against 200-example golden set
- **Alerts**: PagerDuty for: latency P95 > 5s, error rate > 2%, eval score drops > 5%
