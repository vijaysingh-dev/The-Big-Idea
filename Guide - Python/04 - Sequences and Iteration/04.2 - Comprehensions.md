# Comprehensions

#python #comprehensions #iteration

> **In one line:** Comprehensions build lists, dicts and sets from an iterable in one readable expression, run faster than an equivalent append loop, and have their own scope. Use them for transforming and filtering; switch to a loop when there are side effects or more than two clauses.

---

## The Four Forms

```python
squares   = [x * x for x in range(10)]                  # list
evens     = {x for x in nums if x % 2 == 0}             # set
by_id     = {u.id: u for u in users}                    # dict
total     = sum(x * x for x in range(10))               # generator expression (lazy)
```

The general shape, read left to right as nested loops:

```python
[expr for a in A if cond_a for b in B(a) if cond_b]

# is equivalent to
result = []
for a in A:
    if cond_a:
        for b in B(a):
            if cond_b:
                result.append(expr)
```

### Conditional expression vs filter

```python
[x if x > 0 else 0 for x in nums]    # transform every item (if/else BEFORE for)
[x for x in nums if x > 0]           # keep some items (if AFTER for)
```

---

## Scope

Since Python 3, the loop variable of a comprehension does not leak:

```python
x = "outer"
[x for x in range(3)]
print(x)          # 'outer'
```

The walrus operator `:=` deliberately **does** bind in the enclosing scope, which lets you reuse a computed value:

```python
results = [y for x in data if (y := expensive(x)) is not None]
```

⚠️ **Class bodies are a scope trap.** A comprehension inside a class body cannot see class-level names in its expression (only the outermost iterable is evaluated in class scope):

```python
class Config:
    PREFIX = "app_"
    KEYS = ["a", "b"]
    NAMES = [PREFIX + k for k in KEYS]    # NameError: PREFIX (KEYS works — it is the outermost iterable)
```

Compute it outside the class, or in a method or `__init_subclass__`.

---

## Why They Are Faster

A comprehension avoids looking up `result.append` and calling it as a Python method on every iteration. It uses a dedicated `LIST_APPEND` bytecode. Since 3.12 (PEP 709) comprehensions are also **inlined**, with no separate function object created per call. Expect roughly 20–40% faster than the equivalent `for` plus `append` loop. It does not matter for 10 items; it matters in hot loops.

## Generator Expressions: Lazy

```python
sum(order.total for order in orders)          # no intermediate list
any(u.is_admin for u in users)                # stops at the first True
max((len(line) for line in open(path)), default=0)
```

Parentheses make it a generator. It produces items one at a time, uses constant memory, and can be consumed **only once** ([[04.3 - Iterables and Iterators]]). When it is the only argument, the extra parentheses can be dropped.

| Use a list comprehension when | Use a generator expression when |
|---|---|
| You need the result more than once, or need `len` / indexing | You consume it once (`sum`, `any`, `"".join`, a `for` loop) |
| The data is small | The data is large or infinite |

---

## When Not to Use One

```python
# ❌ Side effects: use a loop
[send_email(u) for u in users]          # builds a useless list of None

# ❌ Too clever
[(a, b) for a in xs if a % 2 for b in ys if b > a if (a + b) % 3]

# ✅ A loop with names reads better
pairs = []
for a in xs:
    if a % 2 == 0:
        continue
    for b in ys:
        if b > a and (a + b) % 3:
            pairs.append((a, b))
```

The rule used by most style guides: **at most two `for` clauses or one `for` plus one `if`**, otherwise write a loop or a helper generator function ([[04.4 - Generators]]).

## Useful Patterns

```python
# Invert a dict (values must be unique and hashable)
inv = {v: k for k, v in d.items()}

# Group without defaultdict
from itertools import groupby
groups = {k: list(g) for k, g in groupby(sorted(rows, key=key_fn), key=key_fn)}

# Flatten one level
flat = [item for sub in nested for item in sub]

# Dict from two lists
mapping = dict(zip(keys, values, strict=True))     # strict=True (3.10+) raises on length mismatch

# Filter a dict
public = {k: v for k, v in payload.items() if not k.startswith("_")}

# Matrix transpose
transposed = [list(row) for row in zip(*matrix)]
```

`zip(..., strict=True)` deserves a habit: silent truncation of mismatched lists is a real data-loss bug.
