# Case Study: Payment Gateway

**Difficulty:** Hard | **Patterns:** Strategy, Facade, Chain of Responsibility, State, Observer, Saga

---

## Step 1: Requirements

### Functional

- Accept payments via multiple providers (Stripe, Razorpay, PayPal)
- Support: card, UPI, net banking, wallet
- Process refunds (full and partial)
- Handle payment disputes
- Webhook receiver from payment providers
- Idempotent payment creation (no double charges)
- Retry transient failures

### Non-Functional

- Zero payment data loss
- Idempotency is critical
- PCI-DSS compliance (no raw card data stored)
- Audit trail for all operations
- < 3s response time for payment initiation
- 99.99% availability

### Scope Boundary (for this LLD)

- Payment initiation and status management
- Refund processing
- Webhook handling and reconciliation
- Not in scope: dispute management, fraud scoring, reporting

---

## Step 2: Core Entities

```
Payment          → lifecycle: PENDING → AUTHORIZED → CAPTURED → REFUNDED
PaymentMethod    → card/UPI/wallet token (never raw card data)
Refund           → linked to payment, partial or full
PaymentProvider  → Stripe, Razorpay, PayPal
WebhookEvent     → raw event from provider
PaymentAuditLog  → immutable record of every state change
```

# payment_models.py
from enum import Enum
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from decimal import Decimal
from datetime import datetime
from typing import Optional, List

class PaymentStatus(Enum):
    PENDING = "PENDING"           # created, not yet submitted
    PROCESSING = "PROCESSING"     # submitted to provider
    AUTHORIZED = "AUTHORIZED"     # authorized, not captured
    CAPTURED = "CAPTURED"         # money taken
    FAILED = "FAILED"             # terminal failure
    CANCELLED = "CANCELLED"       # cancelled before capture
    REFUNDED = "REFUNDED"         # fully refunded
    PARTIALLY_REFUNDED = "PARTIALLY_REFUNDED"

VALID_TRANSITIONS = {
    PaymentStatus.PENDING:               {PaymentStatus.PROCESSING, PaymentStatus.CANCELLED},
    PaymentStatus.PROCESSING:            {PaymentStatus.AUTHORIZED, PaymentStatus.CAPTURED, PaymentStatus.FAILED},
    PaymentStatus.AUTHORIZED:            {PaymentStatus.CAPTURED, PaymentStatus.CANCELLED},
    PaymentStatus.CAPTURED:              {PaymentStatus.REFUNDED, PaymentStatus.PARTIALLY_REFUNDED},
    PaymentStatus.PARTIALLY_REFUNDED:    {PaymentStatus.REFUNDED},
    PaymentStatus.FAILED:                set(),
    PaymentStatus.CANCELLED:             set(),
    PaymentStatus.REFUNDED:              set(),
}

@dataclass
class Money:
    amount: Decimal
    currency: str
    
    def __post_init__(self):
        if self.amount < 0:
            raise ValueError("Amount cannot be negative")
    
    def subtract(self, other: "Money") -> "Money":
        assert self.currency == other.currency
        return Money(self.amount - other.amount, self.currency)

@dataclass
class PaymentAuditEntry:
    entry_id: UUID = field(default_factory=uuid4)
    payment_id: UUID = None
    action: str = ""
    from_status: Optional[str] = None
    to_status: Optional[str] = None
    actor: str = ""
    provider_reference: Optional[str] = None
    metadata: dict = field(default_factory=dict)
    occurred_at: datetime = field(default_factory=datetime.now)


class Payment:
    """
    Payment aggregate root.
    Enforces status transitions and maintains audit log.
    """
    
    def __init__(self, payment_id: UUID, order_id: UUID, amount: Money,
                 provider: str, idempotency_key: str):
        self.id = payment_id
        self.order_id = order_id
        self.amount = amount
        self.provider = provider
        self.idempotency_key = idempotency_key
        self._status = PaymentStatus.PENDING
        self._provider_reference: Optional[str] = None
        self._refunds: List["Refund"] = []
        self._audit_log: List[PaymentAuditEntry] = []
        self._events = []
        
        self._record_audit("payment.created", actor="system")
    
    @property
    def status(self) -> PaymentStatus: return self._status
    
    @property
    def provider_reference(self) -> Optional[str]: return self._provider_reference
    
    @property
    def refunded_amount(self) -> Money:
        total = sum(r.amount.amount for r in self._refunds if r.status == "COMPLETED")
        return Money(total, self.amount.currency)
    
    @property
    def refundable_amount(self) -> Money:
        return self.amount.subtract(self.refunded_amount)
    
    def mark_processing(self):
        self._transition_to(PaymentStatus.PROCESSING)
    
    def mark_authorized(self, provider_ref: str):
        self._transition_to(PaymentStatus.AUTHORIZED)
        self._provider_reference = provider_ref
        self._record_audit("payment.authorized", provider_reference=provider_ref)
    
    def mark_captured(self, provider_ref: Optional[str] = None):
        self._transition_to(PaymentStatus.CAPTURED)
        if provider_ref:
            self._provider_reference = provider_ref
        self._record_audit("payment.captured")
        self._events.append(PaymentCaptured(payment_id=self.id, amount=self.amount))
    
    def mark_failed(self, reason: str):
        self._transition_to(PaymentStatus.FAILED)
        self._record_audit("payment.failed", metadata={"reason": reason})
        self._events.append(PaymentFailed(payment_id=self.id, reason=reason))
    
    def initiate_refund(self, amount: Money, reason: str, actor: str) -> "Refund":
        if self._status not in (PaymentStatus.CAPTURED, PaymentStatus.PARTIALLY_REFUNDED):
            raise InvalidStateTransition(f"Cannot refund payment in {self._status} state")
        
        if amount.amount > self.refundable_amount.amount:
            raise RefundExceedsPaymentError(
                f"Refund {amount} exceeds refundable amount {self.refundable_amount}"
            )
        
        refund = Refund(
            refund_id=uuid4(),
            payment_id=self.id,
            amount=amount,
            reason=reason
        )
        self._refunds.append(refund)
        self._record_audit("payment.refund_initiated", actor=actor,
                          metadata={"refund_id": str(refund.id), "amount": str(amount.amount)})
        return refund
    
    def complete_refund(self, refund_id: UUID, provider_ref: str):
        refund = self._find_refund(refund_id)
        refund.complete(provider_ref)
        
        if self.refunded_amount.amount >= self.amount.amount:
            self._transition_to(PaymentStatus.REFUNDED)
        else:
            self._transition_to(PaymentStatus.PARTIALLY_REFUNDED)
        
        self._events.append(RefundCompleted(payment_id=self.id, refund_id=refund_id))
    
    def get_audit_log(self) -> List[PaymentAuditEntry]:
        return list(self._audit_log)
    
    def get_events(self): return list(self._events)
    def clear_events(self): self._events.clear()
    
    def _transition_to(self, new_status: PaymentStatus):
        allowed = VALID_TRANSITIONS.get(self._status, set())
        if new_status not in allowed:
            raise InvalidStateTransition(
                f"Cannot transition payment from {self._status} to {new_status}"
            )
        old = self._status
        self._status = new_status
        self._record_audit("status.changed", from_status=old.value, to_status=new_status.value)
    
    def _record_audit(self, action: str, actor: str = "system", **kwargs):
        self._audit_log.append(PaymentAuditEntry(
            payment_id=self.id, action=action,
            from_status=self._status.value, actor=actor, **kwargs
        ))
    
    def _find_refund(self, refund_id: UUID) -> "Refund":
        refund = next((r for r in self._refunds if r.id == refund_id), None)
        if not refund:
            raise RefundNotFoundError(refund_id)
        return refund


@dataclass
class Refund:
    refund_id: UUID
    payment_id: UUID
    amount: Money
    reason: str
    status: str = "PENDING"
    provider_reference: Optional[str] = None
    created_at: datetime = field(default_factory=datetime.now)
    completed_at: Optional[datetime] = None
    
    @property
    def id(self): return self.refund_id
    
    def complete(self, provider_ref: str):
        self.status = "COMPLETED"
        self.provider_reference = provider_ref
        self.completed_at = datetime.now()


# payment_gateway.py — Provider abstraction (Strategy)
from abc import ABC, abstractmethod

@dataclass
class ChargeRequest:
    amount: Money
    payment_method_token: str
    order_id: str
    idempotency_key: str
    metadata: dict = field(default_factory=dict)

@dataclass
class ChargeResult:
    success: bool
    provider_reference: Optional[str]
    status: str   # "authorized", "captured", "failed"
    error_code: Optional[str] = None
    error_message: Optional[str] = None

class PaymentGateway(ABC):
    @abstractmethod
    def charge(self, request: ChargeRequest) -> ChargeResult: pass
    
    @abstractmethod
    def refund(self, provider_reference: str, amount: Money,
               idempotency_key: str) -> ChargeResult: pass
    
    @abstractmethod
    def supports_currency(self, currency: str) -> bool: pass
    
    @abstractmethod
    def provider_name(self) -> str: pass


class StripeGateway(PaymentGateway):
    def charge(self, request: ChargeRequest) -> ChargeResult:
        try:
            intent = stripe.PaymentIntent.create(
                amount=int(request.amount.amount * 100),
                currency=request.amount.currency.lower(),
                payment_method=request.payment_method_token,
                confirm=True,
                idempotency_key=request.idempotency_key,
                metadata={"order_id": request.order_id}
            )
            return ChargeResult(
                success=True,
                provider_reference=intent.id,
                status="captured" if intent.status == "succeeded" else "authorized"
            )
        except stripe.CardError as e:
            return ChargeResult(success=False, provider_reference=None,
                              status="failed", error_code=e.code,
                              error_message=e.user_message)
    
    def refund(self, provider_reference: str, amount: Money, idempotency_key: str):
        try:
            r = stripe.Refund.create(
                payment_intent=provider_reference,
                amount=int(amount.amount * 100),
                idempotency_key=idempotency_key
            )
            return ChargeResult(success=True, provider_reference=r.id, status="refunded")
        except stripe.StripeError as e:
            return ChargeResult(success=False, provider_reference=None,
                              status="failed", error_message=str(e))
    
    def supports_currency(self, currency: str) -> bool:
        return currency.upper() in {"USD", "EUR", "GBP", "INR"}
    
    def provider_name(self): return "stripe"


# payment_service.py — Facade (Chain of Responsibility for validation)
class PaymentService:
    def __init__(self, payment_repo, gateways: List[PaymentGateway], event_bus):
        self._repo = payment_repo
        self._gateways = gateways
        self._bus = event_bus
    
    def initiate_payment(self, order_id: UUID, amount: Money,
                         payment_method_token: str,
                         idempotency_key: str) -> Payment:
        # Idempotency
        existing = self._repo.find_by_idempotency_key(idempotency_key)
        if existing:
            return existing
        
        gateway = self._select_gateway(amount.currency)
        
        payment = Payment(
            payment_id=uuid4(), order_id=order_id,
            amount=amount, provider=gateway.provider_name(),
            idempotency_key=idempotency_key
        )
        payment.mark_processing()
        self._repo.save(payment)
        
        result = gateway.charge(ChargeRequest(
            amount=amount,
            payment_method_token=payment_method_token,
            order_id=str(order_id),
            idempotency_key=idempotency_key
        ))
        
        if result.success:
            payment.mark_captured(result.provider_reference)
        else:
            payment.mark_failed(result.error_message or "Unknown error")
        
        self._repo.save(payment)
        
        for event in payment.get_events():
            self._bus.publish(event)
        payment.clear_events()
        
        if not result.success:
            raise PaymentFailedError(result.error_message, code=result.error_code)
        
        return payment
    
    def refund_payment(self, payment_id: UUID, amount: Money,
                       reason: str, actor: str) -> Refund:
        payment = self._repo.get_or_raise(payment_id)
        gateway = self._get_gateway(payment.provider)
        
        refund = payment.initiate_refund(amount, reason, actor)
        
        idempotency_key = f"refund:{payment.id}:{refund.id}"
        result = gateway.refund(payment.provider_reference, amount, idempotency_key)
        
        if result.success:
            payment.complete_refund(refund.id, result.provider_reference)
        
        self._repo.save(payment)
        
        for event in payment.get_events():
            self._bus.publish(event)
        payment.clear_events()
        
        return refund
    
    def _select_gateway(self, currency: str) -> PaymentGateway:
        for gateway in self._gateways:
            if gateway.supports_currency(currency):
                return gateway
        raise UnsupportedCurrencyError(f"No gateway supports {currency}")
    
    def _get_gateway(self, provider_name: str) -> PaymentGateway:
        for gateway in self._gateways:
            if gateway.provider_name() == provider_name:
                return gateway
        raise ValueError(f"Unknown gateway: {provider_name}")

## Step 4: Patterns Used

|Pattern|Where|Why|
|---|---|---|
|**Strategy**|`PaymentGateway`|Swap Stripe/Razorpay/PayPal without changing service|
|**State**|`Payment._status`|Enforce valid transitions, prevent double-capture|
|**Facade**|`PaymentService`|Clean entry point hiding gateway + repo + event complexity|
|**Observer**|Domain events|`PaymentCaptured` triggers order fulfillment, analytics|
|**Command**|`ChargeRequest`|Encapsulates payment request — serializable for retry/queue|

## Step 5: Webhook Handling

```python
class WebhookProcessor:
    """Idempotently processes provider webhooks."""
    
    def process(self, provider: str, payload: dict, signature: str) -> bool:
        # 1. Verify signature
        gateway = self._get_gateway(provider)
        gateway.verify_webhook_signature(payload, signature)
        
        # 2. Idempotency — skip if already processed
        event_id = payload["id"]
        if self._processed_events.exists(event_id):
            return True
        
        # 3. Process by event type
        handler = self._handlers.get(payload["type"])
        if handler:
            handler(payload)
        
        # 4. Mark processed
        self._processed_events.mark(event_id)
        return True
    
    def _on_payment_succeeded(self, payload: dict):
        provider_ref = payload["data"]["object"]["id"]
        payment = self._repo.find_by_provider_ref(provider_ref)
        if payment and payment.status == PaymentStatus.AUTHORIZED:
            payment.mark_captured(provider_ref)
            self._repo.save(payment)
```
