# Queues and Events

## Message Queue vs Event Bus vs Event Stream

||Message Queue|Event Bus|Event Stream|
|---|---|---|---|
|Example|SQS, RabbitMQ|EventBridge, SNS|Kafka, Kinesis|
|Consumers|One consumer per message|Multiple fanout|Multiple, replay possible|
|Retention|Until consumed|Ephemeral|Configurable (days/forever)|
|Ordering|FIFO optional|Not guaranteed|Partition-ordered|
|Replay|No|No|Yes|
|Use when|Task queues, work distribution|Decoupled notifications|Event sourcing, audit trail, stream processing|

## Message Queue Patterns

### Point-to-Point (Work Queue)

```
Producer ──▶ Queue ──▶ Consumer 1
                  ──▶ Consumer 2  (competing consumers — each message processed once)
                  ──▶ Consumer 3
```

```python
# producer.py
class OrderQueue:
    def __init__(self, sqs_client, queue_url: str):
        self._sqs = sqs_client
        self._url = queue_url
    
    def enqueue(self, order_id: str, priority: str = "normal"):
        self._sqs.send_message(
            QueueUrl=self._url,
            MessageBody=json.dumps({"order_id": order_id}),
            MessageAttributes={
                "priority": {"StringValue": priority, "DataType": "String"}
            },
            MessageGroupId=order_id   # for FIFO queue — same order always same group
        )

# consumer.py
class OrderProcessor:
    def __init__(self, queue: OrderQueue, order_service: OrderService):
        self._queue = queue
        self._service = order_service
    
    def run(self):
        while True:
            messages = self._queue.receive(max_count=10, wait_seconds=20)
            for msg in messages:
                self._process_message(msg)
    
    def _process_message(self, message):
        try:
            payload = json.loads(message.body)
            order_id = payload["order_id"]
            
            self._service.process_order(order_id)
            
            # Acknowledge: delete from queue only after successful processing
            message.delete()
        
        except Exception as e:
            logger.error(f"Failed to process {message.body}: {e}")
            # Don't delete — SQS will redeliver after visibility timeout
            # After max_receive_count, message moves to DLQ
```

### Fan-out (Pub/Sub)

```
Publisher ──▶ Topic/Exchange ──▶ Queue A (Email service)
                              ──▶ Queue B (Analytics service)
                              ──▶ Queue C (Inventory service)
```

```python
# SNS → SQS fan-out
class OrderEventPublisher:
    def __init__(self, sns_client, topic_arn: str):
        self._sns = sns_client
        self._topic = topic_arn
    
    def publish_order_placed(self, order: Order):
        self._sns.publish(
            TopicArn=self._topic,
            Message=json.dumps({
                "event_type": "ORDER_PLACED",
                "order_id": str(order.id),
                "user_id": str(order.user_id),
                "total": str(order.total),
                "items": [{"product_id": str(i.product_id), "qty": i.qty}
                          for i in order.items]
            }),
            MessageAttributes={
                "event_type": {"StringValue": "ORDER_PLACED", "DataType": "String"}
            }
        )
    # Each subscribed SQS queue gets a copy of this message
```

## Kafka Patterns

### Topics and Partitions

```
Topic: "orders"
  Partition 0: [msg1 (key=user_A), msg4 (key=user_A), msg7 (key=user_A)]
  Partition 1: [msg2 (key=user_B), msg5 (key=user_B)]
  Partition 2: [msg3 (key=user_C), msg6 (key=user_C)]

Key-based partitioning: same key → same partition → ordered per key
Consumer group: each partition consumed by exactly one consumer in group
```

```python
# Kafka producer
from kafka import KafkaProducer
import json

class KafkaOrderEventProducer:
    def __init__(self, bootstrap_servers: str):
        self._producer = KafkaProducer(
            bootstrap_servers=bootstrap_servers,
            value_serializer=lambda v: json.dumps(v).encode(),
            key_serializer=lambda k: k.encode() if k else None,
            acks='all',            # wait for all replicas to confirm
            retries=3,
            enable_idempotence=True  # exactly-once producer semantics
        )
    
    def publish(self, event: dict, partition_key: str = None):
        future = self._producer.send(
            topic="order-events",
            value=event,
            key=partition_key       # routes to same partition — ensures ordering
        )
        # Optionally wait for confirmation
        record_metadata = future.get(timeout=10)
        return record_metadata.offset

# Kafka consumer
from kafka import KafkaConsumer

class KafkaOrderEventConsumer:
    def __init__(self, bootstrap_servers: str, group_id: str):
        self._consumer = KafkaConsumer(
            "order-events",
            bootstrap_servers=bootstrap_servers,
            group_id=group_id,
            auto_offset_reset="earliest",
            enable_auto_commit=False,   # manual commit for at-least-once
            value_deserializer=lambda v: json.loads(v.decode())
        )
    
    def run(self, handler):
        for message in self._consumer:
            try:
                handler(message.value)
                self._consumer.commit()  # commit only after successful processing
            except Exception as e:
                logger.error(f"Failed to process message at offset {message.offset}: {e}")
                # Don't commit — will be reprocessed on restart
```

## Idempotent Consumers

Every message consumer must be idempotent — safe to process the same message multiple times.

```python
class IdempotentOrderEventHandler:
    def __init__(self, order_repo, processed_events_store):
        self._orders = order_repo
        self._processed = processed_events_store
    
    def handle(self, event: dict):
        event_id = event["event_id"]
        
        # Deduplication check
        if self._processed.exists(event_id):
            logger.info(f"Skipping already-processed event {event_id}")
            return
        
        # Process
        order_id = event["order_id"]
        order = self._orders.get(order_id)
        order.mark_shipped(event["tracking_number"])
        self._orders.save(order)
        
        # Mark as processed (in same DB transaction ideally)
        self._processed.mark(event_id)
```

## Dead Letter Queue (DLQ)

```
Processing flow:
  Queue → Consumer → Success → Delete message
                  → Failure → Retry (up to max_receive_count)
                           → Move to DLQ

DLQ handling:
  Monitor DLQ for messages
  Alert when DLQ depth exceeds threshold
  Manual inspection + replay or discard
  Never silently ignore DLQ messages
```

## Ordering Guarantees

```
SQS Standard:    Best-effort ordering. Use FIFO queue for guaranteed order.
SQS FIFO:        Strict ordering within MessageGroup.
Kafka:           Ordered within a partition. Use same key for related events.
RabbitMQ:        Ordered within a single queue + single consumer.

Common mistake: assuming global ordering in distributed queue.
Solution: design consumers to handle out-of-order events,
          or use partition/group keys to ensure per-entity ordering.
```

## Backpressure and Flow Control

```python
# Consumer-side rate limiting — don't overwhelm downstream
class ThrottledConsumer:
    def __init__(self, max_per_second: int):
        self._rate_limiter = RateLimiter(max_per_second)
    
    def consume(self, messages):
        for message in messages:
            self._rate_limiter.acquire()  # blocks if too fast
            self._process(message)

# Producer-side batch publishing
class BatchPublisher:
    def __init__(self, producer, batch_size: int = 100, flush_interval: float = 1.0):
        self._producer = producer
        self._buffer = []
        self._batch_size = batch_size
        self._last_flush = time.time()
    
    def publish(self, event: dict):
        self._buffer.append(event)
        if len(self._buffer) >= self._batch_size or \
           time.time() - self._last_flush >= self._flush_interval:
            self._flush()
    
    def _flush(self):
        if self._buffer:
            self._producer.send_batch(self._buffer)
            self._buffer.clear()
            self._last_flush = time.time()
```
