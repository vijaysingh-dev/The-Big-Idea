# Context Managers

#python #context-managers #resources

> **In one line:** `with` guarantees that setup is paired with teardown, even when an exception is raised. Implement `__enter__`/`__exit__`, or write one generator with `@contextmanager`, and use `ExitStack` when you have a dynamic number of resources.

---

## The Protocol

```python
with expression as target:
    body
```

is roughly:

```python
mgr = expression
target = mgr.__enter__()
try:
    body
except BaseException as exc:
    if not mgr.__exit__(type(exc), exc, exc.__traceback__):
        raise                       # __exit__ returned falsy → re-raise
else:
    mgr.__exit__(None, None, None)
```

| Method | Receives | Returns |
|---|---|---|
| `__enter__(self)` | Nothing | The value bound by `as` (often `self`, not always) |
| `__exit__(self, exc_type, exc, tb)` | Exception info, or three `None`s | **Truthy to suppress the exception.** Almost always return `None`/`False`. |

⚠️ Returning `True` from `__exit__` swallows every exception in the block, including bugs. Only suppress specific exceptions deliberately.

---

## Where You Already Use Them

| Context manager | Setup | Teardown |
|---|---|---|
| `open(path)` | Open the fd | Close it ([[02.7 - File Descriptors and the IO Model]]) |
| `lock` / `threading.Lock()` | Acquire | Release, even on exception |
| `conn.transaction()` | `BEGIN` | `COMMIT`, or `ROLLBACK` on exception |
| `pool.acquire()` | Borrow a connection | Return it to the pool |
| `httpx.Client()` | Create a connection pool | Close every connection |
| `tempfile.TemporaryDirectory()` | mkdir | `rm -rf` |
| `unittest.mock.patch(...)` | Replace an attribute | Restore it |
| `decimal.localcontext()` | Change precision | Restore it |
| `tracer.start_as_current_span()` | Start a span | End it and record any exception |

The pattern behind all of them is **"acquire, then guarantee release"**. Any time you write `try/finally` around a pair of calls, you probably want a context manager.

## Writing One as a Class

```python
import time

class Timer:
    def __enter__(self):
        self.start = time.perf_counter()
        return self
    def __exit__(self, exc_type, exc, tb):
        self.elapsed = time.perf_counter() - self.start
        return False

with Timer() as t:
    work()
print(t.elapsed)
```

Use a class when the manager has state you read afterwards, or is reusable.

## Writing One as a Generator

```python
from contextlib import contextmanager

@contextmanager
def transaction(conn):
    conn.execute("BEGIN")
    try:
        yield conn                  # the body of the `with` runs here
    except Exception:
        conn.execute("ROLLBACK")
        raise
    else:
        conn.execute("COMMIT")
```

Everything before `yield` is `__enter__`, and everything after is `__exit__`. An exception in the `with` body is **raised at the `yield`**, so you can catch it there.

⚠️ **The forgotten `try/finally`.** Without it, teardown does not run when the body raises:

```python
@contextmanager
def chdir(path):
    old = os.getcwd()
    os.chdir(path)
    yield                           # if the body raises, we never chdir back!
    os.chdir(old)

# correct
@contextmanager
def chdir(path):
    old = os.getcwd()
    os.chdir(path)
    try:
        yield
    finally:
        os.chdir(old)
```

(`contextlib.chdir` exists since 3.11, but the pattern is the point.)

`@contextmanager` objects can also be used as decorators, since they inherit `ContextDecorator`:

```python
@transaction_decorator()
def transfer(...): ...
```

## contextlib Highlights

| Tool | Use |
|---|---|
| `suppress(FileNotFoundError)` | Ignore specific exceptions, explicitly: `with suppress(FileNotFoundError): os.remove(p)` |
| `closing(obj)` | Call `obj.close()` on exit, for objects that are not context managers |
| `nullcontext(value)` | A do-nothing manager for optional cases: `with (lock if threaded else nullcontext()):` |
| `redirect_stdout(f)` | Capture prints from code you do not control |
| `ExitStack` | Manage a **dynamic** number of context managers |
| `AsyncExitStack`, `asynccontextmanager`, `aclosing` | The async versions |

### ExitStack

```python
from contextlib import ExitStack

with ExitStack() as stack:
    files = [stack.enter_context(open(p)) for p in paths]   # any number
    stack.callback(log.info, "all files closed")             # arbitrary cleanup
    merge(files)
# every file closed, in reverse order, even if opening the 7th failed
```

`ExitStack` is also the cleanest way to build a resource in several steps and hand it off only if every step succeeds (`stack.pop_all()`).

## Async Context Managers

`async with` calls `__aenter__` and `__aexit__`, which can `await`:

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.pool = await asyncpg.create_pool(DSN)     # startup
    app.state.http = httpx.AsyncClient(timeout=5)
    try:
        yield
    finally:
        await app.state.http.aclose()                    # shutdown
        await app.state.pool.close()

app = FastAPI(lifespan=lifespan)
```

This is the modern way to manage application-wide resources in FastAPI and Starlette. It replaces `@app.on_event("startup")`. It also ties into graceful shutdown ([[12.7 - Graceful Shutdown and Draining]]).

Since 3.10 you can group managers with parentheses:

```python
with (
    open("in.txt") as src,
    open("out.txt", "w") as dst,
):
    dst.write(src.read())
```
