# Prototype Pattern

## At a Glance

|||
|---|---|
|**Type**|Creational|
|**Intent**|Create new objects by cloning existing ones instead of constructing from scratch|
|**Frequency in Backend**|★★☆☆☆ — config templates, test fixtures, caching|

---

## The Problem It Solves

Object creation is expensive (DB lookup, API call, heavy computation) or complex (deep config, nested structure). You need many similar objects — clone a pre-built one instead of reconstructing.

---

## Full Backend Example: Email Template Prototype

```python
# email_template.py
import copy
from dataclasses import dataclass, field
from typing import Optional, List
from abc import ABC, abstractmethod

@dataclass
class Attachment:
    filename: str
    content_type: str
    data: bytes

@dataclass
class EmailTemplate:
    subject: str
    html_body: str
    text_body: str
    from_address: str
    reply_to: Optional[str] = None
    cc: List[str] = field(default_factory=list)
    bcc: List[str] = field(default_factory=list)
    attachments: List[Attachment] = field(default_factory=list)
    tracking_enabled: bool = True
    
    def clone(self) -> "EmailTemplate":
        """Deep clone — mutable lists/attachments must be independent copies."""
        return copy.deepcopy(self)
    
    def with_subject(self, subject: str) -> "EmailTemplate":
        cloned = self.clone()
        cloned.subject = subject
        return cloned
    
    def with_recipient_vars(self, variables: dict) -> "EmailTemplate":
        """Personalize a clone with template variable substitution."""
        cloned = self.clone()
        for key, value in variables.items():
            placeholder = f"{{{{{key}}}}}"
            cloned.html_body = cloned.html_body.replace(placeholder, str(value))
            cloned.text_body = cloned.text_body.replace(placeholder, str(value))
        return cloned


class TemplateRegistry:
    """
    Holds pre-built template prototypes.
    Clone on use — never modify the registry copy.
    """
    
    def __init__(self):
        self._prototypes: dict[str, EmailTemplate] = {}
    
    def register(self, name: str, template: EmailTemplate):
        self._prototypes[name] = template
    
    def get(self, name: str) -> EmailTemplate:
        proto = self._prototypes.get(name)
        if not proto:
            raise KeyError(f"No template registered: {name}")
        return proto.clone()   # always return a clone
    
    def get_personalized(self, name: str, variables: dict) -> EmailTemplate:
        return self.get(name).with_recipient_vars(variables)


# Setup prototype registry at app startup
registry = TemplateRegistry()

# Register base templates (expensive setup done once)
registry.register("order_confirmation", EmailTemplate(
    subject="Your order {{order_id}} has been confirmed",
    from_address="orders@company.com",
    html_body="""
        <h1>Order Confirmed!</h1>
        <p>Hi {{customer_name}},</p>
        <p>Your order <strong>{{order_id}}</strong> is confirmed.</p>
        <p>Total: {{total}}</p>
    """,
    text_body="Hi {{customer_name}}, Order {{order_id}} confirmed. Total: {{total}}",
    tracking_enabled=True
))

registry.register("password_reset", EmailTemplate(
    subject="Reset your password",
    from_address="security@company.com",
    html_body="<p>Click <a href='{{reset_link}}'>here</a> to reset your password.</p>",
    text_body="Reset your password: {{reset_link}}",
    tracking_enabled=False   # don't track security emails
))

# Usage — clone + personalize, original prototype untouched
def send_order_confirmation(order, customer):
    template = registry.get_personalized("order_confirmation", {
        "customer_name": customer.name,
        "order_id": str(order.id),
        "total": str(order.total)
    })
    email_service.send(to=customer.email, template=template)
```

## Deep vs Shallow Copy

```python
import copy

original = EmailTemplate(
    subject="Hello",
    attachments=[Attachment("file.pdf", "application/pdf", b"...")]
)

# Shallow copy — lists are shared (danger!)
shallow = copy.copy(original)
shallow.attachments.append(Attachment("other.pdf", ...))
print(len(original.attachments))  # 2 — original was mutated!

# Deep copy — all nested objects are copied (safe)
deep = copy.deepcopy(original)
deep.attachments.append(Attachment("other.pdf", ...))
print(len(original.attachments))  # 1 — original untouched
```

**Rule for Prototype:** Always deep copy unless you can prove all nested objects are immutable.

## Real-World Backend Uses

|Prototype Use|Why|
|---|---|
|Email/SMS templates|Pre-parse markup once, personalize on clone|
|Default configuration objects|Start from known-good base, override per tenant|
|Test fixtures|Pre-built domain objects, clone and tweak per test|
|Game/simulation objects|Clone a "template" entity, many instances|
|Report templates|Fixed structure, variable data|

---

## When NOT to Use Prototype

- **Simple objects** — just use `ClassName()` constructor
- **Immutable objects** — cloning immutable objects is pointless (they can be shared directly)
- **Object has external resources** (DB connections, file handles) — cloning is dangerous

---

## Tradeoffs

|Pro|Con|
|---|---|
|Avoids expensive re-initialization|Deep copy can be expensive for large objects|
|Flexible — clone then customize|Clone behavior can be surprising (shallow vs deep)|
|Decouples creation from class hierarchy|Circular references can break deep copy|
