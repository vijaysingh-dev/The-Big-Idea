# Build Your Own: Load Balancer

> **Revision tags:** #build-your-own #load-balancing  
> **Related:** [[03.1 - Load Balancers]]

---

## Goal

Build a simple HTTP load balancer to understand how routing, health checking, and algorithm selection work internally. We'll implement round-robin and least-connections, with active health checks.

---

## Core Design

```
Incoming request
    │
    ▼
[Load Balancer]
  ├── Backend Registry (list of backends + health status)
  ├── Routing Algorithm (pick one healthy backend)
  ├── Health Checker (background goroutine / thread)
  └── Proxy (forward request, return response)
```

---

## Implementation (Python)

```python
import threading
import time
import random
import requests
from dataclasses import dataclass, field
from typing import List, Optional
from http.server import HTTPServer, BaseHTTPRequestHandler
from urllib.parse import urlparse

# ── Backend representation ──────────────────────────────────────────────────

@dataclass
class Backend:
    url: str
    healthy: bool = True
    active_connections: int = 0
    total_requests: int = 0
    lock: threading.Lock = field(default_factory=threading.Lock, init=False)

    def increment_connections(self):
        with self.lock:
            self.active_connections += 1
            self.total_requests += 1

    def decrement_connections(self):
        with self.lock:
            self.active_connections -= 1


# ── Routing algorithms ───────────────────────────────────────────────────────

class RoundRobinBalancer:
    def __init__(self, backends: List[Backend]):
        self.backends = backends
        self._index = 0
        self._lock = threading.Lock()

    def next_backend(self) -> Optional[Backend]:
        with self._lock:
            healthy = [b for b in self.backends if b.healthy]
            if not healthy:
                return None
            backend = healthy[self._index % len(healthy)]
            self._index = (self._index + 1) % len(healthy)
            return backend


class LeastConnectionsBalancer:
    def __init__(self, backends: List[Backend]):
        self.backends = backends

    def next_backend(self) -> Optional[Backend]:
        healthy = [b for b in self.backends if b.healthy]
        if not healthy:
            return None
        # Pick the backend with the fewest active connections
        return min(healthy, key=lambda b: b.active_connections)


# ── Health checker ───────────────────────────────────────────────────────────

class HealthChecker:
    """
    Background thread that periodically probes each backend.
    Marks backends unhealthy after consecutive failures.
    """
    def __init__(self, backends: List[Backend], interval: int = 10,
                 path: str = "/health", failure_threshold: int = 3):
        self.backends = backends
        self.interval = interval
        self.path = path
        self.failure_threshold = failure_threshold
        self._failure_counts = {b.url: 0 for b in backends}
        self._thread = threading.Thread(target=self._run, daemon=True)

    def start(self):
        self._thread.start()

    def _run(self):
        while True:
            for backend in self.backends:
                self._check(backend)
            time.sleep(self.interval)

    def _check(self, backend: Backend):
        try:
            response = requests.get(
                f"{backend.url}{self.path}",
                timeout=2
            )
            if response.status_code == 200:
                # Healthy — reset failure count
                self._failure_counts[backend.url] = 0
                if not backend.healthy:
                    print(f"[HealthCheck] Backend {backend.url} recovered ✅")
                backend.healthy = True
            else:
                self._record_failure(backend)
        except Exception:
            self._record_failure(backend)

    def _record_failure(self, backend: Backend):
        self._failure_counts[backend.url] += 1
        if self._failure_counts[backend.url] >= self.failure_threshold:
            if backend.healthy:
                print(f"[HealthCheck] Backend {backend.url} marked UNHEALTHY ❌")
            backend.healthy = False


# ── Proxy handler ────────────────────────────────────────────────────────────

def make_handler(balancer):
    """
    Factory that creates an HTTP handler with access to the balancer.
    """
    class ProxyHandler(BaseHTTPRequestHandler):
        def do_GET(self):
            self._proxy_request("GET")

        def do_POST(self):
            self._proxy_request("POST")

        def _proxy_request(self, method: str):
            backend = balancer.next_backend()
            if not backend:
                self.send_error(503, "No healthy backends available")
                return

            backend.increment_connections()
            try:
                # Forward the request to the selected backend
                url = f"{backend.url}{self.path}"
                content_length = int(self.headers.get("Content-Length", 0))
                body = self.rfile.read(content_length) if content_length else None

                resp = requests.request(method, url, data=body, timeout=5,
                                        headers=dict(self.headers))

                # Return the response to the original client
                self.send_response(resp.status_code)
                for key, value in resp.headers.items():
                    if key.lower() not in ("transfer-encoding", "connection"):
                        self.send_header(key, value)
                self.end_headers()
                self.wfile.write(resp.content)

            except Exception as e:
                self.send_error(502, f"Backend error: {e}")
            finally:
                backend.decrement_connections()

        def log_message(self, format, *args):
            pass  # suppress default logging

    return ProxyHandler


# ── Main ─────────────────────────────────────────────────────────────────────

if __name__ == "__main__":
    backends = [
        Backend("http://localhost:8001"),
        Backend("http://localhost:8002"),
        Backend("http://localhost:8003"),
    ]

    # Choose algorithm: RoundRobinBalancer or LeastConnectionsBalancer
    balancer = LeastConnectionsBalancer(backends)

    # Start health checker
    health_checker = HealthChecker(backends, interval=10)
    health_checker.start()

    # Start load balancer on port 8080
    server = HTTPServer(("0.0.0.0", 8080), make_handler(balancer))
    print("Load balancer running on :8080")
    server.serve_forever()
```

## Testing It

```bash
# Start 3 fake backend servers (use Python's built-in server or Flask)
python -m http.server 8001 &

python -m http.server 8003 &

# Start load balancer
python load_balancer.py

# Send requests — watch them distribute across backends
for i in $(seq 1 9); do curl -s http://localhost:8080/ > /dev/null && echo "Request $i done"; done

# Kill one backend — health checker marks it unhealthy after 3 failures
kill %2  # kill 8002
# After 30s, requests should only go to 8001 and 8003
```

## What's Missing vs Production

| Feature | Production Systems Add |
|---|---|
| SSL/TLS termination | TLS handshake, certificate management |
| Connection pooling | Reuse upstream TCP connections (not new per request) |
| HTTP/2 and gRPC | Protocol-aware proxying |
| Weighted backends | Different weights per backend (canary deployments) |
| Sticky sessions | Cookie/header-based session affinity |
| Rate limiting | Per-client request limits at the LB layer |
| Request retries | Retry on 5xx before returning error to client |
| Circuit breaker | Stop routing to backends under distress |
| L4 vs L7 | Our impl is L7 (parses HTTP); L4 operates at TCP level |
| High availability | LB itself needs redundancy (active-passive pair) |
| Dynamic backend registration | Service discovery integration |

---

## Key Takeaways

- The core is: **pick a backend → proxy the request → track state**
- Health checking is decoupled from routing — background thread, not on request path
- Least-connections requires tracking per-backend active count — must be decremented after response
- The `lock` on Backend is critical — multiple threads read/write `active_connections` concurrently
