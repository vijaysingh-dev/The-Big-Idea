# Observability, Guardrails, and Cost Control for Agents

## Why Agents Need Special Treatment

Agents are harder to operate than simple LLM calls because:

- Multiple LLM calls compound cost and latency
- Tool calls interact with real systems (side effects)
- Loops can run indefinitely without bounds
- Failures are often silent (wrong answer, not an exception)
- Debugging requires tracing multi-step state

Standard API monitoring (uptime, error rate) is insufficient. Agents need purpose-built observability.

## Observability

### What to Trace

Every agent run should produce a full trace:

```python
@dataclass
class AgentTrace:
    trace_id: str
    user_id: str
    task: str
    steps: list[AgentStep]
    total_tokens: int
    total_cost_usd: float
    total_latency_ms: int
    final_answer: str
    success: bool
    failure_reason: Optional[str]

@dataclass
class AgentStep:
    step_number: int
    thought: str              # model's reasoning
    action: str               # tool name or "finish"
    action_input: dict        # tool arguments
    observation: str          # tool result
    tokens_used: int
    latency_ms: int
```

### Trace Storage

Store traces in a way that enables:

- Filtering by task type, user, time
- Debugging specific failures
- Aggregate analytics (average steps, success rate, cost)

```python
# Minimal trace storage
class AgentTraceStore:
    def save(self, trace: AgentTrace):
        # Primary: structured DB for querying
        db.insert("agent_traces", {
            "trace_id": trace.trace_id,
            "user_id": trace.user_id,
            "task": trace.task[:500],  # truncate
            "steps": len(trace.steps),
            "tokens": trace.total_tokens,
            "cost": trace.total_cost_usd,
            "latency_ms": trace.total_latency_ms,
            "success": trace.success,
            "created_at": now(),
        })
        # Secondary: blob storage for full trace (for debugging)
        blob_store.put(f"traces/{trace.trace_id}.json", trace.to_json())
```

## Guardrails

Guardrails are safety checks applied to inputs and outputs to prevent harmful, off-topic, or policy-violating behavior.

### Input Guardrails

Check what the user is asking before the agent acts:

```python
class InputGuardrails:
    def check(self, user_input: str, user_id: str) -> GuardrailResult:
        checks = [
            self.check_prompt_injection(user_input),
            self.check_pii_in_query(user_input),
            self.check_rate_limit(user_id),
            self.check_topic_scope(user_input),   # is this query in-scope for this agent?
        ]
        failures = [c for c in checks if not c.passed]
        if failures:
            return GuardrailResult(blocked=True, reason=failures[0].reason)
        return GuardrailResult(blocked=False)

def check_prompt_injection(text: str) -> CheckResult:
    injection_patterns = [
        "ignore previous instructions",
        "you are now",
        "disregard your system prompt",
        "pretend you are",
    ]
    for pattern in injection_patterns:
        if pattern.lower() in text.lower():
            return CheckResult(passed=False, reason=f"Potential prompt injection: '{pattern}'")
    return CheckResult(passed=True)
```

### Output Guardrails

Check the agent's final answer before returning it to the user:

```python
class OutputGuardrails:
    def check(self, answer: str, task: str, context: list[Chunk]) -> GuardrailResult:
        checks = [
            self.check_pii_in_output(answer),
            self.check_grounded(answer, context),    # hallucination check
            self.check_toxic_content(answer),
            self.check_contradictions(answer, task),
        ]
        failures = [c for c in checks if not c.passed]
        if failures:
            return GuardrailResult(blocked=True, reason=failures[0].reason)
        return GuardrailResult(blocked=False)

def check_grounded(answer: str, context: list[Chunk]) -> CheckResult:
    # Use LLM-as-judge to verify answer is supported by context
    grounded = faithfulness_checker.check(answer, context)
    if grounded < 0.7:
        return CheckResult(passed=False, reason="Answer may not be grounded in retrieved context")
    return CheckResult(passed=True)
```

### Tool Call Guardrails

Check tool calls before execution:

```python
def safe_tool_call(tool_name: str, args: dict, user_permissions: set) -> str:
    # Check tool is in allowlist for this user
    if tool_name not in get_allowed_tools(user_permissions):
        return f"Tool '{tool_name}' is not available"
    
    # Check for dangerous file paths
    if tool_name == "read_file":
        path = args.get("path", "")
        if is_sensitive_path(path):  # /etc/passwd, .env, credentials
            return "Access to this file is not permitted"
    
    # Check for dangerous code patterns before execution
    if tool_name == "execute_python":
        code = args.get("code", "")
        if contains_dangerous_patterns(code):  # os.system, subprocess, network calls
            return "Code contains potentially dangerous operations"
    
    return execute_tool(tool_name, args)
```

### LLM-Based Guardrails (NeMo / Guardrails AI)

For more sophisticated guardrails, use a separate LLM classifier:

```python
# NVIDIA NeMo Guardrails style
class NeMoGuardrail:
    def check_input(self, text):
        return self.classifier.call(
            f"Is this a harmful request? Answer YES/NO: {text}"
        )
```

**Cost vs accuracy tradeoff**: LLM-based guardrails are more accurate but add 100–300ms and cost per check. Use rule-based checks for obvious patterns, LLM-based for nuanced cases.

## Cost Control

### Token Budget Enforcement

```python
class TokenBudget:
    def __init__(self, max_tokens: int):
        self.max_tokens = max_tokens
        self.used = 0
    
    def consume(self, tokens: int):
        self.used += tokens
        if self.used > self.max_tokens:
            raise TokenBudgetExceeded(f"Used {self.used}/{self.max_tokens} tokens")
    
    def remaining(self):
        return max(0, self.max_tokens - self.used)

# Per-user budget
USER_TOKEN_BUDGET_PER_DAY = 100_000  # ~$0.30 at GPT-4o prices

def check_user_budget(user_id: str, estimated_tokens: int) -> bool:
    used_today = token_usage_store.get_daily_usage(user_id)
    return used_today + estimated_tokens <= USER_TOKEN_BUDGET_PER_DAY
```

### Cost Monitoring and Alerts

```python
def track_llm_cost(model: str, input_tokens: int, output_tokens: int) -> float:
    COST_PER_1K_TOKENS = {
        "gpt-4o": {"input": 0.0025, "output": 0.010},
        "gpt-4o-mini": {"input": 0.00015, "output": 0.0006},
        "claude-sonnet-4-5": {"input": 0.003, "output": 0.015},
    }
    rates = COST_PER_1K_TOKENS[model]
    cost = (input_tokens / 1000) * rates["input"] + (output_tokens / 1000) * rates["output"]
    
    metrics.increment("llm.cost_usd", cost, tags={"model": model})
    metrics.increment("llm.input_tokens", input_tokens)
    metrics.increment("llm.output_tokens", output_tokens)
    
    # Alert if daily cost exceeds threshold
    if metrics.get_daily_total("llm.cost_usd") > DAILY_COST_ALERT_THRESHOLD:
        alert("LLM cost spike detected")
    
    return cost
```

### Model Routing for Cost Reduction

Use cheaper/faster models for simple steps, expensive models only when needed:

```python
def route_to_model(task_type: str, context_complexity: str) -> str:
    if task_type == "simple_classification":
        return "gpt-4o-mini"    # $0.15/1M tokens
    elif task_type == "query_rewriting":
        return "gpt-4o-mini"
    elif task_type == "complex_reasoning":
        return "gpt-4o"         # $2.50/1M tokens
    elif task_type == "final_synthesis":
        return "gpt-4o"
    else:
        return "gpt-4o-mini"    # default to cheap
```

This alone can reduce agent costs by 60–80% since most steps don't require the most capable model.

### Caching

```python
import hashlib
from functools import lru_cache

@lru_cache(maxsize=1000)
def cached_embedding(text: str) -> list[float]:
    return embedding_model.encode(text)

def cached_llm_call(prompt: str, model: str) -> str:
    cache_key = hashlib.sha256(f"{model}:{prompt}".encode()).hexdigest()
    cached = redis.get(cache_key)
    if cached:
        return json.loads(cached)
    
    result = llm.call(prompt, model=model)
    redis.setex(cache_key, 3600, json.dumps(result))  # cache 1 hour
    return result
```

Cache aggressively for: embeddings, tool results that are stable (document lookups), repeated query transformations.
