# Architecture Case Study: AI Document Intelligence Platform

## Product Definition

A document intelligence platform extracts structured data from unstructured documents at scale — financial reports, contracts, invoices, research papers. Unlike a search system (find relevant chunks), this system **reads documents and produces structured output**.

**Highly relevant to S&P Global context**: Financial data extraction, earnings report parsing, index methodology documents, regulatory filings (10-K, 10-Q).

---

## Use Cases

- Extract financial metrics from earnings PDFs → populate structured database
- Parse contract clauses → flag risks, extract key terms
- Process invoices → extract line items, totals, vendor info
- Analyze research papers → extract hypotheses, methods, findings
- Process regulatory filings → extract key disclosures

---

## Architecture

```
Document Input (PDF, DOCX, HTML, image)
        │
        ▼
┌──────────────────────┐
│  Document Parser      │  Extract raw text + layout
│  (Unstructured, OCR)  │  Preserve table structure, headings
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Document Classifier  │  What type of document is this?
│  (fast LLM)           │  earnings_report | contract | invoice | research
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Schema Router        │  Which extraction schema applies?
│                       │  Load document-type-specific prompts + schema
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Chunked Extraction   │  Process document in sections
│  (LLM + schema)       │  Extract structured data per section
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Validation + Merge   │  Validate extracted fields
│                       │  Merge section outputs into document-level record
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Structured Output    │  JSON / Database record / API response
│  + Confidence Scores  │  With field-level provenance (which page, which line)
└──────────────────────┘
```

## Document Parsing Layer

```python
from unstructured.partition.auto import partition
from unstructured.documents.elements import Table, Title, NarrativeText

def parse_document(file_path: str) -> ParsedDocument:
    # Unstructured handles PDF, DOCX, HTML, images
    elements = partition(filename=file_path, strategy="hi_res")  # OCR if needed
    
    sections = []
    current_section = {"heading": None, "content": [], "tables": []}
    
    for element in elements:
        if isinstance(element, Title):
            if current_section["content"]:
                sections.append(current_section)
            current_section = {"heading": str(element), "content": [], "tables": []}
        elif isinstance(element, Table):
            current_section["tables"].append(element.metadata.text_as_html)
        elif isinstance(element, NarrativeText):
            current_section["content"].append(str(element))
    
    return ParsedDocument(sections=sections, metadata=extract_metadata(file_path))
```

## Extraction Schemas

from pydantic import BaseModel, Field
from typing import Optional

class EarningsReport(BaseModel):

    invoice_date: str

## Chunked Extraction Pattern

Long documents can't be extracted in a single LLM call (context limits). Process section by section:

```python
EXTRACTION_PROMPT = """Extract structured data from this document section.
Only extract information explicitly stated in the text.
For missing fields, use null.

Document type: {doc_type}
Section: {section_heading}
Content: {section_text}

{tables_if_any}

Extract and return a JSON object matching this schema:
{schema_json}

Return ONLY valid JSON. No explanation."""

def extract_from_document(parsed_doc: ParsedDocument, schema: type[BaseModel]) -> BaseModel:
    # Extract from each section independently
    section_extractions = []
    
    for section in parsed_doc.sections:
        if is_relevant_section(section, schema):
            result = structured_llm_call(
                prompt=EXTRACTION_PROMPT.format(
                    doc_type=parsed_doc.doc_type,
                    section_heading=section["heading"],
                    section_text="\n".join(section["content"])[:4000],
                    tables_if_any=format_tables(section["tables"]),
                    schema_json=schema.model_json_schema()
                ),
                response_format=schema,
            )
            section_extractions.append(result)
    
    # Merge: later sections override earlier for same field (recency)
    # For list fields: concatenate
    return merge_extractions(section_extractions, schema)
```

## Validation and Confidence Scoring

Not all extractions are equally reliable. Score confidence per field:

```python
def validate_extraction(extracted: EarningsReport, source_doc: ParsedDocument) -> ValidationResult:
    results = {}
    
    for field_name, value in extracted.model_dump().items():
        if value is None:
            results[field_name] = {"value": None, "confidence": 0.0, "status": "missing"}
            continue
        
        # Find the text span that supports this extraction
        evidence = find_supporting_evidence(field_name, value, source_doc)
        
        if not evidence:
            results[field_name] = {"value": value, "confidence": 0.3, 
                                    "status": "unverified", "warning": "No source found"}
        else:
            results[field_name] = {
                "value": value, 
                "confidence": 0.9,
                "status": "verified",
                "source": evidence  # {"page": 3, "text": "Revenue grew 12%..."}
            }
    
    return ValidationResult(fields=results, overall_confidence=mean_confidence(results))

def find_supporting_evidence(field_name: str, value, document: ParsedDocument) -> Optional[dict]:
    # Search for the value in the document text
    value_str = str(value)
    for i, section in enumerate(document.sections):
        full_text = " ".join(section["content"])
        if value_str.lower() in full_text.lower():
            return {"section": section["heading"], "text": find_context(value_str, full_text)}
    return None
```

## Handling Tables

Tables are critical for financial documents. Preserve structure:

```python
TABLE_EXTRACTION_PROMPT = """This is an HTML table from a financial document.
Extract all numeric data from the table into structured JSON.

Table:
{table_html}

Return JSON with:
- table_type: what kind of data this table contains
- headers: column headers
- rows: list of row objects using headers as keys
- units: currency/unit for numeric values if stated"""

def extract_table_data(table_html: str, llm) -> dict:
    result = llm.call(TABLE_EXTRACTION_PROMPT.format(table_html=table_html))
    return json.loads(result)
```

## Batch Processing Pipeline

For processing large document volumes (e.g., all S&P 500 earnings reports each quarter):

```python
@celery.task(rate_limit="10/m")  # rate limit: 10 docs/minute (LLM API constraint)
def process_document_batch(doc_ids: list[str]):
    for doc_id in doc_ids:
        try:
            document = document_store.get(doc_id)
            parsed = parse_document(document.file_path)
            schema = get_schema_for_doc_type(classify_document(parsed))
            extracted = extract_from_document(parsed, schema)
            validated = validate_extraction(extracted, parsed)
            
            structured_store.upsert({
                "doc_id": doc_id,
                "extracted_data": extracted.model_dump(),
                "validation": validated.model_dump(),
                "processed_at": now(),
            })
            
        except ExtractionError as e:
            # Don't fail the whole batch on one document
            error_store.record(doc_id, error=str(e))
            continue
```

## Quality and Accuracy Measurement

```python
# Ground truth comparison on known documents
def evaluate_extraction_accuracy(test_set: list[dict]) -> AccuracyReport:
    results = []
    for example in test_set:
        extracted = extract_from_document(example["document"], EarningsReport)
        
        for field in EarningsReport.model_fields:
            expected = example["ground_truth"].get(field)
            actual = getattr(extracted, field, None)
            
            results.append({
                "field": field,
                "correct": values_match(expected, actual),
                "expected": expected,
                "actual": actual,
            })
    
    accuracy_by_field = {
        field: mean(r["correct"] for r in results if r["field"] == field)
        for field in EarningsReport.model_fields
    }
    return AccuracyReport(overall=mean(accuracy_by_field.values()), by_field=accuracy_by_field)
```

Target accuracy benchmarks:

- High-confidence fields (revenue, EPS): > 95% accuracy
- Medium-confidence fields (growth rates): > 85%
- Complex fields (guidance): > 75%
