# Build Your Own: Distributed Lock

> **Revision tags:** #build-your-own #distributed-systems #concurrency  
> **Related:** [[03.12 - Distributed Locks]]

---

## Goal

Build a Redis-based distributed lock with:
- SET NX EX acquire (atomic, with TTL)
- Token-based release (only owner can release)
- Automatic TTL extension via heartbeat (for long-running critical sections)
- Context manager interface for clean usage

---

## Core Design

```
Acquire:
  SET lock_key token NX EX ttl
  → NX: only set if key doesn't exist (mutual exclusion)
  → EX ttl: auto-expire if holder crashes (deadlock prevention)
  → Returns token (UUID) if acquired, None if not

Release:
  Lua script: if GET lock_key == token → DEL lock_key
  → Atomic check-and-delete: only release if we still own it

Heartbeat:
  Background thread: every ttl/3 seconds → EXPIRE lock_key ttl
  → Extend TTL as long as holder is alive
  → Stops when lock is released
```

## Implementation

```python
import uuid
import time
import threading
import logging
import redis
from contextlib import contextmanager
from typing import Optional

logger = logging.getLogger(__name__)

# ── Lua scripts (atomic operations) ──────────────────────────────────────────

# Release: delete key only if value matches our token
RELEASE_SCRIPT = """
if redis.call('get', KEYS[1]) == ARGV[1] then
    return redis.call('del', KEYS[1])
else
    return 0
end
"""

# Extend: reset TTL only if value matches our token
EXTEND_SCRIPT = """
if redis.call('get', KEYS[1]) == ARGV[1] then
    return redis.call('expire', KEYS[1], ARGV[2])
else
    return 0
end
"""


# ── Distributed Lock ──────────────────────────────────────────────────────────

class LockNotAcquiredError(Exception):
    pass

class LockExpiredError(Exception):
    """Raised when the lock TTL expires while held (heartbeat failed)."""
    pass


class DistributedLock:
    """
    Redis-backed distributed lock with heartbeat extension.

    Usage:
        lock = DistributedLock(redis_client, "lock:order:42", ttl=30)

        # Option 1: context manager (recommended)
        with lock:
            process_order(42)

        # Option 2: manual
        if lock.acquire():
            try:
                process_order(42)
            finally:
                lock.release()
    """

    def __init__(self,
                 redis_client: redis.Redis,
                 key: str,
                 ttl: int = 30,
                 retry_delay: float = 0.1,
                 max_retries: int = 0,       # 0 = try once, no retry
                 heartbeat: bool = True):
        self.redis = redis_client
        self.key = key
        self.ttl = ttl
        self.retry_delay = retry_delay
        self.max_retries = max_retries
        self.heartbeat = heartbeat

        self._token: Optional[str] = None
        self._heartbeat_thread: Optional[threading.Thread] = None
        self._heartbeat_stop = threading.Event()

    # ── Acquire ───────────────────────────────────────────────────────────────

    def acquire(self, blocking: bool = True) -> bool:
        """
        Try to acquire the lock.
        Returns True if acquired, False otherwise.
        If blocking=True and max_retries > 0, retries with delay.
        """
        token = str(uuid.uuid4())
        attempts = 0

        while True:
            acquired = self.redis.set(
                self.key,
                token,
                nx=True,       # only set if Not eXists
                ex=self.ttl    # expire after ttl seconds
            )

            if acquired:
                self._token = token
                logger.debug(f"[Lock] Acquired '{self.key}' (token={token[:8]})")

                if self.heartbeat:
                    self._start_heartbeat()

                return True

            attempts += 1
            if not blocking or attempts > self.max_retries:
                logger.debug(f"[Lock] Failed to acquire '{self.key}' — already held")
                return False

            time.sleep(self.retry_delay)

    # ── Release ───────────────────────────────────────────────────────────────

    def release(self) -> bool:
        """
        Release the lock. Only succeeds if we still own it.
        Returns True if released, False if already expired or stolen.
        """
        if self._token is None:
            raise RuntimeError("Cannot release a lock that was not acquired")

        # Stop heartbeat first
        if self._heartbeat_thread:
            self._heartbeat_stop.set()
            self._heartbeat_thread.join(timeout=2)
            self._heartbeat_thread = None
            self._heartbeat_stop.clear()

        result = self.redis.eval(RELEASE_SCRIPT, 1, self.key, self._token)
        token = self._token
        self._token = None

        if result == 1:
            logger.debug(f"[Lock] Released '{self.key}' (token={token[:8]})")
            return True
        else:
            # Lock expired or was taken by someone else
            logger.warning(
                f"[Lock] Failed to release '{self.key}' — "
                f"token mismatch (lock may have expired)"
            )
            return False

    # ── Heartbeat ─────────────────────────────────────────────────────────────

    def _start_heartbeat(self):
        """
        Background thread that extends the lock TTL periodically.
        Extends every ttl/3 seconds — ensures TTL doesn't expire
        while holder is actively working.
        """
        interval = self.ttl / 3

        def heartbeat_loop():
            while not self._heartbeat_stop.wait(timeout=interval):
                if self._token is None:
                    break
                result = self.redis.eval(
                    EXTEND_SCRIPT, 1, self.key, self._token, self.ttl
                )
                if result == 0:
                    # Lock was lost — our token no longer matches
                    logger.error(
                        f"[Lock] Heartbeat failed for '{self.key}' — "
                        f"lock expired or stolen!"
                    )
                    break
                else:
                    logger.debug(f"[Lock] Extended TTL for '{self.key}'")

        self._heartbeat_thread = threading.Thread(
            target=heartbeat_loop, daemon=True
        )
        self._heartbeat_thread.start()

    # ── Context manager ───────────────────────────────────────────────────────

    def __enter__(self):
        acquired = self.acquire()
        if not acquired:
            raise LockNotAcquiredError(
                f"Could not acquire lock '{self.key}' after "
                f"{self.max_retries + 1} attempt(s)"
            )
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
        return False   # don't suppress exceptions

    @property
    def is_held(self) -> bool:
        return self._token is not None


# ── Lock Manager (factory for named locks) ────────────────────────────────────

class LockManager:
    """
    Convenience factory for creating locks with consistent configuration.
    """

    def __init__(self, redis_client: redis.Redis,
                 default_ttl: int = 30,
                 key_prefix: str = "lock"):
        self.redis = redis_client
        self.default_ttl = default_ttl
        self.key_prefix = key_prefix

    def lock(self, name: str, ttl: Optional[int] = None,
             max_retries: int = 0) -> DistributedLock:
        key = f"{self.key_prefix}:{name}"
        return DistributedLock(
            redis_client=self.redis,
            key=key,
            ttl=ttl or self.default_ttl,
            max_retries=max_retries,
            heartbeat=True
        )

    @contextmanager
    def acquire(self, name: str, ttl: Optional[int] = None,
                max_retries: int = 3):
        """Shorthand context manager."""
        lock = self.lock(name, ttl=ttl, max_retries=max_retries)
        with lock:
            yield lock
```

## Usage

```python
import redis

r = redis.Redis(host='localhost', port=6379, decode_responses=True)
locks = LockManager(r, default_ttl=30)

# Context manager — automatic release even on exception
try:
    with locks.acquire("order:42"):
        print("Processing order 42 exclusively...")
        time.sleep(2)   # simulate work — heartbeat keeps lock alive
        print("Done.")
except LockNotAcquiredError:
    print("Order 42 is already being processed by another instance")

# Manual with retry
lock = locks.lock("payment:processing", ttl=60, max_retries=5)
if lock.acquire(blocking=True):
    try:
        charge_card(...)
    finally:
        lock.release()
```

## Testing Concurrency

```python
import concurrent.futures

r = redis.Redis()
locks = LockManager(r, default_ttl=10)
results = []

def try_process(worker_id):
    try:
        with locks.acquire("shared_resource", max_retries=0):
            results.append(f"Worker {worker_id} got lock")
            time.sleep(0.5)
    except LockNotAcquiredError:
        results.append(f"Worker {worker_id} was blocked")

with concurrent.futures.ThreadPoolExecutor(max_workers=5) as pool:
    pool.map(try_process, range(5))

for r in results:
    print(r)

# Output:
# Worker 0 got lock        ← only one gets it
# Worker 1 was blocked
# Worker 2 was blocked
# Worker 3 was blocked
# Worker 4 was blocked
```

## What Production Systems Add

| Feature | What's Missing Here |
|---|---|
| Fencing tokens | Monotonic counter returned with lock; storage rejects older tokens |
| Multi-node Redlock | Acquire on majority of N Redis instances for fault tolerance |
| Lock wait queue | Fair queuing — waiters acquire in order, not random retry |
| Observability | Metrics: acquisition latency, contention rate, heartbeat failures |
| Deadlock detection | Alert if lock held longer than N × TTL |
| ZooKeeper backend | Consensus-based locks for stronger correctness guarantees |

## Key Takeaways

- `SET NX EX` is the entire acquire operation — atomic in Redis
- The token prevents releasing someone else's lock — always check before delete
- The Lua scripts make check-then-act atomic — without them, there's a race between GET and DEL
- Heartbeat is what separates a production lock from a toy lock — without it, long-running critical sections lose the lock mid-execution
- Default to heartbeat=True; only disable for very short critical sections
