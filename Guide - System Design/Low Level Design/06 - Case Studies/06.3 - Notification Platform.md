# Case Study: Notification Platform

**Difficulty:** Medium-Hard | **Patterns:** Observer, Strategy, Builder, Factory, Template Method, Chain of Responsibility

---

## Step 1: Requirements

### Functional

- Send notifications via Email, SMS, Push, In-App channels
- Users can configure channel preferences and quiet hours
- Notification templates with variable substitution
- Priority levels: Critical, High, Normal, Low
- Retry on delivery failure (configurable per channel)
- Notification history and read receipts
- Bulk/broadcast notifications
- Rate limiting per user per channel

### Non-Functional

- Email: deliver within 30 seconds
- SMS: deliver within 10 seconds
- Push: deliver within 5 seconds
- At-least-once delivery
- Idempotent (no duplicate notifications)
- 99.9% availability

### Scope

- Core notification pipeline + channel delivery
- Not in scope: billing per notification, A/B testing, analytics dashboard

---

## Step 2: Core Entities

```
Notification        → what to send (content, type, priority)
NotificationRequest → who to notify and how
DeliveryAttempt     → record of each send attempt
NotificationTemplate → reusable content blueprint
UserPreferences     → per-user channel + quiet hours config
Channel             → delivery mechanism (email/sms/push/in-app)
```

```python
# models.py
from enum import Enum
from dataclasses import dataclass, field
from uuid import UUID, uuid4
from datetime import datetime
from typing import Optional, List

class NotificationPriority(Enum):
    CRITICAL = 1   # account security, fraud — always deliver
    HIGH = 2       # order confirmation, payment receipt
    NORMAL = 3     # promotions, weekly digest
    LOW = 4        # tips, onboarding hints

class NotificationChannel(Enum):
    EMAIL = "email"
    SMS = "sms"
    PUSH = "push"
    IN_APP = "in_app"

class DeliveryStatus(Enum):
    PENDING = "PENDING"
    SENT = "SENT"
    DELIVERED = "DELIVERED"
    FAILED = "FAILED"
    SKIPPED = "SKIPPED"   # skipped due to user preferences/quiet hours

@dataclass
class NotificationContent:
    """Rendered content ready for delivery."""
    subject: str         # email subject / push title
    body: str            # email html / sms text / push body
    metadata: dict = field(default_factory=dict)

@dataclass
class Notification:
    id: UUID
    user_id: UUID
    notification_type: str   # e.g., "order_confirmation", "password_reset"
    priority: NotificationPriority
    content: NotificationContent
    channels: List[NotificationChannel]
    idempotency_key: str
    created_at: datetime = field(default_factory=datetime.now)

@dataclass
class DeliveryAttempt:
    attempt_id: UUID = field(default_factory=uuid4)
    notification_id: UUID = None
    channel: NotificationChannel = None
    status: DeliveryStatus = DeliveryStatus.PENDING
    provider_reference: Optional[str] = None
    error_message: Optional[str] = None
    attempted_at: datetime = field(default_factory=datetime.now)
    delivered_at: Optional[datetime] = None

@dataclass
class UserNotificationPreferences:
    user_id: UUID
    enabled_channels: List[NotificationChannel]
    quiet_hours_start: Optional[int] = None   # hour 0-23 (e.g., 22 = 10pm)
    quiet_hours_end: Optional[int] = None     # hour 0-23 (e.g., 8 = 8am)
    unsubscribed_types: List[str] = field(default_factory=list)
    
    def is_channel_enabled(self, channel: NotificationChannel) -> bool:
        return channel in self.enabled_channels
    
    def is_quiet_hour(self, at: datetime) -> bool:
        if self.quiet_hours_start is None or self.quiet_hours_end is None:
            return False
        hour = at.hour
        if self.quiet_hours_start <= self.quiet_hours_end:
            return self.quiet_hours_start <= hour < self.quiet_hours_end
        else:  # wraps midnight
            return hour >= self.quiet_hours_start or hour < self.quiet_hours_end
    
    def is_type_subscribed(self, notification_type: str) -> bool:
        return notification_type not in self.unsubscribed_types


# templates.py — Template Method pattern for rendering
from abc import ABC, abstractmethod

class NotificationTemplate(ABC):
    """Template Method: defines rendering structure, subclasses fill variables."""
    
    def render(self, variables: dict) -> NotificationContent:
        self._validate_variables(variables)
        subject = self._render_subject(variables)
        body = self._render_body(variables)
        return NotificationContent(subject=subject, body=body)
    
    @abstractmethod
    def _render_subject(self, variables: dict) -> str: pass
    
    @abstractmethod
    def _render_body(self, variables: dict) -> str: pass
    
    def _validate_variables(self, variables: dict):
        missing = set(self.required_variables()) - set(variables.keys())
        if missing:
            raise ValueError(f"Missing template variables: {missing}")
    
    @abstractmethod
    def required_variables(self) -> List[str]: pass


class OrderConfirmationTemplate(NotificationTemplate):
    def required_variables(self):
        return ["customer_name", "order_id", "total", "estimated_delivery"]
    
    def _render_subject(self, v):
        return f"Order #{v['order_id']} Confirmed ✓"
    
    def _render_body(self, v):
        return f"""
            <h2>Hi {v['customer_name']},</h2>
            <p>Your order <strong>#{v['order_id']}</strong> has been confirmed.</p>
            <p>Total: <strong>₹{v['total']}</strong></p>
            <p>Estimated delivery: {v['estimated_delivery']}</p>
        """


class PasswordResetTemplate(NotificationTemplate):
    def required_variables(self):
        return ["customer_name", "reset_link", "expires_in_minutes"]
    
    def _render_subject(self, v):
        return "Reset your password"
    
    def _render_body(self, v):
        return f"""
            <p>Hi {v['customer_name']},</p>
            <p>Click <a href="{v['reset_link']}">here</a> to reset your password.</p>
            <p>This link expires in {v['expires_in_minutes']} minutes.</p>
        """


# channel_senders.py — Strategy pattern for delivery
class ChannelSender(ABC):
    @abstractmethod
    def send(self, user_id: UUID, content: NotificationContent,
             user_contact: str) -> DeliveryAttempt: pass
    
    @abstractmethod
    def channel(self) -> NotificationChannel: pass


class EmailSender(ChannelSender):
    def __init__(self, sendgrid_client, from_address: str):
        self._client = sendgrid_client
        self._from = from_address
    
    def channel(self): return NotificationChannel.EMAIL
    
    def send(self, user_id, content, user_contact) -> DeliveryAttempt:
        attempt = DeliveryAttempt(notification_id=None,
                                  channel=self.channel())
        try:
            msg_id = self._client.send(
                from_email=self._from,
                to_email=user_contact,
                subject=content.subject,
                html_content=content.body
            )
            attempt.status = DeliveryStatus.SENT
            attempt.provider_reference = msg_id
        except Exception as e:
            attempt.status = DeliveryStatus.FAILED
            attempt.error_message = str(e)
        return attempt


class SmsSender(ChannelSender):
    def __init__(self, twilio_client, from_number: str):
        self._client = twilio_client
        self._from = from_number
    
    def channel(self): return NotificationChannel.SMS
    
    def send(self, user_id, content, user_contact) -> DeliveryAttempt:
        attempt = DeliveryAttempt(channel=self.channel())
        try:
            msg = self._client.messages.create(
                to=user_contact, from_=self._from, body=content.body
            )
            attempt.status = DeliveryStatus.SENT
            attempt.provider_reference = msg.sid
        except Exception as e:
            attempt.status = DeliveryStatus.FAILED
            attempt.error_message = str(e)
        return attempt


class PushSender(ChannelSender):
    def __init__(self, fcm_client):
        self._fcm = fcm_client
    
    def channel(self): return NotificationChannel.PUSH
    
    def send(self, user_id, content, device_token) -> DeliveryAttempt:
        attempt = DeliveryAttempt(channel=self.channel())
        try:
            result = self._fcm.send(
                token=device_token,
                title=content.subject,
                body=content.body,
                data=content.metadata
            )
            attempt.status = DeliveryStatus.SENT
            attempt.provider_reference = result.message_id
        except Exception as e:
            attempt.status = DeliveryStatus.FAILED
            attempt.error_message = str(e)
        return attempt


# delivery_pipeline.py — Chain of Responsibility for pre-delivery checks
class DeliveryFilter(ABC):
    def __init__(self):
        self._next: Optional["DeliveryFilter"] = None
    
    def set_next(self, f: "DeliveryFilter") -> "DeliveryFilter":
        self._next = f; return f
    
    def check(self, notification: Notification, channel: NotificationChannel,
              prefs: UserNotificationPreferences) -> Optional[str]:
        """Returns skip reason if should skip, else passes to next."""
        reason = self._evaluate(notification, channel, prefs)
        if reason:
            return reason
        return self._next.check(notification, channel, prefs) if self._next else None
    
    @abstractmethod
    def _evaluate(self, notification, channel, prefs) -> Optional[str]: pass


class ChannelEnabledFilter(DeliveryFilter):
    def _evaluate(self, notification, channel, prefs):
        if not prefs.is_channel_enabled(channel):
            return f"Channel {channel.value} disabled by user"
        return None

class QuietHoursFilter(DeliveryFilter):
    def _evaluate(self, notification, channel, prefs):
        # Critical notifications bypass quiet hours
        if notification.priority == NotificationPriority.CRITICAL:
            return None
        if prefs.is_quiet_hour(datetime.now()):
            return "Quiet hours active"
        return None

class UnsubscribeFilter(DeliveryFilter):
    def _evaluate(self, notification, channel, prefs):
        if not prefs.is_type_subscribed(notification.notification_type):
            return f"User unsubscribed from {notification.notification_type}"
        return None

class RateLimitFilter(DeliveryFilter):
    def __init__(self, rate_limiter):
        super().__init__()
        self._limiter = rate_limiter
    
    def _evaluate(self, notification, channel, prefs):
        key = f"notif:{prefs.user_id}:{channel.value}"
        if not self._limiter.allow(key, limit=10, window_seconds=3600):
            return f"Rate limit exceeded for {channel.value}"
        return None


# notification_service.py — orchestrator
class NotificationService:
    def __init__(self, senders: List[ChannelSender], template_registry: dict,
                 prefs_repo, user_repo, attempt_repo, event_bus, rate_limiter):
        self._senders = {s.channel(): s for s in senders}
        self._templates = template_registry
        self._prefs_repo = prefs_repo
        self._users = user_repo
        self._attempts = attempt_repo
        self._bus = event_bus
        
        # Build delivery filter chain
        self._filter_chain = ChannelEnabledFilter()
        self._filter_chain.set_next(UnsubscribeFilter()) \
                          .set_next(QuietHoursFilter()) \
                          .set_next(RateLimitFilter(rate_limiter))
    
    def send(self, notification: Notification) -> List[DeliveryAttempt]:
        # Idempotency
        existing = self._attempts.find_by_idempotency_key(notification.idempotency_key)
        if existing:
            return existing
        
        prefs = self._prefs_repo.get(notification.user_id)
        user = self._users.get(notification.user_id)
        attempts = []
        
        for channel in notification.channels:
            sender = self._senders.get(channel)
            if not sender:
                continue
            
            # Run pre-delivery checks
            skip_reason = self._filter_chain.check(notification, channel, prefs)
            if skip_reason:
                attempt = DeliveryAttempt(
                    notification_id=notification.id, channel=channel,
                    status=DeliveryStatus.SKIPPED, error_message=skip_reason
                )
                attempts.append(attempt)
                continue
            
            contact = self._get_contact(user, channel)
            if not contact:
                continue
            
            attempt = sender.send(notification.user_id, notification.content, contact)
            attempt.notification_id = notification.id
            attempts.append(attempt)
            
            self._attempts.save(attempt)
            
            if attempt.status == DeliveryStatus.FAILED:
                self._bus.publish(NotificationDeliveryFailed(
                    notification_id=notification.id,
                    channel=channel.value,
                    error=attempt.error_message
                ))
        
        return attempts
    
    def send_from_template(self, template_name: str, user_id: UUID,
                           variables: dict, channels: List[NotificationChannel],
                           priority: NotificationPriority,
                           idempotency_key: str) -> List[DeliveryAttempt]:
        template = self._templates[template_name]
        content = template.render(variables)
        
        notification = Notification(
            id=uuid4(), user_id=user_id,
            notification_type=template_name,
            priority=priority,
            content=content,
            channels=channels,
            idempotency_key=idempotency_key
        )
        return self.send(notification)
    
    def _get_contact(self, user, channel: NotificationChannel) -> Optional[str]:
        contacts = {
            NotificationChannel.EMAIL: user.email,
            NotificationChannel.SMS: user.phone,
            NotificationChannel.PUSH: user.device_token,
            NotificationChannel.IN_APP: str(user.id),
        }
        return contacts.get(channel)
```

## Step 4: Patterns Used

|Pattern|Where|Why|
|---|---|---|
|**Strategy**|`ChannelSender`|Swap Email/SMS/Push without touching service|
|**Template Method**|`NotificationTemplate`|Fixed rendering structure, variable content|
|**Chain of Responsibility**|`DeliveryFilter`|Quiet hours, rate limit, unsubscribe checks composable|
|**Factory**|`template_registry` dict|Centralized template creation by name|
|**Observer**|`NotificationDeliveryFailed` event|Retry service reacts without tight coupling|

```python
# Retry handler — subscribes to delivery failures
class NotificationRetryHandler:
    MAX_RETRIES = 3
    BACKOFF = [60, 300, 1800]  # 1min, 5min, 30min
    
    def on_delivery_failed(self, event: NotificationDeliveryFailed):
        attempt = self._attempt_repo.get(event.attempt_id)
        retry_count = self._retry_repo.get_count(event.notification_id, event.channel)
        
        if retry_count >= self.MAX_RETRIES:
            logger.error(f"Max retries exceeded for notification {event.notification_id}")
            return
        
        delay = self.BACKOFF[retry_count]
        retry_task.apply_async(
            args=[event.notification_id, event.channel],
            countdown=delay
        )
```
