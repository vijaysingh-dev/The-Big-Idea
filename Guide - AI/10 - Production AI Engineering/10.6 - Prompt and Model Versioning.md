# Prompt and Model Versioning

## Why Versioning Matters

AI systems have non-deterministic components: prompts, models, retrieval configurations. Changes to any of these can silently change behavior.

Without versioning:

- "It was working last week" — which prompt was running last week?
- "The new model degraded quality" — do you have baseline metrics to compare against?
- "We need to rollback" — rollback to which state exactly?

Treating prompts and models as versioned artifacts enables reproducibility and safe rollouts.

---

## Prompt Versioning

### Store Prompts as Code

Every prompt lives in version control, not in a database or environment variable:

```
prompts/
├── rag_system_prompt/
│   ├── v1.0.txt          # original
│   ├── v1.1.txt          # added citation instruction
│   ├── v2.0.txt          # major rewrite
│   └── current -> v2.0   # symlink to active version
├── query_rewrite/
│   └── v1.0.txt
└── judge_evaluation/
    └── v1.0.txt
```

### Prompt Registry

```python
class PromptRegistry:
    def __init__(self, prompts_dir: str):
        self.prompts = {}
        self._load_all(prompts_dir)
    
    def get(self, name: str, version: str = "current") -> str:
        return self.prompts[f"{name}/{version}"]
    
    def _load_all(self, directory):
        for path in Path(directory).rglob("*.txt"):
            key = f"{path.parent.name}/{path.stem}"
            self.prompts[key] = path.read_text()

# Usage — version is explicit and logged
prompt = registry.get("rag_system_prompt", version="v2.0")
response = llm.call(prompt.format(context=context, query=query))
log_query(query, prompt_version="v2.0", model_version="gpt-4o-2024-11-20")
```

### Logging Prompt Versions with Every Request

Every query log should include the prompt and model version used:

```python
@dataclass
class QueryLog:
    query_id: str
    user_id: str
    query: str
    prompt_version: str      # e.g., "rag_system/v2.0"
    model_id: str            # e.g., "gpt-4o-2024-11-20"
    embedding_model: str     # e.g., "text-embedding-3-small"
    retriever_config: dict   # top_k, threshold, etc.
    response: str
    latency_ms: int
    tokens_used: int
    timestamp: datetime
```

This lets you filter evaluations by version and compare quality across versions.

## Model Versioning

### Pin Model Versions

Never use `"gpt-4o"` (unversioned) in production — use `"gpt-4o-2024-11-20"`. OpenAI and Anthropic update models behind the same name, which silently changes behavior.

```python
PRODUCTION_MODELS = {
    "primary_llm": "gpt-4o-2024-11-20",
    "fast_llm": "gpt-4o-mini-2024-07-18",
    "embedding": "text-embedding-3-small",
    "reranker": "cross-encoder/ms-marco-MiniLM-L-6-v2",
}
```

When upgrading: treat the new model version as a deployment with eval gating.

## Safe Rollout Process

```
1. Evaluate new prompt/model on golden set
   └── Must match or exceed current scores on all metrics

2. Shadow mode (1–5% traffic, don't serve to users)
   └── Run new version alongside prod, compare outputs, measure quality

3. Canary (5–10% traffic, serve to users)
   └── Monitor: user feedback, error rates, latency, cost

4. Gradual rollout (25% → 50% → 100%)
   └── Evaluate at each stage before proceeding

5. Full rollout
   └── Keep previous version deployed for 24–48h for fast rollback
```

```python
def route_to_version(user_id: str, experiment_id: str) -> str:
    # Deterministic assignment based on user_id hash
    bucket = hash(f"{user_id}:{experiment_id}") % 100
    
    if bucket < 5:    # 5% canary
        return "v2.0"
    else:
        return "v1.0"  # current production
```

## A/B Testing Infrastructure

```python
class PromptExperiment:
    def __init__(self, experiment_id: str, control: str, treatment: str, traffic_pct: float):
        self.id = experiment_id
        self.control = control        # e.g., "rag_system/v1.0"
        self.treatment = treatment    # e.g., "rag_system/v2.0"
        self.traffic_pct = traffic_pct
    
    def get_variant(self, user_id: str) -> tuple[str, str]:
        bucket = hash(f"{user_id}:{self.id}") % 100
        variant = "treatment" if bucket < self.traffic_pct * 100 else "control"
        prompt_version = self.treatment if variant == "treatment" else self.control
        return variant, prompt_version

# In the query handler
experiment = active_experiments.get("rag_v2_test")
if experiment:
    variant, prompt_version = experiment.get_variant(user_id)
    log_experiment_assignment(experiment.id, user_id, variant)
else:
    prompt_version = "rag_system/current"
```
