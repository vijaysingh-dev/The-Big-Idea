# Case Study: Parking Lot

**Difficulty:** Medium | **Patterns:** State, Strategy, Factory, Observer

---

## Step 1: Requirements Clarification

### Functional Requirements

- Multiple entry/exit gates
- Multiple vehicle types: Motorcycle, Car, Truck
- Multiple parking spot sizes: Small, Medium, Large
- Vehicle can enter only if spot of appropriate size available
- Issue a parking ticket on entry
- Calculate fee on exit based on duration and vehicle type
- Support multiple pricing strategies (hourly, flat rate, weekend rate)
- Track occupancy in real-time

### Non-Functional Requirements (for LLD scope)

- Thread-safe (multiple gates operating simultaneously)
- Extensible: new vehicle types, new pricing rules
- Testable without a real database

### Scope Boundary (interview clarification)

- Yes: core parking flow, pricing, occupancy
- No: payment processing (assume cash/card handled externally), reservations, EV charging

---

## Step 2: Core Entities

```
Vehicle       → type (Motorcycle, Car, Truck), license plate
ParkingSpot   → size, number, level, status (Available/Occupied)
ParkingTicket → vehicle, spot, entry time, exit time, fee
ParkingLot    → floors/levels, gates, overall capacity
Gate          → entry or exit, dispenses/processes tickets
PricingStrategy → calculates fee based on duration + vehicle type
```

**Value Objects:** `LicensePlate`, `Money`, `Duration` **Enums:** `VehicleType`, `SpotSize`, `SpotStatus`, `GateType`

---

## Step 3: State Machine

```
ParkingSpot:
  AVAILABLE ──[vehicle assigned]──▶ OCCUPIED
  OCCUPIED  ──[vehicle exits]─────▶ AVAILABLE
  AVAILABLE ──[maintenance]───────▶ OUT_OF_SERVICE
  OUT_OF_SERVICE ──[cleared]──────▶ AVAILABLE

ParkingTicket:
  ACTIVE ──[exit processed]──▶ CLOSED
  ACTIVE ──[lost ticket]─────▶ LOST
```

# models.py — Value Objects and Enums

from enum import Enum
from dataclasses import dataclass
from decimal import Decimal
from datetime import datetime
from typing import Optional
from uuid import UUID, uuid4

class VehicleType(Enum):
    MOTORCYCLE = "MOTORCYCLE"
    CAR = "CAR"
    TRUCK = "TRUCK"

class SpotSize(Enum):
    SMALL = 1
    MEDIUM = 2
    LARGE = 3
    
    def fits(self, vehicle_type: VehicleType) -> bool:
        """Returns True if this spot size accommodates the vehicle."""
        required = VEHICLE_SPOT_REQUIREMENTS[vehicle_type]
        return self.value >= required.value

VEHICLE_SPOT_REQUIREMENTS = {
    VehicleType.MOTORCYCLE: SpotSize.SMALL,
    VehicleType.CAR:        SpotSize.MEDIUM,
    VehicleType.TRUCK:      SpotSize.LARGE,
}

class SpotStatus(Enum):
    AVAILABLE = "AVAILABLE"
    OCCUPIED = "OCCUPIED"
    OUT_OF_SERVICE = "OUT_OF_SERVICE"

@dataclass(frozen=True)
class LicensePlate:
    value: str
    
    def __post_init__(self):
        if not self.value or len(self.value) < 2:
            raise ValueError(f"Invalid license plate: {self.value}")

@dataclass(frozen=True)
class Money:
    amount: Decimal
    currency: str = "INR"
    
    def __add__(self, other): 
        return Money(self.amount + other.amount, self.currency)
    
    def __str__(self):
        return f"{self.currency} {self.amount:.2f}"


# vehicle.py
@dataclass
class Vehicle:
    license_plate: LicensePlate
    vehicle_type: VehicleType
    
    def required_spot_size(self) -> SpotSize:
        return VEHICLE_SPOT_REQUIREMENTS[self.vehicle_type]


# parking_spot.py
@dataclass
class ParkingSpot:
    spot_id: str              # e.g., "A-001"
    level: int
    size: SpotSize
    _status: SpotStatus = SpotStatus.AVAILABLE
    _vehicle: Optional[Vehicle] = None
    
    @property
    def status(self) -> SpotStatus:
        return self._status
    
    @property
    def is_available(self) -> bool:
        return self._status == SpotStatus.AVAILABLE
    
    def can_fit(self, vehicle: Vehicle) -> bool:
        return self.is_available and self.size.fits(vehicle.vehicle_type)
    
    def assign(self, vehicle: Vehicle):
        if not self.can_fit(vehicle):
            raise ParkingError(f"Spot {self.spot_id} cannot fit {vehicle.vehicle_type}")
        self._vehicle = vehicle
        self._status = SpotStatus.OCCUPIED
    
    def release(self):
        if self._status != SpotStatus.OCCUPIED:
            raise ParkingError(f"Spot {self.spot_id} is not occupied")
        self._vehicle = None
        self._status = SpotStatus.AVAILABLE
    
    def mark_out_of_service(self):
        if self._status == SpotStatus.OCCUPIED:
            raise ParkingError("Cannot take occupied spot out of service")
        self._status = SpotStatus.OUT_OF_SERVICE


# ticket.py
class TicketStatus(Enum):
    ACTIVE = "ACTIVE"
    CLOSED = "CLOSED"
    LOST = "LOST"

@dataclass
class ParkingTicket:
    ticket_id: UUID
    vehicle: Vehicle
    spot: ParkingSpot
    entry_time: datetime
    exit_time: Optional[datetime] = None
    fee: Optional[Money] = None
    status: TicketStatus = TicketStatus.ACTIVE
    
    @property
    def duration_minutes(self) -> Optional[int]:
        if self.exit_time is None:
            return None
        delta = self.exit_time - self.entry_time
        return int(delta.total_seconds() / 60)
    
    def close(self, exit_time: datetime, fee: Money):
        if self.status != TicketStatus.ACTIVE:
            raise ParkingError("Ticket is not active")
        self.exit_time = exit_time
        self.fee = fee
        self.status = TicketStatus.CLOSED
    
    def mark_lost(self):
        self.status = TicketStatus.LOST


# pricing.py — Strategy Pattern
from abc import ABC, abstractmethod

class PricingStrategy(ABC):
    @abstractmethod
    def calculate(self, vehicle_type: VehicleType, duration_minutes: int) -> Money:
        pass

class HourlyPricingStrategy(PricingStrategy):
    """Rate per hour, different by vehicle type."""
    
    HOURLY_RATES = {
        VehicleType.MOTORCYCLE: Decimal("20"),
        VehicleType.CAR:        Decimal("50"),
        VehicleType.TRUCK:      Decimal("100"),
    }
    
    def calculate(self, vehicle_type: VehicleType, duration_minutes: int) -> Money:
        rate = self.HOURLY_RATES[vehicle_type]
        hours = Decimal(duration_minutes) / Decimal("60")
        # Round up to nearest hour
        import math
        billed_hours = Decimal(math.ceil(float(hours)))
        return Money(rate * billed_hours)

class FlatRatePricingStrategy(PricingStrategy):
    """Single flat fee regardless of duration."""
    
    FLAT_RATES = {
        VehicleType.MOTORCYCLE: Decimal("30"),
        VehicleType.CAR:        Decimal("80"),
        VehicleType.TRUCK:      Decimal("150"),
    }
    
    def calculate(self, vehicle_type: VehicleType, duration_minutes: int) -> Money:
        return Money(self.FLAT_RATES[vehicle_type])

class WeekendPricingStrategy(PricingStrategy):
    """Discounted rate on weekends."""
    
    def __init__(self, base_strategy: PricingStrategy, discount: Decimal = Decimal("0.2")):
        self._base = base_strategy
        self._discount = discount
    
    def calculate(self, vehicle_type: VehicleType, duration_minutes: int) -> Money:
        base_fee = self._base.calculate(vehicle_type, duration_minutes)
        discount_amount = base_fee.amount * self._discount
        return Money(base_fee.amount - discount_amount)


# spot_finder.py — Strategy for finding available spots
class SpotFinderStrategy(ABC):
    @abstractmethod
    def find_spot(self, spots: list[ParkingSpot], vehicle: Vehicle) -> Optional[ParkingSpot]:
        pass

class NearestEntrySpotFinder(SpotFinderStrategy):
    """Find closest available spot (simplistic: first available)."""
    def find_spot(self, spots: list[ParkingSpot], vehicle: Vehicle) -> Optional[ParkingSpot]:
        for spot in spots:
            if spot.can_fit(vehicle):
                return spot
        return None

class BestFitSpotFinder(SpotFinderStrategy):
    """Find spot that's the smallest fitting size (minimize waste)."""
    def find_spot(self, spots: list[ParkingSpot], vehicle: Vehicle) -> Optional[ParkingSpot]:
        fitting = [s for s in spots if s.can_fit(vehicle)]
        if not fitting:
            return None
        return min(fitting, key=lambda s: s.size.value)


# parking_lot.py — Core aggregate
import threading

class ParkingLot:
    """
    Aggregate root for the parking lot domain.
    Thread-safe: uses locks for spot assignment.
    """
    
    def __init__(self, name: str, spots: list[ParkingSpot],
                 pricing_strategy: PricingStrategy,
                 spot_finder: SpotFinderStrategy):
        self._name = name
        self._spots = spots
        self._pricing = pricing_strategy
        self._spot_finder = spot_finder
        self._active_tickets: dict[UUID, ParkingTicket] = {}
        self._vehicle_to_ticket: dict[str, UUID] = {}  # license → ticket_id
        self._lock = threading.Lock()
    
    # ── Entry ─────────────────────────────────────────────
    
    def enter(self, vehicle: Vehicle) -> ParkingTicket:
        with self._lock:
            # Prevent duplicate entry
            license_key = vehicle.license_plate.value
            if license_key in self._vehicle_to_ticket:
                raise ParkingError(f"Vehicle {license_key} is already parked")
            
            spot = self._spot_finder.find_spot(self._spots, vehicle)
            if not spot:
                raise ParkingFullError(f"No available spot for {vehicle.vehicle_type}")
            
            spot.assign(vehicle)
            ticket = ParkingTicket(
                ticket_id=uuid4(),
                vehicle=vehicle,
                spot=spot,
                entry_time=datetime.now()
            )
            self._active_tickets[ticket.ticket_id] = ticket
            self._vehicle_to_ticket[license_key] = ticket.ticket_id
        
        return ticket
    
    # ── Exit ──────────────────────────────────────────────
    
    def exit(self, ticket_id: UUID) -> ParkingTicket:
        with self._lock:
            ticket = self._active_tickets.get(ticket_id)
            if not ticket:
                raise TicketNotFoundError(ticket_id)
            
            exit_time = datetime.now()
            fee = self._pricing.calculate(
                ticket.vehicle.vehicle_type,
                ticket.duration_minutes or 0
            )
            ticket.close(exit_time, fee)
            ticket.spot.release()
            
            del self._active_tickets[ticket_id]
            del self._vehicle_to_ticket[ticket.vehicle.license_plate.value]
        
        return ticket
    
    # ── Queries ───────────────────────────────────────────
    
    def available_spots(self) -> dict[SpotSize, int]:
        """Thread-safe occupancy snapshot."""
        with self._lock:
            result = {size: 0 for size in SpotSize}
            for spot in self._spots:
                if spot.is_available:
                    result[spot.size] += 1
            return result
    
    def total_capacity(self) -> dict[SpotSize, int]:
        result = {size: 0 for size in SpotSize}
        for spot in self._spots:
            if spot.status != SpotStatus.OUT_OF_SERVICE:
                result[spot.size] += 1
        return result
    
    def is_full(self, vehicle: Vehicle) -> bool:
        with self._lock:
            return self._spot_finder.find_spot(self._spots, vehicle) is None
    
    @property
    def active_ticket_count(self) -> int:
        return len(self._active_tickets)


# factory.py — Factory for building the lot
class ParkingLotFactory:
    @staticmethod
    def create_standard_lot(levels: int, spots_per_level: dict[SpotSize, int]) -> ParkingLot:
        spots = []
        for level in range(1, levels + 1):
            for size, count in spots_per_level.items():
                for i in range(1, count + 1):
                    spot_id = f"L{level}-{size.name[0]}{i:03d}"
                    spots.append(ParkingSpot(spot_id=spot_id, level=level, size=size))
        
        return ParkingLot(
            name="Standard Lot",
            spots=spots,
            pricing_strategy=HourlyPricingStrategy(),
            spot_finder=BestFitSpotFinder()
        )

## Step 5: Pattern Justifications

|Pattern|Where|Why|
|---|---|---|
|**Strategy**|`PricingStrategy`|Different pricing rules without modifying `ParkingLot`|
|**Strategy**|`SpotFinderStrategy`|Different spot selection algorithms (nearest, best-fit)|
|**State**|`ParkingSpot._status`|Valid transitions enforced (`AVAILABLE→OCCUPIED→AVAILABLE`)|
|**Factory**|`ParkingLotFactory`|Complex construction logic isolated from domain|
|**Template Method**|(base pricing)|`WeekendPricingStrategy` wraps and modifies base strategy|

## Alternative Designs Rejected

|Alternative|Why Rejected|
|---|---|
|`ParkingLot.enter()` directly assigns spot|Spot-finding logic should be swappable (Strategy)|
|Fee calculated on exit in `Gate` class|Pricing belongs to business domain, not infrastructure|
|Mutable enum for SpotStatus|State pattern (even if simple) makes transitions explicit|
|One big `ParkingManager` class|SRP violation — split into Lot, Gate, Ticket, Pricing|
